# Universal LPC 本地按需缓存版

双击 `启动Universal-LPC.cmd`，浏览器将打开 http://127.0.0.1:18764/ 。

此目录保存官方发布的浏览器应用，素材首次使用时从官方站点下载至 cache，之后复用本地文件。首次加载和未缓存素材需要联网；这不是完整离线素材包。服务只监听本机。

1. 选择 Male / Female 等身体类型。
2. 在 Hair、Torso、Legs、Feet 等分类中选择部件与颜色。
3. Animation Preview 中选择 Walk，查看四方向行走。
4. 用 Spritesheet (PNG) 导出完整精灵图；用 ZIP: Split by animation 导出分动作图片。
5. 同时导出 Credits (TXT/CSV) 保存素材署名，Export to Clipboard (JSON) 保存可编辑角色配置。

官方项目：https://github.com/LiberatedPixelCup/Universal-LPC-Spritesheet-Character-Generator
素材许可和署名以工具针对所选部件导出的 Credits 为准。

## 已验证的示例

`示例/四方向行走.png` 是 832 × 256 的行走图，帧格为 64 × 64，四行顺序为上、左、下、右。每行前九列为一帧站立与八帧行走，末尾四列是导出格式保留的空白。`示例/行走预览.gif` 可直接查看四方向动画。

`示例/完整精灵图.png`、`示例/分动作图片.zip` 和 `示例/素材署名.txt` 均通过生成器导出。`测试角色.json` 可复制内容并用 Import from Clipboard (JSON) 恢复编辑。
