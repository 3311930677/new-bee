## Game Visual Style Guide (全局视觉设计规范)

1. **主色调 (Primary Palette)**：
   - 暗夜漆黑底衬 (Night Base): `#0c0a10` / `#141018`
   - 漆器青铜中景 (Lacquer Bronze Face): `#1d1724` / `#261e2e`
   - 鎏金/沉金 (Gilded Gold Trim): `#c29a5b` / `#d4af37`
2. **辅助色 (Secondary Palette)**：
   - 璀璨暖金 (Bright Gold Accent): `#fce2a6`
   - 朱砂/赤丹 (Vermilion Seal): `#a3211c` / `#e2402c`
   - 翡翠青/碧玉 (Jade Vitality): `#3abda9` / `#55d8a8`
   - 幽夜青绀/紫魄 (Mystic Night): `#9e71cc` / `#684594`
   - 楮墨雅宣 (Parchment Paper): `#e6dcce`
   - 黛灰旧色 (Aged Muted): `#8f8376`
3. **字体风格 (Typography)**：
   - 一级标题与英雄名号：正统宋体衬线体 (`G.font_serif`)，18~24px，字距微扩，烫金微阴影
   - 二级功能与属性数据：清晰无衬线体粗体 (`G.font_bold`)，14~16px，高对比度
   - 三级描述与剧情正文：清晰无衬线常规体 (`G.font_reg`)，12~13px，全局关闭抗锯齿模糊 hinting
4. **边框风格 (Border Style)**：
   - 主面板外框：1~2px 金铜双线或嵌金暗纹 (`#c29a5b`, alpha 0.85~0.95)，内凹 1px 暗铜深沟 (`#6a5338`, alpha 0.6)
   - 次级卡片槽位：1px 黄铜描边 (`#5b4731`, alpha 0.75) 配内陷暗底 (`#120e16`)
5. **按钮风格 (Button Feedback & States)**：
   - 统一金漆木纹或赤铜雕花底托，配备四态（Normal/Hover/Pressed/Disabled）
   - 触控回弹曲线：按下极速收缩 (`scale 0.96` 0.05s) -> 释放弹性过冲 (`scale 1.03` 0.08s) -> 恢复原状 (`scale 1.0` 0.08s)
   - 触觉与音效：按下同步触发 18ms 轻微马达震动 (`HapticFeedback.light()`) 与清脆竹木/金铁音效
6. **面板风格 (Panel & Modal Dynamics)**：
   - 材质感：玄漆金丝、暗夜微磨砂半透背板，杜绝单调纯色平涂
   - 入场动效：弹性舒展微放 (`scale 0.95 -> 1.0, 0.16s, EASE_OUT`)；退场动效：收缩淡出 (`scale 0.94, alpha 0.0, 0.12s`)
7. **图标风格 (Iconography)**：
   - 100% 东方玄幻与奇幻硬派像素资产，严格保持像素网格整数比 (`TEXTURE_FILTER_NEAREST`)，杜绝非等比拉伸与模糊插画
   - 统一外包边框：八角铜环、金角托槽或符文封印
8. **阴影规则 (Shadows & Grounding)**：
   - 悬浮面板：投射深黑软阴影（`shadow_size = 12~18px`, `Color(0, 0, 0, 0.55)`）
   - 场景道具与单位：西北向东南倾斜 45° 的扁椭圆接地软阴影（dx=12, dy=8, alpha 0.35），杜绝地物漂浮
9. **圆角规则 (Corner Radius)**：
   - 主外框面板：3~4px 典雅微圆角
   - 内嵌卡片与插槽：2~3px 微圆角
   - 标签与药丸胶囊：完全圆角（`radius = height * 0.5`）
10. **间距规则 (Spacing Hierarchy)**：
    - 屏幕外边缘安全边距：`>= 12px`
    - 容器内部内边距 (Padding)：`12~16px`
    - 卡片与条目间距 (Gap)：`8~10px`
    - 按钮与辅助标签间距：`6~8px`
