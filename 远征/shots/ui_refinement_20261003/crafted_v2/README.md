# 行旅册视觉改版

当前实现使用项目内已有的古城背景、远征书法标题与建筑贴图；界面边框、黄铜包角、朱印和头像徽章在游戏内绘制。

- [登录页与城门预览](preview.png)
- [登录页](480x800/login.png)、[头像更换](480x800/avatar.png)、[城门](480x800/gate.png)、[图志阁](480x800/archive.png)
- [长屏登录页](480x1067/login.png)、[长屏头像更换](480x1067/avatar.png)、[长屏城门](480x1067/gate.png)、[长屏图志阁](480x1067/archive.png)

两种视口的 8 个状态均由实际 Godot 场景生成并逐张检查。头像回归通过，涵盖预设选择、自选图片、旧存档转换、重读保存与头像尺寸。测试使用独立存档目录。

字体分工：原书法素材用于游戏标题，站酷小薇用于界面标题与主按钮，思源宋体用于次级标题与角色标签，思源黑体用于输入框与正文。

预设头像：赤尾狐、夜猫、石龟、雪团，与职业独立。

原始运行日志与 `results.json` 同目录保存。Godot 运行环境仍会报告证书读取和退出时资源诊断；截图成功与脚本错误分别检查。尚未进行手机真机触控验证。

复现：从项目目录运行 `python tools/capture_journal_ui.py --godot <Godot 控制台程序路径>`。
