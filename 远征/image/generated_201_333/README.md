# 201–333 图片素材

按 `docs/2026-09-15-图片提示词总库.md` 的 201–333 号生成，共 133 张；前 001–200 不重复生成。

## 可直接使用目录

- `ready/icons/`：技能、节点、状态、货币、宝石、物品、槽位与段位图标，按提示词规格输出。
- `ready/ui/`：面板、卡池界面、横幅、启动图与品牌图，按提示词精确画布输出。
- `ready/cards/`：卡框/卡背；卡框中心已清空为透明，便于叠加卡面。
- `ready/fx/`：抽卡、坐骑召唤等横向等宽帧条，按 `jobs.json` 的 `frames` 与单帧尺寸切图。
- `ready/maps/`：地图节点徽记。
- `ready/npcs/`：透明半身 NPC；`ready/mounts/`：透明侧向坐骑，鞍位平坦并保留接地锚点。
- `source/`：原始生成母稿；`qa/`：分类验收总览。

所有 ready PNG 均已硬化 alpha、按提示词精确画布化；透明素材四边保留安全边，UI/卡背类保持不透明。Godot 导入时使用 Nearest、关闭 mipmaps。
