# 破军四方向 · Pixel Art Studio 试作

使用 Gamezxz/pixel-art-studio 制作，并已替换游戏正式使用的破军行走资源：

- image/role/zs/pojun_walk_4dir.png
- image/role/zs/pojun_walk_frames.tres

每方向 8 帧，128×128 单帧，110ms/帧。行顺序：下、左、右、上。
头部、盔甲、握剑手以原图为底，双腿逐帧制作；后向原图的断裂钢刃已补接。
不是重新生成不同的人物。

双击游戏目录的“打开破军四方向试用.cmd”即可进入实际地图预览。
方向键 / WASD 移动，数字 1–4 自动向对应方向走一小段，空格切换原版对比。
预览存档独立于玩家正式存档。
