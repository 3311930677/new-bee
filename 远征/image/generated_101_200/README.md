# 101–200 图片素材

按 `docs/2026-09-15-图片提示词总库.md` 的 101–200 号生成，共 100 张；100 号未重复生成。

## 目录

- `source/`：内置 imagegen 返回的原始母稿，保留原始比例，便于追溯。
- `ready/map/`：101–142，精确画布、硬 alpha、统一居中/接地或悬浮锚点，可直接放到地图层。
- `ready/fx/`：143–167，240×240 等宽帧格的横向条带，按 `frames` 列切图。
- `ready/fx/`：185–192，128×128 等宽帧格的横向条带，按 `frames` 列切图。
- `ready/status/`：168–184，32×32 状态图标。
- `ready/skill/`：193–200，64×64 技能图标。
- `qa/`：按类别的验收总览和首/中/尾帧检查图。

## Godot 使用约定

地图精灵使用 ready/map 中的无文字 PNG；角色/怪物节点锚点放在脚底或提示词指定的悬浮中心。fx 与 sfx 条带按 jobs.json 的 `frames` 等分切块，ready 版本为透明 alpha，适合直接叠加；source 母稿保留生成器原始结果。导入时使用 Nearest、关闭 mipmaps。

## 验收

脚本已检查 101–200 每个编号均有 source 与 ready，ready 图像按提示词尺寸生成；接地类保留底部安全边，悬浮类垂直居中；特效条带按指定帧数等宽切分。详细字段见 jobs.json。
