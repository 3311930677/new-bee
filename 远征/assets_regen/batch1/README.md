# 批次 1：角色全套资产

本批次沿用批次 0 v2 已确认的原版参考方向：低逻辑分辨率、硬边像素、深色描边、有限色阶、紧凑三头身比例。原始解包图只作为造型、比例、轮廓和色板参考，生成图不直接替换原游戏资源。

## 目录

- `anchors/ready/`：5 个角色立绘锚点，512x768
- `combat/ready/`：6 个战斗动作精灵，112x124
- `walk_grid/ready/`：3 组行走动画网格，4 行 x 5 列，共 20 帧，640x800
- `avatars/ready/`：6 个从锚点图裁出的角色头像，96x96
- 对应 `raw/` 目录保留 ImageGen 原始输出，便于后续重新量化或调整裁切
