# 批次 2：UI 全套

本批次按原版解包 UI 的轮廓、蓝金配色、木质底纹和像素颗粒重新生成，全部禁止烘焙文字，文字由引擎后续渲染。

## ready 资产

- `buttons/`：横幅按钮悬停、按下、禁用 3 状态；常态沿用 `batch0_v2`
- `panels/`：木牌匾、羊皮纸九宫格面板、深木九宫格面板
- `bars/`：HP 框、MP 框、0-9 金色数字排
- `icons/`：背包、任务、坐骑、宠物、社交、设置、邮件、商城 8 个图标

目标尺寸：按钮 480x96、牌匾 480x128、面板 512x512、血蓝条 480x36、数字排 512x64、图标 96x96。

所有 ready 图已做透明边缘硬化、逻辑分辨率降采样、最近邻放大和无抖动色板量化；前景有效色不超过 40 色。面板中央保留透明区，便于引擎九宫格填充或叠加内容。

对应 `raw/` 目录保留 ImageGen 原始输出。
