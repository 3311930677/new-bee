## 二、基线模拟发现的问题与调优措施

### 1. 基线问题定位
1. **牧师（`fz` 晨星）单刷清场偏慢与 AI 能量空耗**：
   - 晨星五式技能（`圣愈`、`普照`、`净化`、`祝祷`、`破晓`）在 `data/skills.json` 中基础伤害系数均为 `k = 0`，完全依赖普攻（`basic_attack_k = 1.35`）。
   - 在原 `MonsterAI._auto_condition` 中：
     - `祝祷`（`fz_zhudao`）仅在 `enemies.size() >= 3 or sim.has_boss()` 时施放，导致残局剩 1~2 只怪时晨星不再补攻击增益；
     - `破晓`（`fz_poxiao`，60 能量大招）未设血线条件，导致满血状态也频繁空放消耗 60 能量与前摇时间。
2. **成长字典口径对齐**：
   - `BattleSim._build_role` 读取的是 `hp_add / maxhp_pct / atk_add / atk_pct / def_add / def_pct / spd_pct / crit_add`，必须在模拟器和局外对比预览中保持唯一口径。

### 2. 实际代码调优（保持 `VerifyGameplayBalance` 100% 兼容）
1. **智能托管条件优化 (`src/combat/MonsterAI.gd`)**：
   - `fz_zhudao`：当自身没有 `atk_up` 增益时主动补放，确保单刷全程覆盖祝祷增益；
   - `fz_poxiao`：仅在任一友方生命低于 `72%` 或首领战满能量时施放，杜绝普通战满血空放大招。
2. **祝祷圣光惩击与攻速联动 (`src/combat/SkillSystem.gd`)**：
   - 晨星施放 `祝祷` (`fz_zhudao`) 时，除赋予 `atk_up (+20% ATK)` 外，同步赋予圣锤迅捷 `spd_up (+18% SPD)`，并对敌方最低血量目标降下一道圣光惩击（`1.45 × ATK` 基础伤害计算），既保留晨星“治疗辅助·圣锤牧者”的职业身份与 `basic_attack_k = 1.35` 契约，又显著改善单人跑图刷怪手感。
