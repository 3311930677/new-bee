## 一、工程现状审计与核心痛点诊断

### 1.1 现有工程架构概览
- **全局单例与存档**：`src/autoload/G.gd` 统一管理玩家账号、四大职业（`zs` 破军、`ck` 穿杨、`fs` 霜语、`fz` 晨星）、钱包（金币/远征币/魂晶/荣誉）、背包与装备、宠物、主世界状态（`G.prog["main_world"]`）、任务进度与统一场景跳转 `G.go()`。
- **核心界面与场景流**：
  - 启动流：`TitleScene.tscn` → `Login.tscn` → `CreateRole.tscn`（挂载 `CreateRoleChestView.gd`） → `GameHome.tscn`（默认挂载 `src/ui/home/TownHome.gd`）。
  - 探索流：`MapScene.tscn`（`src/explore/MapScene.gd`）承载 18 张主世界相连地图（`data/main_world_maps.json`）与经典秘境地图；`CityScene.tscn` 承载经典主城。
  - 战斗流：`BattleScene.tscn`（`src/battle/BattleScene.gd`）采用竖屏回合制策略战斗（普攻、职业专属技能、奥义大招、架势破防、弱点克制、宠物助战、药水与逃跑）。

### 1.2 核心体验缺陷（Phase 2 重点攻关）
1. **任务 A（地图探索与连通性痛点）**：
   - 现有 `data/main_world_maps.json` 共 18 张区域（昭元边城 → 枫林古道 → 断碑坡/旧盐道 → 沉渊港 → 赤砂商路 → 霜关驿 → 渊口外环 → 碑心等），但主页「世界」打开的 `RegionChestMap.gd`（地区行路图）仅为纯静态浏览面板，底部写死“沿相邻路牌步行前往，地点选择不会传送”，且不显示当前追踪的主线/支线/委托目标在哪个地区。
   - 真正的驿路快速旅行 `JourneyPanel.gd`（`JourneyService.gd`）被深埋在“进入野外地图 → 点击右上角微缩地图 → 再点击底部【驿路与传世】按钮”的三级入口里，导致玩家跑图极其繁琐、缺乏全局空间认知。
   - 野外地图 `MapScene.gd` 的出口路牌缺少相对于当前追踪任务的“最优路径方向引导（BFS 寻路提示）”，玩家在多岔路地图（如枫林古道、沉渊港、霜关驿）容易迷失方向。
2. **任务 B（任务系统与 NPC 交互单调）**：
   - 现有支线与委托以“击杀/收集/对话”为主，缺乏调查、试炼小游戏、剧情分支抉择等丰富目标。
   - 简单交付型任务与跨区域跑腿任务缺乏“驿站信使便捷交付”或“一键乘驿车前往目标区域”机制，导致无意义的重复折返跑。
3. **任务 C（主页四角色动态展示 Bug 与角色重选体验）**：
   - **严重缺陷**：`src/ui/home/TownHome.gd:199` 中，主页“出征”按钮上方的舞台角色直接硬编码为 `_strip_sprite(DIR + "hero_town_idle.png", 4, 5.0)`，完全无视 `G.selected_role`！无论玩家选的是破军（`zs`）、穿杨（`ck`）、霜语（`fs`）还是晨星（`fz`），主页永远只显示同一个固定小人，且 `refresh()` 时从不刷新角色精灵。
   - 同时主页舞台缺少当前角色名号/职业定位铭牌、朝向预览与快捷切换/重选角色入口；`CreateRoleChestView.gd` 在“重选角色”模式下也需要支持保留当前存档进度并直观预览四方向动画与职业成长定位。
4. **任务 D（人物行走接地感不足）**：
   - `MapScene.gd` 中跟随宠物 `_pet_follower` 有椭圆形脚底接触阴影，但玩家主角 `_player` 本身竟然没有脚底接触阴影（Contact Shadow），且行走时的重心起伏、脚底基线与地面贴合感不足；`TownHome.gd` 主页舞台角色脚底阴影与基座对齐也需精细校准。
5. **任务 E（缺少完整交互式新手引导）**：
   - 目前首次进入游戏仅有简短的新人任务气泡，缺少涵盖“认识角色 → 移动探索 → NPC 对话 → 接取与追踪任务 → 基础战斗 → 战斗奖励 → 装备穿戴 → 角色成长 → 地图切换 → 返回边城/主城 → 后续远征目标说明”的 11 步剧情融合式交互引导，且缺少引导进度持久化、随时跳过与帮助重看入口。

## 二、七阶段开发路线与优先级

| 阶段 | 核心模块 | 关键交付物与验收标准 |
| :--- | :--- | :--- |
| **Phase 1** | 工程审计、基线截图与长程计划 | 建立 `docs/agent_iteration/` 全套文档体系；抓取 10 张 `before/` 基线截图；锁定回归门禁约束。 |
| **Phase 2** | 核心体验修复（Task A ~ E） | A: `RegionChestMap` 升级为可交互世界行路图（显示任务目的地徽记、迷雾/解锁态、一键驿车传送已访地区）+ `MapScene` BFS 路牌任务方向指引；B: 任务系统升级（信使快捷交付、任务追踪一键导航、新增调查/试炼/抉择目标）；C: 修复 `TownHome` 四角色数据驱动动态展示 + 角色快捷切换/重选与 `CreateRole` 升级；D: `MapScene` / `CityScene` / `TownHome` 角色脚底接触阴影与步态接地校准；E: 11 步交互式新手引导系统（`TutorialService.gd` + `TutorialOverlay.gd`）。 |
| **Phase 3** | 战斗与数值平衡模拟 | 编写可复现数值模拟脚本 `tools/SimBalanceReport.gd`，覆盖 4 职业 × 前/中/后期 × 普通/精英/Boss，校准 TTK、蓝耗、治疗与经济曲线，输出 `BALANCE_REPORT.md`。 |
| **Phase 4** | 五轮实质内容扩充（Round 1 ~ 5） | 依次落地：Round 1（辕门射艺小游戏 + 探索奇物点）、Round 2（套装/特殊词缀装备扩充 + 装备对比 UI）、Round 3（区域历史碑铭 + 多分支支线与 NPC 阶段对话）、Round 4（同行灵宠互动、寻宝感知与羁绊养成）、Round 5（云游秘商、藏宝图解谜、裂隙首领挑战与职业彩蛋称号）。 |

| **Phase 6** | 自动化回归、多分辨率截图与对比 | 扩展 `tools/run_regression.ps1` 覆盖全部新增系统；输出 `480×800` 与 `480×1067` 的 `after/` 与 `comparisons/` 截图。 |
| **Phase 7** | 文档收口、分批 Git 提交与推送 | 完善全部 9 份迭代文档，按逻辑批次执行显式路径 `git commit` 并推送到 `origin/main`。 |

## 三、五轮内容扩充详细规划（Phase 4）

### 第 1 轮：探索与趣味互动扩充（含可玩「辕门射艺」小游戏）
- **核心玩法**：在昭元边城（`lorin_wilds`）与霜关驿（`frost_post`）及主界面驻地增设可交互 NPC「边军教头·斛律温」与「辕门射艺靶场」（`src/ui/ArcheryPanel.gd` + `data/archery.json`）。
- **射艺机制**：包含横移/高低起伏靶位、风向偏移修正、蓄力槽（拉弓蓄力与最佳松弦时机判定）、三档难度（新兵木靶 / 百步流矢 / 朔风贯日）、环数计分（正中靶心 10 环、内环 8 环、外环 5 环、连中加成）、历史最高分记录（持久化至 `G.prog["archery"]`）与分级奖励（远征币、金币、专属神射箭袋饰品与称号）。
- **地图探索微交互**：在主世界各区域增设可翻找的「旧军需木箱」「风化路标碑」「古战场遗物」等探索微事件。

### 第 2 轮：装备与角色成长扩充
- **新增装备内容**：在 `data/equip.json` 中扩充覆盖四职业定位的进阶武器、护甲、饰品及「边塞远征套」「霜关守御套」「碑林星辉套」等具有特殊被动词缀（暴击追伤、破甲连击、护盾回复、首回合先攻）的特色装备。
- **装备对比与标签 UI**：升级 `BagPanel.gd` / `EquipPanel.gd`，点击背包装备时直观展示与当前已穿戴同部位装备的属性差值（`+ATK` 绿字 / `-DEF` 红字）、词缀说明与获取途径提示。

### 第 3 轮：剧情、NPC 与区域叙事扩充
- **多阶段与分支支线**：新增具有抉择分支的支线任务（例如在旧盐道与沉渊港之间抉择护送盐工遗物归乡或交予港务司换取重赏，不同选择影响后续 NPC 台词与专属纪念信物）。
- **区域碑铭与风物志**：在主世界增加可调查的历史石碑与风物记录，阅读后记入远征手札并给予探索阅历奖励。

### 第 4 轮：同伴/宠物与收集玩法扩充
- **灵宠互动与寻宝感知**：扩展 `PetPanel.gd` 与 `MapScene.gd` 中的同行灵宠功能，支持在面板中「喂食/抚摸」提升灵宠亲密羁绊（`pet_bond`），解锁灵宠在野外地图对附近未开启宝箱/奇物点的「灵觉方位提示」与战斗协同增益。

### 第 5 轮：隐藏玩法、挑战与世界秘密扩充
- **云游秘商与藏宝古卷**：在特定区域出现神秘NPC「云游古董商·墨尘」，支持用探索收集的古币/残页兑换藏宝图线索与传奇秘宝；新增高难挑战「碑林古魂试炼」与四职业专属身世彩蛋及传奇称号。
