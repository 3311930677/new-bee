#《远征》整体玩法、玩家通关路线与联机数值方案

审计日期：2026-10-05。依据当前工作区的实际代码与数据，包含本次修复。文中的“当前”指已接入运行时的行为；“建议”指未来设计目标。旧设计文档只作背景参考，不能替代当前实现。

## 1. 玩家实际上在玩什么

《远征》目前是一款竖屏、单人、地图探索与即时指令战斗结合的角色养成游戏。主要体验是：在城镇接到线索，沿地图查证、战斗和解机关，带着任务物返回城镇，把一段路恢复起来，再进入下一幕。

2026-10-05 后续更新：已加入驿路旅行、递进难度、传世挑战、四把传世武器与归路圣鹿。最新入口、掉落与培养规则见 [更新说明](2026-10-05-旅行难度传世与宠物更新.txt)，四份参考设计的取舍见 [参考解读](2026-10-05-四份玩法参考解读.txt)。下文战斗时长与“主线压力偏轻”是本次递进调整之前的审计记录，新的样本见 `plans/2026-10-05-campaign-pressure-samples.json`。

原审计内容规模：四职业、四幕36步主线、18张主世界地图、36条支线、三城12种巡界委托模板、3个特色复战试炼、8个重复历练主题、9种灵宠、6种坐骑。数字按本次审计的数据表计数，包含通关后的归路托付。

玩家有两条独立进度：

| 进度 | 玩家目标 | 如何推进 | 如何判定完成 |
|---|---|---|---|
| 主世界归路碑篇 | 查明失声、修路、稳定碑心、交还记录 | 对话、到达地点、观察、收集、解谜、指定首领战 | 完成s36；只打倒s35首领还需要回城交任务 |
| 八主题历练 | 反复出征、选词条、收集资源、解锁下一个主题 | 每局三层分岔路线，再挑战首领 | 每个主题分别记录首领通关；通关后可扫荡 |

主世界推进不会自动完成八主题历练，历练全通也不会替玩家完成四幕对话与机关。旧文本仍存在“修八碑、打王城”和现行归路碑篇目标混用的地方，后续应统一玩家看到的终点。

核心循环：**接任务 → 看地图目标 → 出行查证与战斗 → 获得经验、金币和装备 → 回城交付、授业与补给 → 进入下一段路**。历练、贸易、邮路、钓鱼和委托为这条循环提供可选分支。

## 2. 四职业怎么选

下表是1级裸属性；装备、天赋、坐骑和称号另算。速度决定普攻频率与回能速度。

| 职业 | 生命 | 攻击 | 防御 | 速度 | 基础暴击 | 实际定位与适合玩家 |
|---|---:|---:|---:|---:|---:|---|
| 破军／战士 | 130 | 22 | 14 | 1.00 | 5% | 前排、破甲、群斩、残血处决；希望能抗能打、手动抓破绽的玩家 |
| 穿杨／枪骑 | 100 | 24 | 9 | 1.20 | 7% | 按远程规则站后排，普攻快，多段与后排打击；希望刷怪流畅、集火关键敌人的玩家 |
| 霜语／法师 | 90 | 26 | 8 | 0.90 | 5% | 后排、群伤、减速与护盾；希望在多怪战控制节奏的玩家 |
| 晨星／牧师 | 115 | 22 | 12 | 0.95 | 5% | 前排、治疗、净化、攻击增益和短暂无敌；容错较高，单刷仍比输出职业慢 |

本次将晨星普攻输入攻击系数调整为1.35，其他职业默认1.00。这个系数进入伤害公式，**不能直接理解为最终伤害增加35%**；治疗仍用原攻击面板，普攻回能仍为20。调整的目的，是缩小辅助职业单刷首领的时间差。

目前四职业共用同一防御公式，没有独立的物理防御、魔法防御或元素抗性。元素主要用于伙伴响应等联动，职业标签不能当成已经实现的属性克制。

## 3. 战斗：玩家要关注哪些事

### 3.1 即时战斗与操作

遇到地图上的明雷后进入战斗。普攻随时间自动执行，玩家通过“攻击、技能、道具、撤退”指令干预。打开技能或道具列表时，模拟继续推进，因此它属于即时指令战斗。倍速加快整场模拟，双方一起变快；战斗内部固定每秒30步。

“攻击”用于指定集火目标，并不绕过普攻间隔。近战通常先打敌方前排，前排全灭后可以攻击后排；远程可以跨排选目标。默认目标往往是剩余生命最少的单位。嘲讽、混乱等状态优先于玩家集火。

主世界通常是玩家与一只具体的地图怪交战，首领可以召唤增援；历练普通节点通常3～4怪，精英是强化精英加随从，首领带随从。主世界的通关难度不能用历练的多怪编成直接推断。

### 3.2 能量、冷却与施法

- 每场战斗初始能量为0，上限100；每次普攻基础获得20能量。速度提高意味着普攻与回能都更快，能量获取天赋和词条还会乘回能量。
- 技能同时受能量、冷却、控制状态与前摇约束；角色正在前摇时不能重复排入另一招。
- 普通技能默认前摇0.4秒，耗能至少60的大招默认0.5秒；怪物可配置更长、能看见的预兆。
- 在正式结算时扣能量并进入冷却。被控制等原因取消前摇时，当前逻辑不会把未结算招式当作成功施放。
- 托管按技能优先级和血线条件出招，未必能主动攒出理想连携，也不会替玩家处理地图机关。

基础普攻间隔约为`2秒÷生效速度`，按整数战斗步取整，最快受约0.333秒的下限限制。破军基础每秒约10能量，穿杨约12，霜语约9，晨星约9.5。低速职业既慢出伤害又慢攒大招，这是未来平衡时必须一起观察的因素。

### 3.3 伤害、治疗与状态

有效攻击为A，有效防御为D：

```text
普通伤害 = max(1, floor(A² / (8D + A)))
技能先把攻击乘技能系数，再代入这个公式；多段技能逐段结算。
暴击再乘暴伤，默认暴伤1.5倍。
治疗 = 最大生命×生命比例 + 攻击×治疗系数。
```

例如攻击100、防御50时伤害20；攻击提高到150时伤害约40。因此技能系数提高50%并不只增加50%伤害，攻防处于不同区间时收益不同。攻击、破甲、穿透和多段爆发的组合，需要用实际战斗评估。

护盾先吸收直伤，伙伴护卫再分担符合条件的重击，剩余部分扣生命。流血和中毒按施加时攻击快照、比例和层数逐步累计，通过直伤路径扣血；当前会绕过普通护盾、潜伏与护卫路径，但仍受无敌影响。不能把所有受伤都视作同一种伤害。

控制状态包括眩晕、恐惧、混乱等；控制抗性目前主要决定是否抵抗。减速降低普攻频率，也间接降低回能。首领低于30%生命时存在通用攻击狂暴，部分剧情首领还有独立阶段、召唤和反击窗口。

### 3.4 药剂、伙伴与退路

药剂回复最大生命的35%，每8秒最多使用一瓶；满血时拒绝使用，阵亡角色不能靠药剂复活。誓约可以小幅改变药效。常规出征基础带2瓶，最多补到4瓶，额外两瓶分别180金、300金；主世界还有场景补给与特定首领援助，应以当前道具页为准。

可带出战和替补伙伴，一场战斗只能换宠一次；换上的伙伴获得一次免死。角色倒下而伙伴仍存活时，战斗不立即判败，伙伴可能完成清场。

生命与药剂需要跨遭遇管理；能量、限时增益与战斗冷却在新战斗重建。撤退会保留战损与已完成进度，部分剧情首领禁止撤退。战斗模拟超过300秒判超时：PVE按失败处理，演武按未分胜负处理。

### 3.5 玩家值得手动做的事

先看预兆和首领阶段，提前处理破甲、护盾、净化或药剂；把高费爆发留给破绽窗口。主线机关往往能提供辅助条件，先完成机关再打首领，比在缺条件时反复硬打更有效。

当前四组连携均按实际技能结算顺序计时，中间插入其他招会改变上一招记录：

| 连携 | 时间窗 | 收益 |
|---|---:|---|
| 破阵 → 断罪 | 5秒 | 断罪额外增加1.0攻击系数 |
| 霜环 → 天陨 | 4秒 | 对符合减速条件的目标增加30%攻击系数倍率 |
| 祝祷 → 破晓 | 5秒 | 破晓治疗增加30% |
| 遁影 → 夺魄 | 3秒 | 夺魄额外增加0.5攻击系数 |

连携的前提是有足够能量连续释放。例如祝祷30、破晓60，两招要预留90能量；托管可能在攒够之前使用其他技能。

## 4. 怎么升级、怎么通关

### 4.1 主线优先，而非先刷到满级

每升一级基础生命增加40、攻击增加4、防御增加2、暴击增加0.1个百分点，基础速度不随等级增加。上限60级，升到下一等级所需经验为：

`floor(100×当前等级 + 2×5^(0.1×当前等级))`。

当前主线首通经验由`campaign_growth.json`覆盖原任务表的旧经验。36步合计356,012经验，仅完成主线就能达到60级；战斗、支线等额外经验可能使玩家提前升级。目标等级是**完成该步之后**的等级，不能用击败首领后发的经验去证明首领战前已经达到那个等级。

主线单独提供5,950金币，36条支线表合计6,995金币，战利、贸易和日常另算。经验成长较充足；材料、金币、装备是否及时穿戴，比“再刷几级”更容易成为玩家真正的问题。

### 4.2 第一幕：边城与失声碑窟，1～12级

路线：昭元边城 → 枫林古道 → 断碑坡 → 失声碑窟 → 回边城。

1. 找闻叔接线索，去古道处理路边残影，再回石头和闻叔处核对发现。
2. 完成s03后找岳教头学习第二招；真实使用产生效果后，再选第一组技能分支。
3. 完成s04后去兽栏与阿豆结缘岩龟。宠物并不会自动跟主人等级一起长，需要喂养。
4. 完成s06后去马厩领取首匹马；骑乘主要改善地图行走，同时激活坐骑有小幅战斗加成。
5. 找青姨得到碑窟线索，进入碑窟完成碑座机关，再击败失声守碑者。
6. s10领取碑鸣武器，回城修碑：锻合花2精炼石，拓录花120金；最后向闻叔报告，完成s12。

装备拿到后要在背包主动穿戴。s12还给碑鸣护甲。第一幕终点推荐碑鸣武器+2、护甲+1，这轮加工花600金、3强化石；不要在即将被替换的开局装备上过量强化。

### 4.3 第二幕：盐道与沉渊港，12～25级

路线：古道 → 旧盐道 → 沉渊港 → 潮痕滩 → 退潮水闸 → 回港。

核对盐车账页并交给沈澜，观察滩上的货箱，击败闸卫取线索，再解水闸机关、击败潮蚀司祭。s20回港选择先疏盐渠或加固堤道，该选择影响市场供应价格与商旅条件。

完成s12后、角色至少12级且满足前置授业条件，可以在导师处学习第三招。s19给潮关武器，s20给潮关护甲；它们是打完相应节点后的升级奖励。第二幕终点推荐新武器+3、新护甲+2，本轮花1,350金、5强化石。

港口可领取并孵化潮羽蛋，也有付费追加购买。第一只确定伙伴和主线装备足以支持推进，抽传说伙伴不是主线前置。

### 4.4 第三幕：商路、矿脉与雪幕，25～42级

路线：沉渊港 → 赤砂商路 → 霜关驿 → 裂谷矿道/矿脉 → 霜林栈道 → 冰隘 → 回驿。

把霜关来信交给宁砚，检查翻倒矿车，在矿脉完成环境机关并击败赤砂械卫；之后观察栈道双关讯号，到冰隘处理雪幕领主，回驿选择商货先行或守关补给。

第四招要求至少25级、完成s20和前置授业；第五招要求至少35级、完成s24和前置授业。授业也有金币与实效熟练门槛，不是达到等级自动获得全部招式。s24后可以在霜关训练伙伴护卫、追击和元素响应。

s25给霜关武器，s27给霜关护甲，s28给双关坠饰。第三幕终点推荐这三件分别+3、+3、+2，本轮加工花2,250金、8强化石。到s28三幕保底累计24强化石，这条三幕分轮加工路线合计花4,200金、16强化石。预算还需留出导师、修碑、买卖和药剂支出。

### 4.5 第四幕：归路碑篇收束，42～60级

路线：霜关 → 冰隘东口 → 渊口外环 → 回昭元找青姨 → 门厅 → 共鸣廊 → 碑心 → 回昭元找闻叔。

1. s29向宁砚问关外回声，才能通过冰隘东侧进入渊口。
2. 查看三地共鸣后回昭元交给青姨；s32选择聆听三声或先稳碑座，取得进入深处的凭证。
3. 在归路门厅先留下返程锚，随后校准林、潮、雪三声并完成封记。关卡状态满足后才能进入碑心。
4. s34获得三声护甲，推荐穿上并加工；s35击败渊脉化身后得到归路武器。
5. 带记录回闻叔处完成s36，才能正式结束主线，取得归路留声佩和通关后的回访内容。

最终首领战使用的是**此前得到的武器**；归路武器是胜利奖励。不能把s35奖励装备算进s35之前的必备战力。主线到60级后，经验不再提供进一步等级成长。

### 4.6 卡关时的排查顺序

先检查当前任务目标是否要求回城交付、特定怪或机关旗标；再检查新装备是否在待领区、是否穿错职业武器；再补导师授业、药剂与低阶确定强化。最后考虑少量清怪、支线或委托。主线通常不需要在旧地图漫长刷经验。

旧地图怪等级固定，玩家升级不会让它们同步变强，回访因此更轻松。常见普通怪约90～120秒刷新，前三幕部分剧情首领约24小时刷新，第四幕深处配置约10分钟；试炼复战另有规则，不能把刷新当成主线重复奖励。

## 5. 养成系统与投入优先级

| 系统 | 当前规则 | 玩家优先级 |
|---|---|---|
| 等级 | 主线足以到60；裸属性线性成长 | 按目标推进主线 |
| 天赋 | 每5级1点，满级12点；狂战、坚壁、迅捷三系，深层节点需本系投入 | 有点就安排；常见收益是攻击、防御、速度与回能 |
| 装备强化 | 每级基础属性+10%，最高+20；新装备不继承旧件强化 | 先保底装备+1～+3 |
| 宝石 | 攻击、防御、生命三类，各5级；通常每件3孔 | 有现成低阶宝石就用，避免早期大量合成 |
| 精炼 | 每件4词条；攻击/防御/生命比例、暴击、速度；锁词条用锁符 | 主线通关后再集中优化 |
| 技能研习 | 可研习技能最高10级，每级提高相应强度5%，1→10共2,460远征币 | 输出角色优先常用伤害招；晨星优先真正会用到的治疗/增益 |
| 导师分支 | 学招、产生真实效果、选择稳式或疾式等分支 | 与主线授业一起做；控制时长和研习强度是不同机制 |
| 伙伴 | 喂粮升级、资质影响成长、突破、进化、两槽训练特性 | 先固定一只常用伙伴，避免同时养满全部 |
| 坐骑 | 六类各两阶，只激活一只；首马可免费领取 | 首马优先，高价二阶放后期 |
| 称号 | 条件达成后领取/或荣誉购买，只佩戴一个生效 | 检查已达条件并主动领取、佩戴 |

强化目标+1～+3必成功；更高阶基础成功率为`0.9^目标等级`，每次失败再加15个百分点，失败扣钱扣石、不掉级，成功后清掉失败积累。+20基础成功率只有约12.2%，直接冲顶和保底+3不是同一个经济成本。每次金币成本为150加上当前强化级数×150，石料成本每5级阶梯增加。

镶嵌一颗花200金；三颗同级宝石加300金可合成高一级。攻击宝石五级数值3/6/10/15/21，防御2/4/7/11/16，生命25/50/85/130/190。精炼每次基础消耗2精炼石，锁住的每个词条还需要锁符。

宠物每份粮给100经验，下一级经验`50×当前宠物等级+30`，宠物等级不能超过主人。从1级养到60级要累计90,270宠物经验，约903份粮；如果全从物资铺90金一份购买，约81,270金。主线能把人物快速拉到60，但不会同步养满伙伴，宠物应该被视作长期投入。

资质1～5星对应每级成长倍率0.8～1.6；资质果可能洗低。突破最多5层，每层属性+8%，总需100突破晶、1,500魂晶。进化通常耗3进化晶石，当前伙伴模板提高主要战斗属性约25%，每只一次。护卫每战可分担一次重击的35%，伙伴自己承受伤害；追击和元素响应有12秒冷却，第二训练槽要求该伙伴已有3次参战胜利。

当前只对有明确强度收益的技能开放研习。战吼、遁影、净化保留基础功能与导师分支，不再收取无收益的升级费用。已有这些技能的旧研习投入在读取存档时退回，等级重置；其他辅助技能已获得真实强度成长。

## 6. 四种货币：赚什么、花在哪里

| 货币 | 主要实际来源 | 主要消耗 | 给玩家的用法 |
|---|---|---|---|
| 金币 | 主线/支线、野外战利、物资与装备出售、贸易、城镇活动 | 强化、镶嵌、材料、授业、补给、休息、坐骑等 | 保留通关所需加工与补给预算，再做可选大额消费 |
| 远征币 | 主题历练、路线与扫荡奖励 | 技能研习等历练成长出口 | 优先投常用技能；与金币分开规划 |
| 魂晶 | 历练精英/首领、部分事件与收集奖励 | 寻访、宠物突破、部分坐骑 | 先保证既有伙伴的成长，再考虑额外寻访 |
| 荣誉 | 演武连胜，也仍可从历练和扫荡得到 | 辅助材料兑换、称号、二阶坐骑等 | 当前不是独立竞技专属货币 |

货币表的“用途定位”比实际产出更严格：代码仍让历练产出魂晶和荣誉，部分坐骑也消费魂晶。因此文档按实际入账说明，不把描述中的分类误写成禁止跨系统产出。

物资铺买价/卖价：强化石120/48、精炼石260/104、宠物粮90/36、资质果420/168、进化晶石600/240。同店买进再卖出必亏。荣誉兑换当前可换强化石、精炼石、锁符和三阶攻击/生命宝石，没有四币之间的自由兑换。

装备背包容量60，满包奖励进入待领区，不应丢弃任务装备。出售前注意穿戴与锁定状态；主线保底的回收价较低，价值在稳定提供战力。

### 6.1 寻访与保底

灵宠寻访单抽80魂晶、十连720魂晶，每日一次免费；普通60%、稀有30%、史诗8%、传说2%，十连至少史诗，连续60抽未出史诗或传说时保底给其中一档，出史诗或传说会清零计数。**当前并不保证60抽必出传说。**重复伙伴当前转成金币：普通200、稀有600、史诗1,500、传说4,000，**并非转成魂晶**。

保底和免费次数存档。联网后这些计数必须由服务器管理，不能沿用可编辑本地文件或客户端日期。

### 6.2 当前演武场怎么玩

现在演武场是本地傀儡/镜影训练，不连接其他玩家。可以更换对手等级，玩家带伙伴和2瓶药剂进行战斗。初始段位分1,000，胜利基础加18～26分，失败减12分、最低不低于0；连胜从第二胜开始每场额外加2分，最多额外10分，每3连胜给40荣誉。平局或主动退出不改变段位分，也不按失败清掉连胜。

段位门槛：铜印0、银印1,200、金印1,400、铂印1,600、钻印1,800。当前没有联网匹配、其他玩家排行、赛季结算或对战真实性校验。荣誉兑换与段位分是两套数值，花荣誉不会直接扣段位分。

### 6.3 城镇活动与两种“天”

签到基础60金/30经验，连续签到从第二天起额外20金/10经验；征收每4小时120金/20经验；操练每小时45经验；巡城每2小时45金/15经验；宴会每4小时花200金换160经验。签到需要祭坛，当前祭坛建设要求3级、260金、20魂晶。

城镇冷却、每日免费等使用现实时间；市场、订单、钓鱼等使用经济日。经济日主要通过休息推进，休息配置22金。不是每过24小时所有系统都统一刷新。当前日期实现还存在UTC日期键与本地日期键混用的风险；中国玩家未来应统一到明确的北京时间刷新规则。

活动入口已有配置读取和界面，但`activities.json.events`当前为空，所以没有已配置的限时活动。不能把入口当成已经存在的活动内容。

## 7. 贸易、邮路、钓鱼和通关后的生活

贸易提供独立金币玩法：谷物、盐、药草、铁料在五个市场拥有不同价格、每日库存与需求。基础载重上限28，铁料每件重2，其他每件重1。买价取市场中间价的110%，卖价取88%再减搬运费，价格还受经济日波动和主线修路选择影响。

玩家应看“能赚多少净利润”，而不是只看高卖价：购货、运费、休息、押金、保险和延期都会占本金。本地同市场往返不能凭空赚钱；跨地图价格差与订单才是收益来源。

目前存在几类不同业务：

- 第一幕断碑坡补给订单，先完成盐包相关支线；路桥选择可降低运费。
- s16后港口船运，备舱与沿岸药粮有到货日、期限与沿路援助。
- s28后霜关缺药订单，有押金、快路/安全路、保险、延期、放弃退款与宽限结算。
- 可重复商约：s20后盐铁、s28后粮箱。基础押金60；保险费8、基础利润25，自担风险基础利润55，阻碍可能损失25；通常3个经济日到期，可花12金延2日。到手额可能含退回押金和货值，不能全部算利润。
- s28后归路邮驿，接信、找沿途线索、选路线、交付再返回结算。

四个钓点分别在旧盐道、港口、潮痕滩和霜关；每个钓点每经济日3次机会，开始时即占次数，成功给鱼与发现记录，鱼可加工成宠物粮。鱼王按经济日周期出现，需要更准确的操作。钓鱼既提供收集，也提供小量、稳定伙伴培养材料。

三城巡界委托分别在s04、s13、s21后开放，每城每天提供两条公告，完成后交付；过日时已有未完成委托保留。目标包含检查、护送、修路和战斗，修理消耗到现场才扣。另有三种誓约，在s12后三城选择，影响随后尚未锁定誓约的地图行程：庇护重防守，征伐重攻击，丰收换取培养材料。

特色试炼在对应主线首领处理后开放：碑窟声纹、潮闸接应、矿脉无药复战。首次记录通常给2强化石与图志记录，重复挑战以练习为主，不重复发首通奖励。

通关后可做三城回访、归路托付、补图志、委托、贸易、邮路、钓鱼和营地故事；也可推进剩余历练主题与长期养成。主线结局已经完成，但仍有收集与重复内容。

## 8. 历练怎么打、有什么收益

每局生成3层，每层3选1，再打终点首领。生成规则保证第二层有精英选项、路线图有事件和商店；它保证的是**选项存在**，并不强制玩家把它们都选中。

普通、精英、首领与宝箱可提供局内词条选择，次数分别1/2/3/1。局内同流派通常凑2个词条即可激活流派；这些构筑保留本局，回城后不永久保存为人物被动。篝火回复40%生命并提供调整词条机会，事件常在休整和伤血换资源之间选择。

| 奖励节点 | 金币 | 远征币 | 魂晶 | 经验 | 荣誉 |
|---|---:|---:|---:|---:|---:|
| 普通 | 120 | 20 | 0 | 60 | 1 |
| 精英 | 300 | 45 | 5 | 140 | 3 |
| 首领 | 800 | 120 | 15 | 300 | 15 |
| 宝箱 | 200 | 30 | 0 | 30 | 0 |
| 清图额外奖励 | 260 | 40 | 0 | 110 | 2 |

实际一局收入还受到路径、地图多只怪、探索拾取和事件影响，这张表不能直接相加作为固定每局收入。失败或撤离仍保留已获得收益，出征前购买的补给则已经支出。

历练敌人层数倍率为`1+0.12×层数`；苦行再让敌方全属性×1.15、节点收益×1.30。敌方攻击与防御一起提高，实际难度不会只提高15%。已通关主题可用1张扫荡券，按标准奖励计划的70%折算，扫荡不吃苦行收益。

当前主题顺序为苍绿林海、凛风雪原、焚天火山、幽暗古墓、流沙荒漠、千年冰川、无底深渊、王城遗迹。雪原周期减速、火山周期灼烧、深渊缩小探索揭示范围；并非八个主题都已经有同样丰富的独立环境机制。

## 11. 仍然需要设计决定的失衡与缺口

这些问题已确认有依据，但本次保留现有规则，避免在没有体验目标时一次改变整条成长线：

1. **主线成长节奏很快，伙伴成长很慢。** 主线可直接60级，宠物喂满却需要约903粮；玩家可能误以为伙伴没有成长。建议在界面明确伙伴等级，并补稳定任务粮、参战经验或阶段追赶，先定目标再改经济。
2. **主线首领压力偏轻。** 单场保底装备与1级伙伴样本多有高剩余生命。建议先增加可读预兆、必须处理的阶段与可选挑战；如果只是全属性一起上调，可能破坏普通玩家通关。
3. **职业收益不同。** 穿杨速度高，出伤害、回能一起占优；晨星升伤害书的收益结构与治疗不同。主线可通不等于未来PVP公平。
4. **攻击与百分比词条有非线性收益。** 高阶强化、多个精炼词条、技能等级、暴击和破甲一起叠加，很容易使高投入输出与低投入生存拉开差距。
5. **荣誉仍能在PVE获取并买战力。** 如果以后把它当排位成绩货币，现有历练、扫荡和坐骑/称号出口会冲淡竞技含义。
6. **演武并非真实玩家镜像对局。** 镜影作为怪物使用技能，不遵循角色耗能与同一托管决策；玩家还带宠物、药剂，镜影有90%生命等训练偏置。它只能当本地演练，不能直接改名为公平PVP。
7. **主题差异和结局文本尚未完全统一。** 八主题环境机制稀疏，部分图志仍使用旧八碑终局目标，应继续做内容与文本对齐。
8. **时间和存档仍在客户端。** 本地时间前跳、日期口径混用、可编辑金币与奖励状态，在单机可接受，联网必须改为服务端权威。

## 12. 未来联机：先确定玩法，再制定平衡

建议按“好友协作探索 → 组队特色副本 → 独立公平演武 → 长期赛季”推进。先做合作更能承接当前世界：护送、核账、接应、试炼和首领分工都已有基础。跨玩家交易、排行榜和付费经济应在奖励权威与反作弊完成后开放。

不要直接复制当前单人角色与宠物数量到多人房间。队伍中有治疗、护盾、分担、召唤时，实际战力不是人数乘单人战力；以下都是**建议起点**，需要新测试数据校准。

### 12.1 合作PVE数值起点

| 项目 | 建议第一版 |
|---|---|
| 队伍规模 | 先2人，再3～4人；每人最多1出战伙伴 |
| 首领生命 | 以单人基准H为准：2人1.8H，3人2.6H，4人3.4H |
| 首领普通伤害 | 目标最终承伤分别为单人1.05/1.10/1.15倍；按伤害公式反求攻击，不能直接把攻击也乘生命倍率 |
| 群体攻击 | 依人数增加覆盖和目标选择，预兆给足反应时间；先控制总伤害预算 |
| 人数中途变化 | 开战时锁定难度；离队不即时降血、不重发奖励 |
| 强弱组队 | 高等级玩家临时同步到副本等级与装备预算；保留选择和操作差异 |
| 通关时长 | 初始目标：普通遭遇10～25秒，精英30～75秒，首领60～120秒 |
| 普通副本成功率 | 适配装备的新手组首通目标70%～90%；熟练组90%以上；自愿挑战单独分档 |

共享技能中的百分比治疗必须用同步后的最大生命，不能用局外真实高等级生命跨级治疗。盾量叠加与群体治疗须设多人专用上限，避免两个辅助轮流堆永久盾。

建议多人护盾总池初始上限为目标最大生命的35%，同类攻击增益取最强，多个免死来源一段时间内只能触发一次。复活先做每场有限次数、需要读条和团队资源的救援。具体值先放独立多人配置，不改坏单机已有成长。

### 12.2 公平PVP与成长玩法分开

首版排位建议统一60级基准与固定装备预算：装备强化、宝石、精炼、资质、抽奖稀有度、坐骑和称号的局外战力不直接带入。角色、技能分支与伙伴用赛场模板保留选择，外观与收集继续有价值。

PVP初始规则建议：

- 禁止治疗药剂，取消随机强化与稀有度带来的战力；所有玩家使用统一技能研习等级。
- 治疗系数先按PVE的65%作为试算起点，治疗不能暴击；护盾上限为目标最大生命30%，无敌先试0.75秒，免死每人每场一次。它们都需要对局复测后再定稿。
- 重复硬控制尝试100%/50%/25%时长，短期连续受控后给免控窗口；不要只靠概率抗性解决无限连控。
- 1v1主要按单体贡献平衡；队伍PVP另外观察治疗、减伤、救援和集火贡献。晨星的单刷补偿系数在队伍赛应单独调，不默认照搬。
- 第一阶段不加入局内随机三选一词条，减少不可控组合；娱乐模式可另设构筑规则。
- 对等水平与配置的职业胜率先以45%～55%作为警戒带，长期偏离再调整；观察对战矩阵，不能只看全服总胜率。

建议先用固定生存与伤害预算验证20～45秒的主要交战时间，再看是否符合游戏节奏。过短无法体现前摇、净化和连携，过长可能让辅助无休止互奶。这些时间是设计目标，不是已经验证的联网指标。

如果以后确实要做保留成长的自由切磋，应把它列为另一个模式，按实际有效战力段匹配，限制等级差与装备差，并对奖励单独限额。

### 12.3 联机经济和奖励

经验、金币与材料按玩家独立结算；队伍贡献认输出、有效治疗、护盾吸收、承伤、机关和任务行动，不能仅用最后一击。满血空奶、超杀虚报伤害不算贡献。本次超杀修复已经为这个口径打下基础。

每日首通/周奖励/免费寻访全部由服务器发放并记录唯一凭据；断线重连只能补发同一笔，不重新结算。多人奖励可以在单人基准的1.0～1.1倍/人起测，先计入平均耗时和失败成本，不机械地随队伍人数再翻倍。

货币建议保持金币用于生活与加工、远征币用于历练成长、魂晶用于伙伴；新增或拆分排位专用荣誉，主要兑换外观和赛季纪念。旧单机荣誉保留为旧体系资源，不自动转换成排位货币。公平排位的胜率不能由多花荣誉买属性来决定。

普通在线PVE账号不导入本地金币、存档道具和抽奖保底。若需要继承单机经历，可以继承非交易外观或已完成剧情标签，并由服务端验证明确规则。

### 12.4 技术边界与发布门槛

现有30步/秒、独立战斗模拟与种子随机适合做联机基础，但当前还不是完整联网协议。建议服务器决定战斗结果与奖励，客户端发送技能、目标、用药等意图，服务端检查角色归属、能量、冷却、距离/目标和当前状态。

需要补齐：多个角色的阵营/主人关系、伙伴归属、治疗目标、集火、队伍胜负、断线快照与恢复。目前很多接口仍假设唯一主角，不能只把第二个角色加入数组就算完成组队。

当前状态哈希只覆盖少量生命、能量、单位和时间信息，未完整覆盖随机源状态、增益、施法队列、阶段标记与技能冷却；跨机器确定性也不能只凭同机测试宣称成立。多人发布前要验证完整状态回放、网络延迟、丢包、重复指令与不同设备计算一致性。

上线门槛应包括：同一奖励至少重复上报100次仍只到账一次；断线前后恢复相同战斗状态；客户端修改时间不能多领；队伍离开/重入不能刷新难度或奖励；低投入与高投入模板都进入同一场公平排位预算。

## 13. 后续调数应记录哪些证据

每种职业、等级段、装备预算、伙伴配置与操作模式，至少记录胜率、中位/P90战斗时长、剩余生命、药剂消耗、技能频率、有效治疗、护盾吸收、控制时长和奖励净收益。固定种子复测，同时增加真人样本，避免只优化托管。

每次只改变一组可解释参数。先保证通关与资源足够，再提升阶段互动；PVP先保证模板预算一致，再调职业差异。回归验证证明逻辑正确，真人数据才决定玩法是否好玩。
