# 《远征》主页人物 · 10 秒入场演出

目标改为帅气、有起承转合的角色亮相。每个职业独立生成一条约 10 秒的入场视频，包含抬眸、真实踏步、武器展示、一个招牌动作和收势。前 8 秒完成演出，最后 2 秒稳定在可衔接主页待机的姿势。

入场只播放一次，随后切到待机，不把 10 秒亮相不停循环。原来的四职业待机提示词保留在 [6秒待机提示词（备用）.md](6秒待机提示词（备用）.md)。

## 怎么生成

1. 上传对应角色的单张参考图，用作图生视频的角色与造型依据。
2. 复制对应职业的完整提示词，时长设置为 10 秒左右，每个职业独立生成。
3. 若平台支持单独指定尾帧，可把对应参考图用作收势目标；否则通过提示词要求最后两秒回到参考站姿。
4. 精彩程度通过蓄力与释放、武器动作、发梢与衣摆的惯性和局部效果体现，镜头保持固定。
5. 下载原始 MP4，保留实际分辨率与帧率信息；不要录屏或先转 GIF。

## 统一规格

| 项目 | 要求 |
| --- | --- |
| 时长 | 约 10 秒，完整动作一次完成；8–10 秒收势后轻微呼吸 |
| 画幅 | 1:1，优先 1024×1024 或 1080×1080 |
| 帧率 | 优先 24 FPS；若只能输出 30 FPS，四个职业统一 30 FPS |
| 镜头 | 单镜头、固定机位、固定比例，沿用参考图视角；全身和完整武器始终可见 |
| 背景 | 均匀纯品红 #FF00FF；支持真正透明视频时可交透明版本 |
| 空间 | 为挥剑、提枪、举杖和披风预留边界，动作全过程不得裁切人物或武器 |
| 脚步 | 可以真实迈出一小步，脚掌落地有重量，不滑步，不长距离移动 |
| 造型 | 保留脸型、头身比、服装、配饰、主色与武器；持握手不改变，武器刚性稳定 |
| 美术 | 精致像素奇幻，清楚的像素簇、阶梯轮廓与稳定明暗，不转成写实或 3D 渲染 |
| 动作 | 先蓄力后释放，有快慢、有停顿，衣摆与发梢延迟跟随，不做机械匀速摆动 |
| 特效 | 每个职业一个局部效果，清楚的实色像素形状，不铺满画面、不盖脸、不画地面法阵 |
| 结尾 | 第 8 秒前回到参考图所示持械站姿；最后两秒稳定，仅轻微呼吸 |
| 其他 | 无地面、投影、环境、背景渐变或反光；无字幕、水印和对白 |

纯色背景用于后续抠图，不会保留在游戏内。投影与环境氛围由游戏统一处理。特效避免大片半透明烟雾和漫射光晕，减少抠图后残边。

## 生成后怎么选

- 先检查脸、手、服装和武器是否从头到尾一致，再看动作是否帅气。
- 检查脚步有没有真实落地，蓄力、释放和收势能否读清，衣摆是否自然延迟跟随。
- 缩小到主页实际显示尺寸，检查姿态和局部特效是否仍清楚，不能只挑中间最惊艳的一帧。
- 检查第 8 秒前是否已收回参考站姿，最后两秒没有突然变化、裁切或滑动。
- 背景必须均匀，没有残留地面、投影、品红反光或水印。
- 首次每个职业生成 1–2 个版本，以动作完整、造型稳定的版本优先。
