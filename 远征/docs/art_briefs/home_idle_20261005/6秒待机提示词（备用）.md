# 《远征》主页人物视频生成规范与提示词

目标：为四个职业生成精致、安静、有生命感的主页待机动画，延续现有像素奇幻美术。先生成四条基础待机视频，通过后再做四条偶发小动作。每个职业单独一个文件，不在同一条视频里换人、转方向或换动作类型。

当前主页使用 128×128 的四帧序列，以 5 FPS 循环，一轮 0.8 秒，并放大两倍显示。新素材接入时需要同时调整帧数、时长和播放节奏。只换图片、沿用四帧循环仍会丢失新视频的大部分动作。

## 生成操作

1. 使用图生视频，将对应职业的单张参考图作为角色依据；不要上传四格序列图或整个主页截图。
2. 下方四条基础提示词可分别完整复制。平台有独立负面提示词栏时，使用末尾的统一负面词。
3. 如果支持指定首帧与尾帧，两者使用同一张参考图。循环接缝仍以实际生成结果验收。
4. 下载原始视频，避免录屏、聊天软件二次压缩或先转 GIF。

## 统一交付规格

| 项目 | 要求 |
| --- | --- |
| 视频 | 单个角色、单个固定视角、单镜头 |
| 基础待机 | 每条 6 秒，首尾姿态和动作相位能自然衔接 |
| 画幅 | 1:1，优先 1024×1024 或 1080×1080；平台只能输出其他尺寸时保持方画幅 |
| 帧率 | 优先 24 FPS；若只能选 30 FPS，四个职业统一使用 30 FPS |
| 背景 | 均匀纯品红 #FF00FF；不加地面、投影、渐变、背景反光。支持真正透明视频输出时也可交透明版本 |
| 镜头 | 与参考图一致；锁定机位、缩放、透视和构图，不推进、旋转或变焦 |
| 构图 | 全身居中，参考图所示朝向；双脚、发梢和完整武器始终在画面内；脚底约在画面高度 86% |
| 安全边界 | 左右、头顶和脚底留白；连武器在内的轮廓宽度不超过画面约 80% |
| 动作 | 双脚不移位；上身呼吸位移不超过角色身高约 1%；发梢和衣摆小幅摆动 |
| 光照 | 固定左上方柔和主光；保留明暗层次；不让曝光随时间闪烁 |
| 风格 | 清楚的像素簇与阶梯轮廓；保留头身比、脸型、服装、武器、配饰和主色；减少细碎噪点 |
| 特效 | 基础待机不带烟雾、散射粒子、地面法阵或大面积光晕；晶石或武器仅可内部轻微明暗变化 |
| 声音 | 无音轨或静音；不要对白、字幕、文字和水印 |

数值作为构图与动作的约束目标，不要求通过挤压或拉伸人物来硬凑。长枪完整可见优先于机械套用留白比例。

## 收片与接入检查

- 从头到尾检查脸、手、装备和武器，不能只看开头一帧。
- 检查双脚位置、人物比例与完整轮廓，确认没有裁掉发梢或武器尖端。
- 连续播放两遍，检查首尾是否跳动、衣摆是否突然换方向、晶石是否突然变亮。
- 检查背景是否真正均匀、有没有染到白发或银色武器上。
- 不合格版本保留但不要混进正式交付；通过版本用上述职业与动作命名，备注分辨率、帧率、时长。

后续将基础视频抽帧、去纯色背景、统一人物比例与脚底基线，接入专用于主页的 SpriteFrames。保留世界行走动画；待机循环和偶发小动作分别配置播放。先保留连续动作，再按实际显示效果决定抽帧密度和播放速度，避免再次压成四帧快循环。
