## 实际修改

InventoryQuestSkin.gd 是背包与任务页共用的局部皮肤。木质标题、暗铁卡片、纸面详情、青玉按钮和物品格使用同一素材体系；像素素材以最近邻采样，文字保留平滑采样以保证中文可读。

BagPanel.gd 保留五列格子及装备、材料、宝石、待领取四个分类。状态不同，详情区高度随之调整；待领取空状态居中展示透明宝箱。装备比较、镶嵌孔、锁定、卖出、卸下和领取继续使用现有接口。

QuestPanel.gd 使用容器布局。主线、委托目标、发布人、状态、奖励、接取与交付各自有独立位置；委托区支持滚动，返回按钮固定可见。长屏上居中显示卷宗，移动安全区域及键盘焦点均纳入验证。
