### 顺带修掉的两个真实缺陷（因为判定变严才浮出来）

1. **`G._veil_viewport_size()` 在节点未入树时刷 7 条引擎错误。** 父级还没 `add_child` 就调 `parent.get_tree()`，Godot 4.7 直接报 `ERROR: Parameter "data.tree" is null. at: get_tree (scene/main/node.h:559)`，并打出完整 GDScript 回溯（`TraitPicker.setup` → `MapScene._after_battle_rewards`）。已改为先 `is_inside_tree()` 再取树，拿不到就退回 480×800 基准。
2. **非法存档码会刷引擎红字。** `SettingsPanel.do_import` / `G._load_save` 用 `JSON.parse_string`，解析失败时引擎自己 push 一条 `Parse JSON failed`。玩家粘贴一段乱码就会看到报错。新增 `G.json_parse_silent()`（`JSON.new().parse()`，失败返回 `null`），这两处改走静默解析，由业务层给人类可读提示。

### 本轮新增可体验内容：演武场「连胜之证」

演武场此前赢了只有段位分，**没有任何可花的产出**，连胜也无人记录。现在：

- 连胜计数：胜 +1、败清零；**平局与撤退不清零**（沿用口径 D3，不退切磋还能保住连胜）。
- 每满 `step`（默认 3）连胜，额外发放荣誉（默认 +40），并按连胜长度给段位分加成（每级 +2，封顶 +10）。
- 面板新增「连胜 N · 最佳 M」一行 + 奖励口径说明；触发里程碑时播放 `reward` 音效并弹「N 连胜！额外荣誉 +40」。
- 数值全部落在**新增数据表 `data/arena.json`**（连胜步长/荣誉/加成/段位阈值），代码不写死；`G.arena_rank()` 也改为读表，段位阈值调整不再动代码。
