# 游戏素材像素网格处理记录（2026-10-03）

项目共有 1,252 张 PNG。本次逐一清点后，将 732 张当前运行时素材纳入处理范围；520 张旧版地图、替代角色图、总览/QA 图和已有成品对应的生成母稿不参与游戏导入。字体与文字标识也保持原始清晰度。

运行时素材中，575 张原本就在小尺寸像素格上，或属于已校准帧坐标的角色行走图，保持原样。157 张较大的背景、场景、立绘和坐骑进入候选集。质量门槛在接近 480×800 的显示尺寸比较处理前后画面，8 张世界场景图因细节损失过大而恢复原图，7 张候选图本来已经符合处理结果，最终 142 张 PNG 更新。

处理器为开源 Pillow，入口是 `python tools/pixelize_game_assets.py`。默认只生成前后对比图和清单，`--apply` 才会覆盖素材。流程先以 BOX 缩为 2×2 源像素对应 1 个逻辑像素，再无抖动限色到 192 或 256 色，最后以最近邻恢复原画布尺寸。每张图的像素尺寸和完整 alpha 通道逐位保留，动画图集坐标不会移动。脚本固定读取转换前的 Git 提交 `fd7cefde640944a0f2aaf507de5ad78d38505302`，重复运行不会累计模糊；新增素材需要先建立新的原图基线。

审阅输出在 `D:\new bee\pixel_audit`，其中 `report.json` 列出所有已处理、保留和质量拒绝的图片，并包含对比图及 480×800 游戏截图。实测 142 张修改图的尺寸和 alpha 均与原图一致；二次运行写入 0 张。Godot 4.7.2 已重新导入素材，完整回归为 52/52 通过。主世界、战斗和标题画面已实图检查。独立截图进程仍有现存的 Windows 根证书读取和退出时资源泄漏告警，未出现运行时脚本错误。

所用开源工具与参考项目：[Pillow](https://github.com/python-pillow/Pillow)、[Pixel Game Kit](https://github.com/kenyonxu/pixel-game-kit)。Pixel Game Kit 的网格重对齐思路适合后续专项修复 AI 伪像素图；本次没有安装或运行该项目，实际转换全部由仓库中的 Pillow 脚本执行。
