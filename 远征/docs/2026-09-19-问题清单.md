## P0 — 硬伤（8 条）

### P0-1 撤离后重进同一节点 = 无限刷资源（经济闭环被击穿）
- **证据**：地图种子只由 `run_seed + layer*10 + index` 决定（`src/explore/MapScene.gd:98`），重进必得同一批怪；每次战斗胜利都重发奖励与掉落（`MapScene.gd:1356-1357` 战利+掉落、`1370-1371` 清剿赏、`1284-1289` 评价赏、`1360` 委托进度）；「撤离」只退节点、不结算、不标 cleared（`src/run/RouteScene.gd:325-329`，仅 cleared 禁重进 `RouteScene.gd:300-301`）；材料掉落入包即落档（`src/autoload/G.gd:96-98`）。
- **影响**：首领节点每轮约 800 金 + 15 魂石 + 300 经验；普通节点穷尽一轮约 1000 金 + 350 经验 + 材料。零风险无限刷，抽卡/养成/扫荡的经济口径全部失效。
- **建议**：`RunState` 增加「本节点已结算」标记（重进保留地图与怪、奖励只发首次）；或按设计文 §2.7「撤离=走出本局」定稿——两条路线二选一并与文档同步。

### P0-2 战斗中「撤退」= 整局判负
- **证据**：二次确认后直接 `sim.finished=true; sim.result="defeat"`（`src/battle/BattleScene.gd:688-694`），而按钮注释写「放弃本节点」；`MapScene` 收到非 victory 即结束整局（`src/explore/MapScene.gd:1351-1355`）。
- **影响**：低血提示写「补药或撤退」，玩家以为只退本节点，实际整局远征结束；与地图「撤离」（退节点、局继续）语义正好相反。
- **建议**：撤退改走「退出本节点」（exited 语义），或把按钮/提示改为「放弃远征」；两处按钮语义统一。

### P0-3 存档导入不生效，且随后被旧内存覆盖（备份功能反而毁档）
- **证据**：`do_import` 只写盘（`src/ui/SettingsPanel.gd:441-452`），成功后 `reload_current_scene()`（`SettingsPanel.gd:499`）；而 G 是 autoload，`_load_save()` 只在启动时执行一次（`src/autoload/G.gd:228`），之后任意一次 `save_game()`（`G.gd:380-408`）都用旧内存态覆盖刚导入的文件。
- **影响**：玩家看不到导入的数值；随后任意入账（兑换/扫荡/升级）即把导入档覆盖——「导出备份」变成「覆盖备份」。
- **建议**：新增 `G.reload_save()`（重读盘并重建全部内存态），导入成功后显式调用再回标题；`VerifyPanels` 补「导入后内存态 = 文件态」断言。

### P0-4 「重置存档」重置不干净
- **证据**：`gm_reset_save()` 只重建 `prog` 与 `wallet`（`src/autoload/G.gd:2053-2060`），而 `save_game()` 会把 items（含抽卡保底 `gacha_pity`）、city（建筑/访客/活动）、quest（委托）、arena（段位分）、account/昵称/头像原样写回新档。
- **影响**：重置后仍持有保底计数、道具、已建建筑、今日委托、段位分——等于没重置；`tools/VerifyPanels.gd:176-183` 只断言了 honor，漏测其余字段。
- **建议**：按默认字典一并重建 `items/city/quest/arena`，明确 `account/avatar` 是否保留，并补断言。

### P0-5 宴会（feast）无冷却，可无限领
- **证据**：`data/city.json:135-137` feast `cd:0` 且非 daily → `activity_left()` 对 `cd<=0` 直接返回 0（`src/autoload/G.gd:768-770`）→ 只要金币够就能连续领：200 金换 160 经验。
- **影响**：等级曲线可被金币直接绕过；与布告板「冷却好了来领」的口径不符。
- **建议**：给 feast 加 cd 或每日次数上限；`activity_left` 对「cd<=0」显式区分「无冷却」与「无限次」。

### P0-6 吸血（lifesteal）方向反了
- **证据**：受击结算里读的是**受击方自己**的 lifesteal，然后治疗**攻击方**（`src/combat/Combatant.gd:244-246`）；来源：精英词缀（`src/combat/BattleSim.gd:238`，20%）与首领吸血技（`data/monsters.json:52`，50%）。
- **影响**：带吸血的敌人被玩家打时，**玩家按伤害的百分比回血、敌人 0 回复**；反之敌人打玩家不回血。任何战力评估都会被这行代码误导。
- **建议**：改读 `src.buff_pct_sum("lifesteal")`（与同段 `thorns` 的正确写法对齐，`Combatant.gd:238-242`）。

### P0-7 双刃词条数值错配：「燃血」+35% ATK 从未生效，「薄甲」白拿 +5%
- **证据**：`src/combat/TraitSystem.gd:56-57` 硬编码「薄甲 +0.35」（表值 0.30，`data/traits.json:88-89`）；而「燃血」的 `atk_pct:0.35`（`data/traits.json:85-87`）没有代码读取（`_sum_stat("atk")` 只认 `effect.stat=="atk"`，`TraitSystem.gd:41-48`）。
- **影响**：双刃池里燃血=纯负面（掉血但没加攻），薄甲比描述还多 5%。
- **建议**：两处都从 `_effect_of("de_ranxue"/"de_baojia")` 读 `atk_pct`，删除硬编码。

### P0-8 BOSS「召唤狼群」是死技能
- **证据**：数据把召唤写进 `target:"summon"` 字段（`data/monsters.json:16-17`，无 `effect` 字段），而代码只在 `effect.type=="summon"` 时召唤（`src/combat/SkillSystem.gd:159-162`）；`_pick_targets` 无 summon 分支 → targets 为空 → 直接 return（`SkillSystem.gd:108-110`）。
- **影响**：森林之主每 30 秒放一次「空招」（还照扣 CD）；`BattleSim.summon_monsters`（`BattleSim.gd:414`）正式玩法不可达，仅测试脚本调用。
- **建议**：数据改 `effect:{"type":"summon"}` 或代码兼容 `target=="summon"`。

## P1 — 重要（玩法与体验，15 条）

### P1-1 每日免费抽未实现；抽奖系统与设计 §4 系统性偏离
- **证据**：设计 §4.2 要求「每日免费 1 抽（零点刷新）+ 连 7 天送魂石×50」——全仓搜「免费抽 / daily_free」0 命中；`data/gacha.json` 单池（80/800 无 9 折）、保底 60 单计数（设计：20 保紫、60 保金）、十连保底是「至少蓝」非「至少紫」（`src/ui/GachaPanel.gd:906-918`）、无抽奖历史 100 条、池产物只有宠物（无技能书/资质果/宠物粮）。
- **影响**：每日回访少一个主钩子（只剩签到）；装备秘库缺位 → 装备获取断链（见 P1-2）。
- **建议**：抽奖数据结构升级为设计 §4.4 的 `pools[]`；先补「每日免费 1 抽」与抽奖历史。

### P1-2 装备系统只有「强化」半边：获取三渠道全缺 + 外观 3 阶未接
- **证据**：精英/首领掉落只有材料（`data/drops.json:4-18`）；无装备秘库、无商店（锻造铺 `soon`，`data/city.json:53-56`）；装备槽 0 级即吃基础属性、无装备实例/背包（`src/autoload/G.gd:1038-1050, 1111-1121`）；`data/growth.json:7` `equip_visual_tiers` 全仓 0 消费。
- **影响**：「打装备」正反馈缺失；外观升阶是纯承诺。
- **建议**：至少补「BOSS 掉装备 + 一个金币商店入口」；或从设计文降级该承诺。

### P1-3 宠物养成缺 3 环：进化 / 吞噬 / 宠物技能书
- **证据**：全仓搜 `evolve|devour|pet_book` 0 实现；`data/pets.json` 8 条 `evolve_to:"pet_*_evo"` 全部悬空（无对应条目、无读取）；进化/技能书素材（`itm_evolve_crystal` 等）0 引用；`skillbook.json` 是人物技能表，与宠物无关。
- **影响**：宠物玩法停在数值三件套，与「抽奖主出口」定位不符。
- **建议**：优先做「进化」（素材与字段已备），或先删 `evolve_to` 消除误导。

### P1-4 深渊/无尽缺失；PVP 除演武场全线未做
- **证据**：设计阶段 4.1/5 未落地；`data/monsters.json:99-101` `mon_boss_endless` 是孤立条目（0 引用）；演武场只有傀儡/镜影切磋与段位分（`src/ui/ArenaPanel.gd`），无 ELO 匹配/锁步/赛季/荣誉结算（设计 §7.5）。
- **影响**：单机闭环缺终点内容；荣誉第二出口缺位。
- **建议**：排期二选一先做（建议深渊：直接复用现有主题与层数系统）。

### P1-5 连败保底礼包未实现（世界链卡关无兜底）
- **证据**：设计 §6/§12 的「连续失败 3 次送魂石×30 + 宠物粮×5」全仓 0 实现（搜 `连败 / fail_streak` 0 命中）。
- **影响**：世界逐个解锁 + 战力断层时没有减压阀。
- **建议**：`RouteScene/RunState` 记连败计数，3 连败在结算页发礼包。

### P1-6 篝火/药剂治疗夹到「错误上限」——回血节点反而掉血
- **证据**：`RunState.max_hp()` 只算角色+词条、不含局外成长（`src/run/RunState.gd:77-80`），而战斗血上限含天赋/装备/坐骑/称号加成（`src/combat/BattleSim.gd:83-87`）；`heal()` 用 `mini(cap, ...)` 夹紧（`RunState.gd:145-149`）→ 带养成的角色点篝火（`src/explore/MapScene.gd:606-615`）可能被削到低上限。
- **影响**：越强越容易「回血掉血」；地图血条比例也会 >100%。
- **建议**：`max_hp()` 叠加 `G.growth_bonuses`（与战斗同口径），或 `heal()` 只加不夹。

### P1-7 空目标技能照扣能量与 CD（front_all 空放）
- **证据**：`resolve_cast` 先扣能量/写 CD（`src/combat/SkillSystem.gd:44-52`）再 `_apply_skill`，而 targets 为空即 return（`SkillSystem.gd:108-110`）。`enemy_front_all` 类技能（回风斩/震地/劈砍）在对方前排死光或全远程阵容时 100% 空放。
- **影响**：玩家/AI 白付能量与前摇；演武场傀儡唯一技对远程角色完全空转。
- **建议**：结算前判 targets，空则回退最低血单体（普攻已有同款回退，`src/combat/Combatant.gd:326-331`）。

### P1-8 演武场傀儡数值过肥 + 超时判负
- **证据**：1 级傀儡 520 血 / 20 攻 / boss AI（`src/autoload/G.gd:2740-2751`），对 1 级角色（约 130 血，`data/roles.json`）；战斗 300s 超时直接判负（`src/combat/BattleSim.gd:380-383`）。
- **影响**：新号切磋大概率超时吃「负 -12」；体验是「必输的桩」。
- **建议**：傀儡血量按玩家面板比例生成（或基准降到 150-200）；超时改平局不计负。

### P1-9 自动前往 + 托管 = 近乎全程挂机；开战不打断自动前往
- **证据**：`_auto_walk` 只在手动推杆时停（`src/explore/MapScene.gd:807-810`），开战/战斗结束都不改 `_auto_walk`（`MapScene.gd:1294-1312, 1343-1388`）；战斗自带托管（`src/battle/BattleScene.gd:233-236`）。
- **影响**：一次点击即可自动走位 → 被怪撞 → 托管打完 → 自动续走 → 踏阵通关，轮次 16 的「清一遍 vs 走一趟」取舍被抹平。
- **建议**：至少「首次遇敌强制停自动前往」；传送阵加守阵怪或二次确认。

### P1-10 浮层/看大地图期间怪物照常追击（可被偷袭开战）
- **证据**：怪物冻结条件缺 `_big_map/_altar_ui/_exit_ui/_beat`（`src/explore/MapScene.gd:1711`）；接触判定只挡 `_battle/_map_done`（`MapScene.gd:1294-1298`）；战斗层 layer=2 压在浮层之上（`MapScene.gd:1335-1337`）。
- **影响**：玩家看大地图/开祭坛时被偷袭 → 战斗盖住浮层；战斗结束后浮层仍在、看似卡死。
- **建议**：统一 `_modal_open()` 判定（含全部浮层 + `G.ui_blocked`），命中时冻结怪物与接触。

### P1-11 前摇期间每 tick 重复入队 → cast_start 事件/音效风暴
- **证据**：`enqueue_cast` 不写 CD、不打 pending 标记（`src/combat/SkillSystem.gd:26-32`），CD 只在结算时写（`SkillSystem.gd:44-52`）；`MonsterAI.decide()` 每 tick 对 `cd_left<=0` 的技能重复入队（`src/combat/MonsterAI.gd:11-16`）；`can_act()` 无「施法中」拦截（`src/combat/Combatant.gd:109-110`）。
- **影响**：一次施法在 0.4~0.5s 内产生 12~15 条重复 `cast_start`：提示反复刷新、音效叠爆、队列浪费（多余项结算时被静默丢弃）。
- **建议**：入队即写 `cd_left = windup` 或加 pending 标记去重。

### P1-12 词条名不副实三处：荆棘·小 / 弱点洞悉 / 处决者
- **证据**：① 荆棘·小 `hook:"on_behit"`（`data/traits.json:24-25`），而 `reflect_pct()` 只统计 passive（`TraitSystem.gd:138-145`）→ 8% 反伤永不生效；② 弱点洞悉 `crit_vs_full_hp`（`traits.json:66-67`）全项目 0 读取；③ 处决者只在技能路径结算（`SkillSystem.gd:192` 调 `modify_skill_dmg`），普攻不享受。
- **影响**：词条池存在「抽到=没抽」与「与描述不符」的选项。
- **建议**：三处逐一接线或从池中移除。

### P1-13 时钟回拨/前调可刷日常（签到已确认；委托部分【疑似】）
- **证据**：daily 判定 = `city.day != today_key()`（`src/autoload/G.gd:762-767`），无单调时间/回拨守卫；系统日期往回拨一天即可再签到（连签计数重置）；前调一天即重刷今日委托并清「已交付」记录（`G.gd:1626-1656`）【疑似】。
- **影响**：本地存档的日常经济可无限刷（离线单机风险等级中，但应设防）。
- **建议**：`city/quest` 存 `last_ts`（unix 秒）参与判定；回拨时保留冷却、禁止连签回退。

### P1-14 自动前往无寻路（直线 + 左右横跳）
- **证据**：自动前往为直线朝向 + 卡住后左右交替横移（`src/explore/MapScene.gd:1151-1181`），无 A*；26s 超时直接把「路远」误判为「前路不通」（`MapScene.gd:29, 1157-1160`）。
- **影响**：凹形障碍区可能来回撞到超时；玩家在通畅的图上被「劝退」接手。
- **建议**：卡住时记录失败方向不再重复；超时改为「卡住累计时长」并区分提示语。

### P1-15 怪物穿树追击，「绕行是策略」失效
- **证据**：散件（树/石）只有 `collision_layer=2`、无监测方（`src/explore/MapScene.gd:1620-1636`），怪物直接 `position +=`（`MapScene.gd:1728-1730`），玩家躲避用的障碍对怪无效；设计文 §2 写明「可绕行逃避」。
- **影响**：「躲进树林」不成立，绕怪只剩拉开距离一种。
- **建议**：怪加 `move_and_slide()` + `collision_mask=2`（或修正设计文案）。

## P2 — 中等（工程 / 一致性 / 性能，23 条）
