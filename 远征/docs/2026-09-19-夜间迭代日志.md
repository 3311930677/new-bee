## 环境整备（开工先修的两件硬事）

1. **Git 仓库离线不可用 → 已修复。**
   现象：`git status / add / commit / write-tree` 全部报
   `could not fetch <sha> from promisor remote`（仓库是 `partialclonefilter=blob:none` 的**部分克隆**，
   本机没有网络，历史上 blob 拉不下来；`.git/index` 也丢了）。
   修法：`git read-tree HEAD` 重建索引 → `git add -A`（把工作区全部文件**重新哈希入库**，缺失的 blob
   由本地内容等价重建）→ `git write-tree` / `git commit-tree` / `git update-ref refs/heads/main` 完成
   本地提交（绕开需要旧 blob 的 diff 统计）。**代价**：`add -A` 约 67s；旧历史 parent 仍缺（`git log` 只能
   到本机第一次克隆的深度），不影响开发。**push 仍需网络，恢复联网后 `git push` 即可。**
2. **回归脚本 `tools/run_regression.ps1`（新）**：22 项 headless 一键跑，支持 `-List a,b,c` 分批、
   `--quit-after` 防挂死（脚本编译错误时协程不会 quit，headless 会永远挂着）、失败自动摘错误行。
   注：`Start-Process -ArgumentList` 会按空格重新拆参，把 `d:\new bee\远征` 拆成 `d:\new`——**必须用 `&` 调用**。

## 轮次 14｜返回与 ESC 分层统一：手游每个界面都要有能点的返回键

**现状缺口**（用户点名"ESC 退出还是有时候会有问题，而且这是手游，每个界面都要有能点击返回的按键适配"）：
1. **主｜ESC 时灵时不灵**：全项目 20+ 个浮层各写各的 ESC，**半数浮层压根没处理**
   （WorldPanel / CodexPanel / DeployPanel / ExchangePanel / GachaPanel / SettingsPanel / TalentPanel），
   只能靠父层 GameHome / CityScene 兜底；而父层的兜底不认"谁在最上层"。
2. **主｜ESC 层级错乱**：已经有 `_unhandled_input` 的浮层里，**十余个没有 `G.ui_blocked` 守卫**——
   开着 GM 控制台按 ESC，会把控制台背后的浮层一起关掉（"时灵时不灵"的根因就在这）。
3. 副｜三选一词条浮层不吃 ESC：PC 玩家按 ESC 完全没反应（界面上明明有「放弃」这个选择）。
4. 副｜登录页没有可见返回键（只有 ESC），手游从标题页进来就出不去了。
5. 副｜**幽灵按钮在暗底上"字没了"**：`ghost_button` 的字是深棕 `6a4a1e`，压在召唤结果层这种
   整屏暗底（`VEIL_TAKEOVER_A` 0.94）上肉眼几乎看不见——"有按钮但看不见"等于没有返回键。
