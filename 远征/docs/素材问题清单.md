# 素材问题清单（生成日期 2026-09-16）

审查范围：4 职业 idle/icon/walk_4dir（12 张）、地形 tile 5 张（001/004/007/010/013）、背景与 deco 7 张（066/067/070/062/063/064/065）、宠物 3 张（092/096/100）、立绘抽查 1 张（080），共 28 张，另对疑点帧做了像素级放大复核。

技术参数整体合格：角色 idle 均为 512×128（4 帧×128）、icon 128×128、walk_4dir 均为 1024×512（8 列×4 行×128，帧排列整齐，均为 down/left/right/up 布局）；背景 971×1619（≈480×800 的 2 倍）；该透明的素材（角色、deco、宠物、立绘）均为 RGBA 且四角全透明；tile 为 RGB 不透明，正常。

## 严重（阻断使用）

- [ ] `image/role/fz/chenxing_idle.png`、`image/role/fz/chenxing_icon.png` 与 `image/role/fz/chenxing_walk_4dir.png` **角色造型完全不一致**：idle/icon 为棕红色短发 + 黄色星星发饰 + 粉色披风 + 白金裙；walk_4dir 为金色长卷发 + 白色修女帽（带十字纹）+ 蓝白金长袍。发色、发型、头饰、披风、服装配色全部不同，游戏内站立/行走切换时角色外观突变。
  → 重新生成建议：先确定以哪一套为准（建议以出现场景更多的 walk_4dir 造型，或反之以 idle 为准重切 walk），然后用**图生图/参考图锁定角色设定**重出另一组；提示词中固定关键描述（发色、发型、头饰、披风颜色、服装主色、手持晨星锤样式），四张图共用同一段角色描述，仅改动作与帧布局。

## 中等（可用但影响观感）

- [ ] `image/map/010_tile_tomb_1.png`（及同系列 011/012 待连带验证）：石砖为错缝排列，单张目检无法确认左右/上下边缘砖缝能否对接，若不能对接，大面积平铺会出现断缝。
  → 建议：先在游戏内 3×3 平铺实测；若有断缝，重新生成时提示词强调 "seamless tileable texture, edges wrap perfectly"，或生成后用 offset 滤镜手工修边。

## 轻微（可接受，后续顺手优化）

- [ ] `image/role/fs/shuangyu_walk_4dir.png` 第 2、3 行（左/右走）部分帧两腿之间出现粉肤色块，形似赤腿或多余肢体（放大复核后判断为"袍摆开衩露腿"的 AI 不稳定表达，非真正多肢体）；128px 播放下基本不可见。
  → 后续可用像素笔刷把肤色块涂成袍色/靴色，或重新生成时提示词补充 "long robe covers legs, dark boots"。
- [ ] `image/generated_001_100/source/062_deco_bg_mountain.png`、`063_deco_bg_clouds.png`、`064_deco_bg_mist.png` 为绘画晕染风，与 066/070 等像素风主视觉存在风格混搭（065 悬崖为像素风，协调）。若视差远景为有意设计可保留。
  → 如需统一，重生成时提示词补 "pixel art style, consistent with 16-bit JRPG backgrounds"。
- [ ] `image/generated_001_100/source/100_pet_eyescat.png`、`080_role_fs.png` 左下角各有 1 像素 alpha≈1 贴到画布底边，极端放大时可能出现细边。
  → 后续裁掉底部 1~2 像素或整体缩 1% 即可。
- [ ] `image/generated_001_100/source/100_pet_eyescat.png` 为双尾造型，需与策划确认"眼猫"设定是否就是猫又式双尾；若设定为单尾则需重生成（提示词明确 "single tail"）。
- [ ] `image/map/001_tile_forest_1.png` 等噪点类 tile 内部亮色斑簇分布略规律，超大面积平铺可能有轻微重复感，当前地图尺度下可接受。

## 后续生成公共约束（所有重生成提示词须遵守）

1. **角色设定锁定**：同一角色的 idle / icon / walk_4dir / 立绘必须共用同一段外观描述（发色、发型、头饰、服装主色、武器样式），仅改动作与帧布局；优先以 walk_4dir 为准反推其余。
2. **风格统一**：像素风为主基调（16-bit JRPG 质感），背景/deco 类提示词一律追加 "pixel art style, consistent with 16-bit JRPG"，禁止水彩/晕染混搭。
3. **tile 可平铺**：地形 tile 提示词必须含 "seamless tileable texture, edges wrap perfectly"，生成后先 3×3 平铺实测再入库。
4. **画布留白**：透明素材四周至少留 2px 空白，禁止主体贴边；生成后检查四角与四边 alpha。
5. **宠物特征显式声明**：尾巴数量、眼睛数量等关键特征在提示词中明确写出（如 "single tail"），避免模型自行发挥。
