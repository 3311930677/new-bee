# 设置与货币图标精修

本轮承接全页面精修，集中改善实际显示在 18–34 像素的小图标。

- 设置：钢灰齿轮、旧金内圈和蓝色晶核；主页入口取消方框，交互时亮起圆弧并轻转。
- 货币：金币用方孔星纹钱币，远征币用六角罗盘章，魂晶用紫蓝切面晶石，荣誉用红绶带勋章。
- 票券：十连券采用紫色符印，扫荡券采用绿色通行符。通过资源名称统一应用到所有调用位置。
- 设置内页：旅人手札、存档册、声音、音乐、震屏、演出、倍速与关闭各有独立图案。音量行保留滑条与百分比的空间。
- 图标均为代码原生 SVG，减少细碎纹理，统一左上光源、深色轮廓与切面。页签保留彩图原色，避免重复染色。

图标原稿位于 `assets/ui/refined_icons/`。人物、装备、地图素材延续已有美术。

验证与原生截图位于 `shots/ui_icon_polish_20261005/`：两种屏幕比例下的主页、三页设置、开始菜单、背包、召唤、竞技、商铺、演武补给及大额余额。预览页提供修改前后对照、图标深浅底色检查和真实设置动效。
