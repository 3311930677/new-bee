# 活动中心配置

正式入口：营帐左侧「活动」。配置文件：data/activities.json。

当前 events 为空，页面会显示「暂无正在进行的活动」。列表和详情已可用，后续配置不同活动无需重写页面布局。

示例仅用于说明字段，不是当前开放活动：

```json
{
  "version": 1,
  "events": [
    {
      "id": "festival_2027",
      "title": "新岁行旅",
      "summary": "简短活动介绍，推荐一至两句话。",
      "visible": true,
      "enabled": true,
      "starts_at": 1798761600,
      "ends_at": 1799366400,
      "body": [
        "活动时间与背景介绍。",
        "玩法规则、参与方式与奖励说明。"
      ]
    }
  ]
}
```

- id 必须唯一，title 必填；空记录、重复 id、visible=false 的记录不展示。
- starts_at / ends_at 使用 Unix 秒数，0 表示未设置。时间以本机时钟展示：开始前「即将开启」，开始时进入「进行中」，到结束时显示「已结束」。enabled=false 显示「未开放」。
- body 支持长字符串或多段字符串数组。内容可滚动，返回按钮始终保留。
- 详情返回活动列表；活动列表返回营帐；安卓返回/ESC 使用相同逻辑。
- 当前是活动公告与说明结构。奖励领取、活动计数和服务器时间未接入；后续开放真实活动时应单独实现相应玩法，不可仅写公告就认为奖励已经可领取。
