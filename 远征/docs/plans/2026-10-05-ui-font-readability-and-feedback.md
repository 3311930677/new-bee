# 远征：文字清晰度与界面反馈修整

日期：2026-10-05。

## 检查结果

使用 Godot MCP 检查了主场景、根节点、项目显示设置和字体 API。主界面场景只保存根 Control，布局与 Theme 在运行时生成，不能仅凭场景文件判断最终布局。编辑器桥接端口未能连接，本次没有把静态场景读取当作实时编辑器检查；另用独立游戏实例输出了运行时节点报告。

实际发现的问题：

- 项目为像素素材设置了最近邻过滤，部分文字也继承了该设置。原字体采用两倍采样，最近邻缩小字形贴图时，细笔画会断裂。已用同字体、同字号的原生渲染对照确认。
- 一些小按钮使用细长装饰字或毛笔字，笔画挤在小字号中；部分文字叠加过重描边，字腔不清晰。
- 任务主线卡的奖励行超出内边距，分区题签的行高不足，造成视觉挤压。
- 原预览页将 480 像素截图缩进四列缩略图，进一步降低了文字可辨性。缩略图不能用作笔画检查的依据。
- 当前使用的五种字库均覆盖了“领取、解锁、返回、营帐、背包、远征”等检查字符，未发现这些字符实际缺字。

## 已实施

- 文字节点独立使用线性过滤，保留角色、场景和像素图标的最近邻过滤。覆盖 Label、原生 Button、LineEdit、RichTextLabel 与 TextEdit，也覆盖动态创建的文字。
- 保留大字号毛笔标题；紧凑控件使用清晰的黑体或宋体。限制小字号的过重描边。动态文字的延迟调整使用弱引用，避免页面重建时访问已释放的节点。
- 页面继承共同的文字 Theme；背包保留自己的银灰、墨蓝、黄铜 Theme 与 Container 布局、滚动区、焦点导航。
- 主页题签改用艺术字；竞技、召唤、兑换入口改为圆形徽记。加载页启用已有笔锋显露动画，并调整副标题。
- 背包增加毛笔标题、金属角饰、稀有度选中底线与悬停提示。领取按钮显示克制的呼吸光纹；禁用状态不显示可领取提示。
- 增加领取后的收获题签，以及解锁后的青玉光纹。接入委托、图鉴、船单、支线、待领取装备、旅装保底、伙伴、坐骑、称号、建筑、天赋、招式和招式分支。反馈在成功保存后触发，不改动奖励、概率或费用；无需持久化的演示操作不播放实际结算反馈。
- 成功反馈忽略输入，约 2.5 秒后自动销毁。满包和重复领取不播放成功效果。

## 验证

- 146 张原生游戏截图，覆盖主要页面、城内交互、剧情选择、养成、招式、说明页与两种屏幕比例。
- 逐图检查 4,069 个可见文字节点：错误过滤、紧凑艺术字和低于字形高度的文字框均为 0。该检查只验证渲染配置与文字框高度，人工截图检查另行完成；不代表自动证明所有内容与布局都完美。
- 16 项相关回归通过。其中背包真实鼠标、键盘及状态切换检查 191 项；字体与反馈专项检查 13 项，覆盖快速销毁临时文字、失败领取、重复领取、反馈不拦截输入和自动清理。
- 198 帧真实游戏运行录制：主页、可领取提示、实际装备领取、实际导师解锁、加载标题动画。GIF 用于查看动效，保留全分辨率 PNG 检查字体。
