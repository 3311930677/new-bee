## 一、总原则（战场女神项目经验沿用）

1. **抽象特征提取**：提示词只描述「特征」（职业气质/装备轮廓/配色/构图），不复刻原版像素排布——生成结果是原创像素画，参考图只提供神韵。
2. **锚点图体系**：每个角色先生成一张「锚点主图」，后续所有派生图（战斗精灵/动画网格/头像）都以锚点图为第 1 参考图，锁定人物一致性。
3. **头像从主图裁剪**，不单独生成（防脸漂移）。
4. **UI 一律生成无文字版本**，文字由引擎 Noto Sans SC 渲染（原版 button0 烘焙了「简约版」字样，重生成时禁止带字）。
5. **统一像素后处理**：AI 出大图 → 降采样像素化 → nearest 2x → 入库。禁止 Real-ESRGAN（会造人工纹理）。
6. **全局色板锁定**（写进每条提示词的色板段）：

```
深木底 #2b2016 · 面板木 #3d2e1e · 描金 #d9a94e · 亮金 #ffd97a ·
米白字 #f0e6d2 · 羊皮纸 #d8c8a0 · 青玉蓝 #4a8fa8 · 血红 #c0392b ·
翡翠绿 #4a9e5f · 暗紫 #7a4fa8 · 战斗底 #1a140c
```

**风格锚点分析**（目标观感，已按实机截图校正）：
- 明亮**黄橄榄绿**草地（偏高饱和黄绿，非纯绿），带深浅噪点斑与小草叶笔触，非纯色平铺
- 蜿蜒米黄沙土路，边缘**犬牙交错不规则**（非直线），路面散布碎石斑点
- 圆冠大树（浓密层叠树冠）呈**金绿色**（受光偏黄，非深绿）+ 松树（深绿），树干粗壮带椭圆投影
- 另有**沙地**（橙黄 #f0b676）与**紫红秋树**（#91303d）两种变体地形/植被
- 大量占格散件：灌木丛 / 细草丛 / 白黄野花 / 灰圆石 / 原木，密度是"氛围感"的关键
- 视角：正俯视略带倾斜，tile 无缝拼接；tile **32px**（原版 16px × 2x），角色约 32×48
