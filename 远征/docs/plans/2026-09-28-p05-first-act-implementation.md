## 1. 玩家实际要玩到什么

玩家登录命名后在昭元边城出生，向闻叔接事，沿古道、断碑坡进入碑窟。普通战教会“接触—指令—胜利—掉落—换装”；导师处解锁并在实战用出第二技能；兽栏剧情送岩龟，身边和战斗中都能看见。玩家可沿路接一条支线、发现固定奇遇或挑战失路兽。击败碑灵后带碎片找石头，以两种可预览的材料路径之一修复碑文，再向闻叔复命。复命后城中供应、NPC 台词和地图环境有可见变化；第一幕不再只是一串自动弹出的对话。

主线无历练、签到、抽取和现实时间门槛。四职业普通装备加剧情宠能通关；失败、缺材料、背包满、重读档都能继续。

| 类别 | ID | 用途 |
|---|---|---|

## 3. 主线修碑选择：先做这一纵切

保持 s10 的碑文碎片必得；把 s11 从“找石头即自动扣物完成”改为“对话后打开修碑面板，点击一个可承担的方案才提交”。旧档若已有 `s11`，原状态不回退；旧档停在 `s11` 且持碎片，进入同一面板。

| 方案 | 实际消耗 | 展示与结果 | 可得性 |

## 4. 六条支线：同一状态机，不复用每日委托

共同规则：城市 NPC 或野外实体可接；同一时间只追踪 1 条，但已接的其他支线保留进度；目标发生在接取前不计数，避免接任务后自动交付。完成时回发布者领取，交易 ID 固定为 `side|<id>|complete`（账本实际落盘形式为 4 段的 `side|<id>|complete|`，见 §8）。完成奖励只一次；主线终章后仍可补做。

| ID／类别 | 接取与目标 | 交付、固定奖励 | 可见反馈 |
|---|---|---|---|
| `a1_rel_guard` 人物关系 | 城门卫接取；古道击退 2 只游荡敌影 | 卫兵处交，金 100、经验 45、强化石 1（口径调整见 §8） | 城门台词从“先保命”变成“路口已清” |
| `a1_rel_child` 人物关系 | 小满接取；找古道遗失的风铃并带回 | 小满处交，金 70、经验 40、图鉴条目 | 小满位置／对白随完成改变，不挡路 |
| `a1_eco_roots` 生态采集 | 青姨接取；古道两处草根点各采一次 | 青姨处交，金 90、经验 45、强化石 2（口径调整见 §8） | 草根点采集后不再生成（不设每日刷新，见 §8） |
| `a1_eco_tracks` 生态观察 | 兽栏师傅接取；断碑坡观察两处足迹 | 兽栏交，宠粮 2、金 60 | 岩龟对足迹有一段反应，地图标记消失 |
| `a1_trade_cart` 商旅／价格 | 驿商接取；将封好的盐包送至古道驿商 | 目的地交，金 140、经验 35，开启首个订单预览 | 市集“断碑坡运路”供货说明变化；不凭空开放期货 |
| `a1_elite_beast` 精英秘闻 | 闻叔给线索；找到失路兽、击败或观察后回报 | 首胜额外定向装备；观察也可交基础奖励 | 首领巢穴、布告栏、闻叔台词同步变化 |

每项要有 `title / clue / map / target / objective / progress / reward / completion_dialogue / world_feedback` 配置。任务日志给当前地点和返回对象，地区图只指向已知线索；小地图同时存在主线与追踪支线时，主线金、支线蓝，实体标签不压玩家头顶。材料不足可保留 `ready` 状态，失败不重置进度。

## 5. 可选首领“失路兽”

位置在断碑坡路西侧，固定巢穴边界与刷点；离主线北口至少一个完整屏幕，不主动追逐，玩家接近才开战。头顶标等级和紫色首领名签，城内布告栏给“路西兽影”线索。等级跟区域 6–12 的上半段；四职业普通装备加岩龟在合理操作下可赢。

机制不是放大普攻数值：①“嗅踪”标记 2 秒（图形圈与文字同示），接着扑向前排；玩家可用防护、换位或治疗应对；②生命 50% 以下“迷路低吼”召 1 只影狼，影狼先死会给首领 4 秒破绽。阶段只触发一次，撤退规则在按钮明示。首胜固定一件职业适配的蓝装、图鉴条目及世界旗；再次挑战只给普通材料、经验和有上限的金币。失败不掉已装备物，首胜 ID 重放不重复发奖。

## 6. 同一幕的成长与探索收束

- **导师第二技能**：沿用四职业既有技能表，s03 后导师对话开放本职业第二技能；第一场有效命中／治疗／护盾给明确熟练进度。首次专精选择提供两种行为差异并可用普通金币重置。不能只把技能按钮变亮而无实战反馈。
- **岩龟**：新档在 s04–s07 间通过兽栏剧情领取，老档已有宠物不删不顶替。主世界跟随脚点与 Y-sort、战斗站位和一次可识别的护卫动作须同屏检查。
- **首骑**：边城马厩任务送一只基础坐骑；先完成四向骑姿与脚点、进出建筑下马、接战和窄路碰撞。速度提升不可跳过 NPC／出口触发。
- **定向装备**：失路兽首胜或章末宝箱保证一件对应职业可穿蓝装，背包满进待领取；工坊可比较、强化与镶嵌，地图外观至少武器轮廓一处变化。
- **固定奇遇**：古道风铃旁的旧路石箱只触发一次，给支线线索和小额材料；地图上有可看见的实体，不能仅在菜单提示。
- **章末世界变化**：修碑后主城图志阁展示碑名，断碑坡北口由灰转暖，市集供货说明、闻叔／青姨／石头对白分辨两种修法；重进图与读档后保持。
