# 《远征》界面精修规则：边城行旅账册

> 2026-10-05 复盘：本文件保留第一轮实现记录。用户反馈说明账册式方向尚未达到视觉目标；后续视觉规则以 [第二轮方向复盘](2026-10-05-ui-art-direction-review.md) 为准，原有交互、存档与功能验收要求继续适用。

适用本轮：行旅营帐、养成总览、技能书。保留角色素材、存档和玩法逻辑。后续页面以这些规则为标准逐页整理，不能只换颜色后继续复制旧卡片。

## 1. 视觉方向与判断依据

以像素人物所在的边城为世界，以行旅器物和整备账册为界面身份。截图里的拼接感来自精细像素角色、模糊场景、柔和彩色应用卡片、满屏书法字同时存在。本轮统一材质、字体、信息密度和交互层级。

每处设计必须回答：它承载什么内容，帮助玩家做什么决定。纹样、分隔和颜色需要有结构或状态含义。

## 2. 色彩

统一注册于 `G.gd`，由 `FieldUI.gd` 复用。

| 用途 | 色值 | 使用规则 |
| --- | --- | --- |
| 墨色底材 | #222b2d / #171e20 | 营帐工具区、招式展示区、次级按钮 |
| 旧纸 / 亮纸 | #e9e1cd / #f4eddb | 养成与研习账册、正文反白 |
| 正文 / 辅助字 | #313b3a / #646b60 | 纸面信息层级 |
| 分隔线 / 铜色 | #b6ae96 / #b79867 | 装订、细线、资源与进度 |
| 行旅旗红 | #87554b | 每页唯一主要操作 |
| 职业色 | 战士赭红、枪骑灰绿、法师灰蓝、牧师灰紫 | 招式标记和选中态，不为每个入口任意换色 |

禁止六个模块六种粉彩底色。通知点只表示当前可处理的奖励或资源，不作装饰。

## 3. 字体与空间

- 宋体只用于页面标题、角色/招式名与出发动作；黑体负责导航、数字、状态和说明。取消导航上的大书法字。
- 480 像素基准宽度；页面边距 24，账册内边距 28，主内容宽 376，通用间距采用 4 的倍数。
- 页面标题 30，招式名 32，人物名 24，导航 18，正文 16，辅助信息 14。正文不描边。
- 内容左对齐；只有导航标签和操作按钮允许居中。状态数字按固定列对齐。
- 一层主底材即可承载正文，禁止“外框 → 纸框 → 卡框 → 对比框”重复套框。
- 纸面只在装订边、穿线孔、页角体现材质；不铺噪点、假旧纹、无意义花纹。

## 4. 三页各自的构图

### 营帐

头像与名字 → 四币固定宽度栏 → 场景与角色 → 四件行旅器物 → 三个营地活动 → 唯一出发按钮。

- 世界、背包、养成、图鉴使用地图、行囊、修习器物、书册，排列在同一整备台上。
- 竞技、召唤、兑换降为次级入口；设置放在右上角。任务入口靠近场景，保留主线/委托的明确文字。
- 钱包四等分；大额单位缩写，完整金额可查，不随数字增长超出屏幕。
- 角色保留原动画；脚下只画接地暗影，取消金色发光圆台。
- 长屏增加场景呼吸空间，整备、活动与出发按各自比例下移，短屏仍完整可见。

### 养成

装订账册：角色摘要 → 战斗修习（天赋、装备、技能书）→ 同行与荣誉（宠物、坐骑、称号）。

- 六行入口共享同一纸材；名称、当前状态、进入箭头分列，消除空白巨大彩色宫格。
- 状态使用真实存档。没有骑乘和没有佩戴明确说明，不能将“没有装备”误写为“没有拥有”。

### 技能书

钱包 → 五个具名招式页签 → 招式图与效果 → 等级细刻度 → 同一行升级收益 → 研习操作。

- 保留滑动和键盘翻页，取消匿名分页点；切换时具名页签同步选中。
- 以原生像素图示表达招式，职业共用笔宽与尺寸。
- 对比使用实际伤害系数，保持现有战斗计算；效果型技能如实说明数值固定。
- 满级/币不足为清晰不可操作状态；升级保留当前招式，及时更新余额与收益。

## 5. 交互和验收

- 可点击区域最小 44×44；普通/悬停/按下/禁用/键盘焦点状态完整。
- 按下移动 1 像素，不缩放文字。页签可以点击，也支持滑动与键盘。
- 浮层关闭、子页返回和 ESC 与现有存档和玩法保持一致。
- 实际引擎渲染检查 480×800 与 480×1067；检查四职业、长昵称、大额钱包、币不足与满级。
- 运行现有导航、养成、技能书、布局、安全区和游戏主体回归。视觉合格需要看实际截图，不能仅用测试通过代替。

## 6. 本轮落地与复核

- 新增 `FieldUI.gd` 原生样式工厂；三个页面共享颜色、字级、账册底材和五种按钮状态。
- 新增 `VerifyFieldUI`：验证可见导航打开真实页面、关闭后恢复，四职业五个具名页签、升级实际扣费并保持当前页、币不足和满级不改存档。
- 钱包支持查看完整金额，关闭养成、召唤、兑换等页面后刷新首页余额；末次联动修正额外通过 `VerifyFieldUI`、`VerifyGameHome`、`VerifyPerf`，日志：`tools/_logs/field_ui_wallet_final`。
- 全量回归由 69 项增至 70 项，全部通过；日志：`tools/_logs/field_ui_full70_verified`。退出时的引擎资源释放诊断仍按已有问题 #43 单独记录。
- 实际 GPU 渲染 31 张：四职业 × 三页面 × 两种屏幕高度，加法师其他四招、禁用/满级和长昵称大额钱包。
- 复核修正角色摘要中立绘撑开、钱包超宽、升级提示遮住操作和治疗说明拆词等问题。
