# 全界面视觉修改与验收 · 2026-10-02

> 本文记录第一轮修改。随后根据反馈重新调整了加载与标题背景、字体、入口按钮、信息分页和建筑阴影；当前效果与验证见 [后续精修记录](2026-10-02-aesthetic-refinement.md)。下文的庭院背景、字体与截图描述保留为历史记录。

本轮覆盖加载、标题、登录、补名、创角、序章、营帐、功能面板、养成、城镇、主世界、历练路线及两种战斗界面。继续使用原有场景、导航、任务与存档系统。修改入口是当前 `project.godot`；运行项目后从标题页进入，已有档登录后进入主世界，点「营帐」查看整备页。

## 统一视觉规则

- 深青灰背景 `#192629`，信息卡 `#203437`，纸面 `#f1e7cf`，正文 `#292f2b`，辅助字 `#645d4c`，主按钮 `#c6a264`。
- 中文正文沿用项目常规字体，辅助字号 15、说明 17、正文 18；24 以上的页面标题才使用宋体。按钮与数字使用同一组字体规则，减少小字描边与大字间距。
- 纸面文字采用深色；暗场字幕保留暖白。`VerifyVisualRefresh` 检查正文、辅助字、收益与装备品质字在纸面上的 4.5:1 对比度。
- 面板统一细边、轻阴影和圆角；主操作、次操作、页签、不可用状态保持区别。营帐入口改为两列四行，保留原有八个功能及提示红点。
- 长屏下背景覆盖完整视口，普通战斗与营帐操作贴近底部；固定阅读页居中，嵌套全屏子页只居中一次。
