# 《远征》世界叙事与整体游戏逻辑定稿

日期：2026-10-03。性质：**后续制作的叙事和系统规格，尚未接入运行时**。配套制作清单见[后续玩法设计](2026-10-03-next-gameplay-design.md)。本文以现行 [36 步主线](../../data/story_quests.json)、[24 条支线](../../data/side_quests.json)、[18 张主世界地图](../../data/main_world_maps.json)和已交付的归路托付为本篇事实；它不把拟议内容写成已完成。

特色关卡、商路与联网的分阶段范围见[专项方案](2026-10-03-signature-levels-trade-and-online-roadmap.md)。

## 一、一句话讲清楚这是什么游戏

玩家是一位带着半卷《远征图志》的巡界者。碑声失准后，人、货物和消息都难以平安往返。玩家通过**听取证词、实地查证、处理危险、修复一段路，再看人们能否重新使用它**推进四幕故事。战斗保护出行，探索提供证据，城镇和商路检验修复是否真的有效；结局要回答的不是“杀光怪物了吗”，而是“后来的人还认不认得回家的路”。

主线属于**归路碑篇**：从昭元边城的失声事件出发，经过沉渊港和霜关驿，追到渊口并稳定归路碑。八座镇界碑、渊的根源与王城首座属于更大的悬念。本篇结尾给出可继续调查的证据，不宣告八碑归位，也不强制玩家立刻进入下一章。

## 二、统一世界规则，避免剧情和玩法互相打架

| 设定 | 本篇采用的规则 | 玩家怎样看懂它 |
|---|---|---|
| 镇界碑 | 八座实体古碑共同约束地下的“渊”；各地保存的碑文、拓片和传说可能不完整，不能把每条民间说法当成已证实史实。 | 图志把“亲眼所见”“他人证言”“仍待核实”分栏，不提前把旧卷推论写作真相。 |
| 归路碑 | 作为八碑体系的**交通与记录枢纽**来设计，本篇修复的对象；它不是新增的第九座镇界碑，也不等于修好了八座实体碑。此身份在后续对白中分三幕逐步证实。 | 第一幕只叫“旧碑”；第二幕发现三地交通和水闸会受它影响；第四幕在碑心确认“归路碑”与三声的关系。 |
| “碑声” | 界碑运行和道路回响能留下可辨的声纹。碑声紊乱时，错误的方向、名字和警讯会重复传播；并非每个回声都是真人灵魂。 | 林、潮、雪三种声纹在 s34 有可听、可看的辨别线索；点错给反证与重试，不随机锁死。 |
| 渊与怪物 | 渊是地脉下的异常源；渗出会扭曲守护物、地形和记忆，但普通野兽与人祸也存在。不能把所有矛盾都归咎于渊，更不能让击败一只怪等于修好一个地区。 | 首领战后仍需修闸、轮岗、通邮等具体行动；图志标出“受到渊气影响”与“尚无证据”。 |
| 半卷图志 | 它是前人写下的地图与记录，有缺页，也有误判。玩家靠对照人证、物证和地图把它补成可使用的路书。 | 图志条目随观察、支线、委托和主线递进，显示来源和发现地点；空白不剧透。 |
| 八主题历练 | 现有八种出征主题是可反复挑战的**图志回境/异象记录**，其怪物和首领是具有叙事意味的遭遇；主题数量不能作为“已修实体碑数量”。 | 出征页写“回境”与“历练进度”，主世界页写“归路碑篇”与实地足迹，两个进度条分开。 |

“归路碑是枢纽”“历练是回境”是**拟定的统一解释**，必须在文本和界面一并落地后才能算运行时设定。现有 [世界志](../../data/lore.json)仍把八主题写成连续修八碑、最终王城决战；现有 `G.main_goal()`、`WorldPanel` 也延续这个旧目标。不能只增加这张设定表就声称游戏已经自洽。

### 纪年与人物的明确改稿口径

采用“**天倾纪十七年为本篇现在；天倾纪十一年王城火起、林碑先失声，至今六年**”作为统一时间线。序章城火发生于十一年；当夜先异常的是林碑，其余失声在此后陆续发生。把旧文中“城破十七年后”“七年守碑”“那夜八道碑光全部熄灭”等句子逐条改成能与这条时间线共存的说法。这里是待执行的改稿决定，**尚未修改 `lore.json`**；不得让新支线继续引用旧年数。若后续剧情组希望城破更早，应先统一整份时间表，再同时改序章、城堡回境、图志和测试，不能局部改一个数字。

主角保留“最后一脉”和半卷图志，但“无铭旧剑”是师父留下的**遗物**，不规定四职业开局都持剑。阿豆在序章送信、在现行城镇做兽栏事务，可以写成营地里兼差的人；在对白交代一句“信没人领的时候，我先来照看这些会认路的小家伙”，再把身份统一为“信使兼兽栏帮手”。这是角色连续性的补笔，不新增 NPC。

## 三、四幕事件因果链

| 幕与现有节点 | 玩家提出的问题和得到的证据 | 行动如何造成下一幕 | 本幕真正改变的世界 |
|---|---|---|---|
| 第一幕，s01–s12，昭元/古道/碑窟 | 界碑为什么失声？守影、铁扣、青姨拓片、碑灵和碑片显示：旧路的“名字”缺了一段，碑被改动过；**谁改的尚无定论**。 | 修碑法 s11（锻合/拓录）保住边城通路，残缺的路名与失联盐车账页指向旧盐道。s13 是自然追查，不是忽然换地图。 | 一段古道重新能走，闻叔接手守路；玩家获得继续核账的理由。 |
| 第二幕，s13–s20，旧盐道/沉渊港/潮闸 | 盐车账页记的是闸门开合；港口账目异常同时影响人的渡运和盐、谷供给。水闸司祭被击败只解除急迫危险，不会自动补回断货。 | 玩家在 s20 选先通盐渠或堤道，市场产生可解释的供应变化；同一印记又出现在霜关来信，沈澜托玩家北上核实。 | 港口听见潮钟、两条供货路逐步恢复；另一条路不永久关闭。 |
| 第三幕，s21–s28，赤砂商路/霜关/矿道/冰隘 | 商队催开关，岑雪担心撤岗；两份同印记的信说法相反。矿车记录、双关讯号和雪幕说明“消息失真”与“补给短缺”一起扩大风险；现阶段不指定幕后坏人。 | 玩家既查矿道又处理雪幕，再在 s28 决定哪队先走。之后林、潮、雪三地拓片指向渊口外环的同一处共鸣。 | 霜关有人接岗，另一队随后放行；失踪者、灯和补给需要继续照料，给支线与委托留下空间。 |
| 第四幕，s29–s36，渊口/昭元/门厅/共鸣廊/碑心 | 三地声纹是“曾有人往返”的记录，而非命令玩家继续开门。青姨在 s32 帮玩家确认缺页；s34 要先留下返程锚，再校准林、潮、雪，s35 阻止渊脉化身干扰碑心。 | s36 把碑心记录交闻叔，决定归路碑的留存方式。它结束这次远征，并让三城回访、邮路和守路责任成为通关后的日常。 | 归路可再走；三城 NPC 对亲历的选择有回应；八碑总谜、王城旧账仍待证据。 |

每幕使用同一个可演出的六拍：**遇到具体人和麻烦 → 听到一种解释 → 在地图上找到反证 → 解决可见危险或机关 → 作出有信息的地区决定 → 回城见到人的回应**。首领只能负责第五拍之前的危险，不能代替最后的地区修复。

必须把三条最重要的跨幕线索画在图志“归路调查”页：**名字/拓片**由碑窟到青姨再到碑心；**货签/印记**由盐车、水闸到霜关两封信；**林潮雪声纹**由各地观察到 s34。每条标“已确认、互相矛盾、待查”，并链接实际地图和人物。玩家中断数日再回来，能从这一页理解为什么要去下个地区。

### 长线谜题的揭示顺序

归路碑解决的是**三城之间如何再通行**，不是八碑为什么失声。长线采用“物证先于结论”的顺序，防止旧世界志一句话提前剧透整部游戏：

| 层次 | 本篇可以明确说 | 只作为疑问保留；以后需要什么证据 |
|---|---|---|
| 王城旧火 | 主角在城火中失去师门，并继承被裁开的半卷图志。 | 谁裁去第二页、城火和林碑失声是否同一人的行动；需原页、幸存者证词和王城现场互证。 |
| 八碑与渊 | 各地确有镇界碑体系，渊口受碑声稳定程度影响。 | 八碑全部位置、各自状态、归位的真实代价；需实地测绘和不受回境扭曲的记录。 |
| 首座的“账” | 旧卷声称首座因“八碑归位会死一半人”推开第一座碑；这是一份人物主张，不能在图志里写成事实。 | 算式依据、他可选择的其他办法，以及所谓“一半人”指谁；本篇末页只露出一个待核的账页线索。 |
| 渊中的声音 | s35 的化身可被击退，s36 的归路碑可稳定。 | 渊的起因、声音能否冒用旧人的记忆、其余实体碑是否受同一威胁；没有证据前不定幕后黑手。 |

如果将来制作下一篇，先从现有六条归路托付和新增三城口述/图志缺页里发现**互相矛盾的一条王城记录**，再开放新区域去找第二份独立证据，最后才让玩家与首座的算法正面交锋。王城决战是未来可制作内容，不在 s36 后弹出虚假的“去王城”任务。未来篇也应保留本篇“先查证、再做决定、回来看人的生活”的玩法语法，而不是突然变成收齐八个道具才准看结局。

### 分支只改变可见的人情与秩序

| 现有选择 | 当下可见 | 后续引用范围；不改变的东西 |
|---|---|---|
| s11 锻合/拓录 | 铁件重新承力，或保存可辨的文字；石头、青姨各有一句评语。 | 断碑坡旁景、一次图志注记和补给消息受其影响；不改变碑窟首通奖励。 |
| s20 疏浚盐渠/加固堤道 | 港口告示显示先恢复哪类货与价格缘由。 | 委托、商路合约读出同一市场状态；另一条道路后来可恢复，任务入口始终可达。 |
| s28 商货/守关补给先行 | 霜关的货栈、轮岗簿和两位代表人物有不同短台词。 | 先后次序影响可见供货与一封回信，不把另一队写成被玩家放弃。 |
| s32 先听/先稳 | 进入归路门厅前得到不同的解释和机关提示。 | s34 两种准备都能校准三声并获得同一主线凭证。 |
| s36 封渊留路/留声守望 | 一种以降低渗漏、巡守记录为重；一种以保存回声、公开听读为重。 | 三城后日谈的语言、碑心外观和图志末页不同；**两种结局均可回访地图、完成六条现有托付及全部后续可玩内容**。 |

不要用“善恶”“完美/普通结局”解释这些分支。结局页需分别说明玩家选择的**即时责任、可见代价和未解之谜**，不能只改一句文案却让结算界面暗示某一边更正确。

## 四、人物为什么会参与同一件事

| 人物/群体 | 本人的需求 | 贯穿节点与通关后去向 |
|---|---|---|
| 闻叔、老赵、青姨、石头 | 一位负责路上平安，一位认得人情，一位保存证据，一位让碑和桥实际可用。 | s01–s12 是接案、巡查、查拓片、修碑；s32–s36 把证词汇回昭元；通关后灯、桥、口述档案和守路誓约从他们手上展开。 |
| 沈澜、老鹭、陆七、阿棠 | 关心港口能否安全通行、信能否送达、价格能否解释、生态会否被修路伤到。 | s16–s20 是查账与通闸；之后用潮线观察、缆绳、货签、留根取样检验“路通了”是否真的惠及港口。 |
| 宁砚、岑雪、陶铎与矿工 | 要在商货和守关补给间作决定，同时不让矿工与守夜人变成抽象资源。 | s23–s28 的相反来信迫使查证；之后用矿工救援、炉息、岗火和名牌留下一个有人接班的霜关。 |
| 阿豆与随行伙伴 | 信件到不了的年月里，照看会辨路的动物，让失联者仍有被找到的希望。 | 在第一幕补身份对白；宠物的闻踪提示是可选帮助，图志与地图总提供不用宠物的观察手段。 |

新增 12 条支线按“**每幕三个余波**”安放：秘闻补证据、商旅补物资秩序、关系/生态补生活后果。它们的具体 ID 和任务实体沿用[玩法设计第四节](2026-10-03-next-gameplay-design.md#四补足-12-条支线每幕再添三条)。已有 24 条支线，尤其 s36 后的六条归路托付，负责第一层后日谈；新增三条第四幕支线负责口述、小聚与生态回访，不能重做送信、采叶或碑心余纹。

## 五、把操作、成长和叙事做成同一个循环

```text
城镇听闻/告示/图志线索
  → 选一件主线或可选旁事，读清地点、风险与收益
  → 带补给、职业技能、伙伴或坐骑出行
  → 地图观察取得证据；战斗排除危险；机关改变道路
  → NPC 与地形立即反馈，图志记下“从何处得知”
  → 回城交付，资源与地区状态一次结算
  → 新路、新关系或可重复事务出现，再选择下一趟
```

| 已有/拟增系统 | 在世界里的理由 | 玩家决策与反馈 | 与主线的边界 |
|---|---|---|---|
| 四职业、装备、战斗 | 不同巡界者处理同一处危险的方法不同。 | 看首领预兆，接近打击、闪避或用技能；击败后让调查继续。 | 四职业均能独立完成 s01–s36；机关线索不靠特定技能读取。 |
| 主世界与三座旧副本 | 从野外物证走向失声源，逐房确认“听到的”“可以修的”“必须挡住的”。 | 调查、机关、首领三房分别给新信息；撤退可从安全入口续查。 | 保留 `stele_cavern`、`tidal_gate`、`rift_mine_vault` 世界 ID、原首领和唯一首通奖励。 |
| 现有八主题历练 | 图志记录的回境让玩家在安全锚点重访危险的可能性。 | 层间风险与词条构筑，首次首领演出体现各地记忆。 | 回境进度不解锁现实归路碑的故事步骤；八主题不等于已修八碑。 |
| 委托与地区信任（拟增） | 路修好后仍要有人巡、有人送、有人核账。 | 公告栏给明确现场目标；完成后看岗火、信箱、市场说明等小变化。 | 永不要求刷信任才能听主线对白或进门；原有 13 条任务继续可用。 |
| 交易与船运、合约（合约拟增） | s20、s28 对供货路线的选择需要经济上的可见结果。 | 先看货源、成本、保险/延期条件，再选择运货和排障。 | 金币是补给与外观的来源，不替代关键信物，也不借债卡剧情。 |
| 钓鱼、宠物、坐骑、图志（扩展拟增） | 水位、足迹、地貌和动物行为本身就是调查线索。 | 钓鱼认识潮线，宠物闻踪，坐骑辨地，图志把发现连回任务。 | 都有步行与肉眼观察替代路线；稀有宠物不掌握唯一正确答案。 |
| 守碑誓约（拟增） | 玩家在一趟出行前说明“优先救人、压住威胁、还是保住生态与补给”。 | 庇护、征伐、丰收给轻量战斗/探索差异和专属记录。 | 是玩法姿态，不是阵营；不重新判定 s36 的结局善恶。 |

前 15 分钟先让玩家在昭元完成一次**证词→足迹→战斗→回城复命**的小闭环，再开放支线和出征；第一次遭遇盐车时演示“账页不等于盐数”；霜关首次来信时演示图志的“相互矛盾”标签。不要把六种系统按钮在序章一次推给玩家。中后期用一次出行可同时推进主线线索和一项非强制旁事，减少无意义往返。

资源逻辑只设一个通用约束：必需的药、普通装备和路费能从主线/野外自然取得；支线和委托补充选择而不垄断生存。首通剧情物、支线独有事件、可重复货物和外观材料分池结算；剧情物不可交易或被合约扣押。重复内容提供变化的决策与地点，而不是每天重复一段声称“第一次”的对白。

### 结局后的可玩目标

s36 后不自动跳到“王城决战”。任务簿改为“归路已稳；三城仍有托付”，保留现有六条回访，并逐渐开放新支线、地区委托、图志缺页、可重访副本和历练。王城旧账只在完成几条不同来源的调查后呈现为**未开启的长线线索**，用明确文案告知“本篇到此”，不能在已完成 UI 上假装它已经有可玩地图或 boss。玩家选择收工、继续照看三城、追索图志残页，都能获得完整的本篇结局体验。

## 六、把现行冲突改进运行时的顺序

1. **锁定时间线与名词表。** 为天倾纪十一至十七年列事件表；确定“八镇界碑、归路碑、三地共鸣点、八回境”四种名词，各文本只按一个口径使用。检查 `lore.json` 序章、八主题首领前后、王城段、s01–s36 与 24 条支线；不给现有未开的长线补一个假结局。
2. **修两个并存的主目标。** `G.story_goal_short()` 和任务簿已按 s01–s36 显示归路篇，但 `G.main_goal()` / `main_goal_short()` 仍按八主题逐个讨伐并以“八碑归位、回王城”结尾。界面明确标“归路主线”与“回境历练”；改世界图志、出征页标题和完成文案，保持原解锁/扫荡玩法不变。相应更新 `VerifyLore.gd`，使测试证明两条进度不会互相冒充。
3. **补跨幕过场与回城回应。** 在 s12→s13、s20→s21、s28→s29 各增加一小段“谁递来证据、玩家为何出发”的文本/演出；不改 36 个稳定 step ID、不重发原奖励。先让已通关旧档在图志中读到归纳页，再逐幕补新档的现场演出。
4. **把世界变化做成可读证据。** 三城各先实现一个永久可见的示例：边城路标、港口潮线公告、霜关轮岗灯。每个变化同时有场景实体、NPC 一句回应和图志记录；从存档 flags 重建。s11、s20、s28、s32、s36 的旧档选择都需正确映射。
5. **再扩新玩法。** 先接失声碑窟纵切和三城各一个现场委托，然后沿[实施批次](2026-10-03-next-gameplay-design.md#七实施批次与可验收成果)扩 12 条支线、跨日委托、地区信任、合约与回境续局。文案、事件、奖励走同一稳定 ID 与事务账本。

验收以三类玩家问题判断：新玩家能在序章说出“为什么先去昭元”；玩到每幕结尾能说出“修好的是什么、还有什么没解决”；通关玩家能分清“归路篇已结”和“八碑长线仍未揭开”。再用四职业、两种 s36 结局、旧档/新档、真实按钮操作、退出重进与奖励去重作工程验证。静态文案检查只证明规格和字段一致，不能替代这些运行时结果。
