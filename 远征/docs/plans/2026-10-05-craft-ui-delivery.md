# 第二轮界面与场景道具交付

本轮依据商业游戏参考中共同的角色主体、操作层级和素材完成度，重做营帐、人物养成和技能书。世界道具同步补齐用户指出的平面路牌，以及主世界、余波任务和技能预览中常见的几何占位。改动已接入游戏运行场景，不是设计样张。

## 已落实

- 营帐：蓝调营地与灯光落地，角色成为中央主体；顶部紧凑余额，任务显示真实目标，右侧次级快捷入口，底部固定四入口，金色继续旅程按钮明确承接当前地图。
- 人物养成：六条成长线围绕实际职业角色组织；装备、技能与同行摘要保留真实状态，整备提示显示可用天赋点。
- 技能书：五个具名招式、职业动画与效果预览、就近的等级/系数/研习成本；纯效果技能不伪造数值增长。预览不启动真实战斗、不消费资源、不改变进度。隐藏预览停止处理。牧师旧战斗图有越格和人物不一致问题，本页改用当前角色的完整待机帧与施法起伏。
- 材质：暗青底、金属边、少量职业能量色、统一斜角与状态反馈；保留 44 像素以上点击高度、九位余额与长昵称支持。
- 返回：修复养成/竞技用 Escape 关闭后营帐仍被隐藏的问题。

## 边界

这轮完成的是三页重构和上述常用道具；背包、装备详情、宠物详情、召唤等其他页面尚未按第二轮构图全面重做。场景地表和已有建筑没有整批重绘，旧底图中画出的简化围栏及部分远景细节仍属于后续美术统一范围。角色大厅仍使用现有 128 像素角色帧；专用高分辨率展示立绘尚未制作。视觉观感以本轮真实截图为准，功能测试不能替代审美确认。
