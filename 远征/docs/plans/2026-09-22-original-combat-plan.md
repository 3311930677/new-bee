## 二、双地图结构（不破坏原结构的关键）

```
远征探索层（现有 MapScene，6 主题探索图）        ← 原样保留，玩法入口
        │ 撞怪/踩事件
        ▼
主地图·战斗场（新场景 CombatField.tscn）         ← 单屏固定镜头，对标原版
        │ 战斗结算
        ▼
回到探索层（奖励/词条三选一/进度落表，全部沿用远征）
```

- **探索层不动**：`MapScene` 的移动/明雷/拾取/祭坛/传送门照旧——它就是"原来的那些地图"。
- **主地图是新增场景**：不替换任何现有场景；`BattleScene.tscn` 保留为兼容层，
  新场景 `CombatField.tscn` 接管同样的 `battle_finished(result, hp_left)` 信号，上层无感。
- 主地图按世界主题换色（草地为基准，雪原/火山等改色板），**不做成 6 张图**，一张场 + 主题 tint。

## 三、战斗规格（从三张截图逐条拆出）

### 3.1 场地与站位
- 单屏固定镜头，无视差滚动；草地底 + 一条蜿蜒沙路 + 深绿草丛簇（对标 08 图）。
- 敌方**左上**、我方**右下**，对角线站位；脚下椭圆投影。
- 尺寸基准：角色约 64px 高（原版 240×320 → 2x），场地按 480×800 竖屏留出顶部标题与底部安全区。

### 3.2 信息层
| 元素 | 规格 |
|---|---|
| 顶部标题 | 「遭遇战」红字居中（战斗结算时改「胜利/战败」） |
| 名牌 | 绿字「名字+等级」（如 敖采薇10），悬浮在单位头顶 |
| 敌方血条 | 仅红条（HP），位于单位正下方，宽 ≈ 单位身宽 |
| 我方血条 | 红(HP)+蓝(MP) 双条上下排列，右对齐；条末端挂**状态小图标**（中毒=草） |
| 飘字 | 普通伤害=黄字数字（如「30」）；重击=红字「-42」+ 下方「重击」小字；治疗=绿字 |

### 3.3 指令轮（核心交互，对标 06 图）
- 点击敌方单位（或自动战斗触发）→ 以我方为中心弹出**四向指令轮**：
  上=攻（双剑图标）、左=技（书）、右上=物（药瓶）、下=逃（门）。
- 轮中央偏上挂**沙漏图标** = 行动读条（ATB）：沙漏走完才能出手，指令选中后进入等待。
- 图标直接用原版提取件：`apk_xajh/xaqd_tree/gwy/wm1/pk/0.png`（攻）等，缺的按同风格自绘。
- 自动战斗开关沿用远征现有 `自动` 逻辑。

### 3.4 特效与动作
| 时机 | 表现 |
|---|---|
| 我方攻击 | **投掷武器**：武器精灵旋转飞向敌方（对标 07 图的镰刀飞行态），命中前收轮 |
| 命中 | 12 芒星芒爆（黄心红边），敌方闪白 1 帧 + 顿帧 2 tick |
| 重击 | 星芒更大 + 红「-42」+「重击」小字 |
| 施法 | 单位头顶沙漏读条，读满放出法阵/弹道 |
| 死亡 | 原版 `die_l` 系列倒地帧 + 尸体淡出 |

### 3.5 节奏
- 实时 ATB：双方按速度积蓄行动条（沙漏可视化），非回合制。
- 远征的技能/词条/药剂数值**原样接入**：技=技能卡轮盘里的技能（扩展指令轮的「技」为二级扇形菜单），
  物=药剂，数值走 `BattleSim` 现有公式——**战斗内核不重写，只重写表现层与输入层**。

## 七、风险

1. **原版帧率/动画语义**：`.aef` 只解析到 key/frame/dx/dy，帧时长与事件位可能理解不全 → 用录屏逐帧比对兜底。
2. **指令轮的「技」二级菜单**：原版细节录屏不清晰 → 按远征技能卡样式做成扇形二级，标注为自设计。
3. **回退保障**：`CombatField` 为新增场景，随时可切回 `BattleScene`（一行接线改动）。
