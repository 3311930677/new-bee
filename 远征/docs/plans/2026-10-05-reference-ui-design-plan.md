# 《远征》界面精修：参考对照与六块改造方案

日期：2026-10-05。目标是在现有像素奇幻美术内建立清楚的视觉焦点、独立的功能图标、可辨识的材质和有节制的动效。参考用户提供的七张游戏截图，只借鉴组织和表达方法，不复制角色或素材。

## 对照后真正的差距

| 参考 | 有效的设计方法 | 《远征》当前问题 | 对应改造 |
| --- | --- | --- | --- |
| 皇室战争收藏、卡片详情 | 物品大图、稀有度边框、选中后展开操作；阅读顺序是主体→属性→动作 | 背包装备图偏小，容器和物品都用平灰底，选中反馈较弱 | 背包改为深色装备陈列与浅色信息页，增加稀有度边沿、图标底座、选中亮边 |
| 皇室战争主页 | 中央舞台、侧边独立道具图标、唯一突出的主操作 | 营帐背景和入口同样繁复，功能图标存在金币、书本复用，主次竞争 | 压低背景色彩对比但保留清晰像素；场景中心留白；冒险按钮占主位；不同功能使用不同轮廓 |
| 王者荣耀主页 | 大面积主体、功能分组、开边界的导航和精细金属层次 | 横条牌子、框中框较多，装饰与内容没有层次 | 金属强调仅用于主动作和关键状态；导航使用无框、圆章、盾牌、菱形等形状 |
| 狐系角色主页 | 主角占视觉中心、侧边信息短而明确、底部导航简洁 | 养成角色周围缺少围绕人物组织的状态，底部信息空而大 | 养成改成角色展示、左右功能节点、实际整备摘要；用颜色与轮廓区分六个系统 |
| 棕黑色英雄详情 | 开放的圆环装备节点、衬线字和细线构图、较少大边框 | 图鉴有多层厚框，未获得宠物只是变暗，信息和图片争抢面积 | 图鉴使用独立的灵宠展示域、稀有度标识、明确的未解锁状态和干净的属性行 |
| NIKKE主页 | 主操作与辅助入口在尺寸、角度和材质上有明确差异 | 召唤初始页更像表单，仪式只出现在结果阶段 | 召唤页面增加灵宠舞台、符环和呼吸光；抽取、资源和奖池分别成组；结果仪式仍使用真实结果 |

与参考游戏的另一项差距是原画数量和分辨率。现有角色与装备像素素材不能通过加滤镜变成高精度原画；这轮优先改构图、组件和反馈，保留原素材清晰边缘，不拉伸伪造细节，也不加入模糊和噪点。

## 六块实施顺序

1. **图标与材质**：修复功能语义，统一光源和尺寸。世界用地图、背包用皮包、养成用生长枝、图鉴用册页、竞技用双剑、召唤用晶核、兑换用天平。保留像素几何，新增图标由项目内矢量绘制，不再用金币代替功能。
2. **主页**：保留清晰场景与原角色；减弱背景抢眼区域；增强舞台的接触阴影和光环；区分侧边入口、底部导航和冒险主按钮；主按钮副标题继续使用实际目的地。
3. **背包**：保留 Container 布局、分页、装备、锁定、出售、宝石和焦点行为。提升窗体、页签、装备卡、详情和主操作的层次；扩大装备图和选中标识；背包满、不可售等禁用状态仍准确。
4. **养成**：以角色为中心组织六个功能节点，入口用不同图标和材质；等级、职业和整备摘要均来自实际存档，不制造虚假战力。
5. **召唤与图鉴**：召唤初始页建立仪式舞台和四列奖池；结果展示保持真实抽取与保底规则。图鉴减少嵌套厚框，展示主体、稀有度与实际解锁条件；解锁态更清楚。
6. **公共弹窗与反馈**：通过共享绘制组件统一光源、描边和按下深度，按用途区分面板。保留领取、解锁的成功反馈；禁用、失败和重复领取不产生成功光效。加载、主页和召唤动效在真实运行中验证。

## 字体与细节约束

- 大标题使用现有艺术字，正文和数值使用清晰字形；小字号不使用复杂装饰字，不增加厚重描边。
- 文字使用线性采样，角色和像素道具使用最近邻采样。背景不虚化。
- 每个页面只保留一处最强动作强调；正文、次要说明、资源数值有不同层级。
- 普通文字不低于 14 像素，关键动作触区不低于 44 像素；按钮的装饰层不拦截输入。
- 稀有度用色、线、徽记共同表达；动效集中在可领取、选中、抽取和完成时，避免整页同时闪烁。

## 验收

修改前后分别在 480×800 和 480×1067 原生分辨率截图，逐块检查主体比例、边界、字体、遮挡和触区。运行主页导航、背包交互、布局、召唤、养成、图鉴及文字采样的回归检查。输出可打开原尺寸图片的对照页和动效预览；记录完成范围和素材限制。

## 本轮实施与检查结果

六块均已落实到游戏代码，沿用现有角色、装备和灵宠素材，保留原有进度、价格、概率和保底配置。

| 模块 | 已完成 |
| --- | --- |
| 图标与材质 | 修复金币代替功能的图标；绘制地图、皮包、枝叶、双剑、晶核、天平、爪印、鞍具和王冠；区分圆章、盾牌与六边章 |
| 主页 | 圆形旅人小像；资源数字加大；任务册页、活动布签、艺术字主操作与人物名；局部色彩压暗、清晰背景、角色底座微光 |
| 背包 | 墨蓝装备陈列与象牙详情页；装备图放大；品质边沿、选中切角、高光底座；保留焦点、滚动、分页和真实装备操作 |
| 养成 | 六条线路使用独立器物与徽章；角色展示底座；实际天赋、强化等级和灵宠数量摘要 |
| 召唤与图鉴 | 主打灵宠与符环待机；四列奖池；主次按钮和 44 像素免费触区；图鉴剪影与开放圆环；移开覆盖里程文字的翻页指示器 |
| 公共控件与反馈 | 公共纸页减少嵌套厚框、统一光源；按钮悬停与按下深度；加载说明字加大；领取、解锁成功光效；召唤结果焦点切换 |

- 146 张原生截图，覆盖主要页面、章节服务、养成分支、说明弹窗与长屏状态；主要页面同时检查两种屏幕比例。
- 4,076 个可见文字节点：文字非线性采样、小字号复杂艺术字和文字框高度不足均为 0。
- 17 项相关检查通过；其中背包真实输入检查 191 项、字体与奖励反馈检查 13 项、召唤键盘输入检查 14 项。
- 402 帧运行录制；输出全彩 APNG，保留字体与像素边缘。稀有单抽是隔离测试样例，正式概率未修改。
- 发现并修复：图鉴翻页指示器与里程行重叠、剪影残留原颜色、深底警告字过暗、召唤结果缺少默认焦点。
