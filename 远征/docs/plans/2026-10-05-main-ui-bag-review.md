# 主界面检查与背包优化

2026-10-05。检查对象为正式 `GameHome.tscn` 与由主页入口打开的 `BagPanel.gd`；截图使用独立演示存档。

## Godot MCP 检查结果

使用项目已安装的 Godot MCP，通过 `read_scene`、`get_node_properties`、`editor_state`、`open_scene_in_editor`、`live_scene_tree`、`execute_editor_script` 检查场景和布局数据，再以 `capture_screenshot` 验证渲染。

`GameHome.tscn` 只有一个铺满视口的 Control，入口、角色展示、任务和货币栏均由 `GameHome.gd` 在运行时创建。这解释了编辑器场景树里看不到完整主页；节点并未丢失。运行时数据由实际实例化的主界面采集，再经 MCP 编辑器脚本读取复核。

## 主界面发现的问题

1. **尺寸变化后没有重新排布。** `_layout_tall_home()` 只在 `_ready()` 调用；未监听 `resized` 更新入口位置。实际将 480×800 变为 480×1067 后，“继续旅程”的位置仍为 `(32, 622)`、尺寸仍为 `(416, 70)`，底部导航也留在原处，留下大块空白。初次进入长屏已有单独的位移处理；本问题针对进入之后的尺寸变化。桌面配置目前禁止手动调整窗口，因此是移动端适配与未来窗口模式的风险。
2. **布局主要依靠固定坐标。** 货币栏是唯一 Container；任务、右侧快捷入口、角色名牌、旅程和底部导航分别写坐标与尺寸。增加入口、调整字体或安全区时，要同步改多处。建议后续将顶部、侧边与底部导航分别置于容器中，角色展示保留独立层。
3. **没有继承的统一 Theme。** 目前依靠 `G`、`FieldUI` 和 `CraftUI` 的组件工厂及局部覆盖绘制。现有工厂已有共用配色，因此没有将“无 Theme”直接判为视觉错误；问题是字体、边距、焦点和状态皮肤散在多处，改一个页面容易与另一个页面不同步。
4. **两个触摸入口缺少键盘操作。** 头像框和可点击的货币栏使用普通 Panel/HBoxContainer 加鼠标事件，未提供可获取焦点的操作入口；主页其他 11 个按钮已支持焦点。移动端可点击，键盘体验尚不完整。

## 已接入正式背包的修改

- 继承独立 `InventoryTheme.gd`，保留银灰面板、墨蓝按钮、金色边线、暖色详情区及已有像素图标。文字平滑显示，图标保持最近邻采样。
- 容器层次为：安全区内居中的 PanelContainer → VBoxContainer → 标题、容量与货币、四分类、物品滚动区、详情、返回区。
- 装备以四列图标格展示，每页八件；名称、品质、强化与锁定状态分开显示。详情包含属性、在身装备比较、宝石孔和词条，操作按钮留在详情底部。
- 材料与宝石列表可滚动，说明自动换行；修复原版宝石提示越出右边界的情况。材料通过现有 `G.item_icon()` 映射加载已有素材。
- 待领取列表保留分页；满包时禁用领取并说明原因，腾出格子后恢复领取。
- 按钮高度至少 44 像素，具有悬停、按下、禁用与焦点样式。Tab 可循环访问分类、物品、翻页、宝石孔和操作按钮；方向键可访问装备格。返回与 Escape 恢复打开背包前的焦点。
- 长短屏幕均在安全区内居中。装备页限制最大高度，避免长屏拉出无意义的大块空白；详情内容过长时单独滚动。
- 换装、锁定、卖出确认、宝石拆除和领取仍调用现有 `G.inv_*` 接口，未修改掉落或装备数值。

## 验证

- `VerifyInventoryUI.tscn`：通过视口实际鼠标与键盘事件，检查翻页、选物、锁定/解锁、稀有卖出两次确认与金币到账、换装/卸装、拆宝石、材料图标、滚动、满包领取、Tab、Escape 和返回主页后的焦点。同时测量 480×800 与 480×1067 下四分类的窗口与按钮边界。
- 现有 `VerifyUiLayout`、`VerifyNav`、`VerifyFieldUI` 均返回各自成功标记及退出码 0。
- Godot MCP 截图返回 `ok: true`、`imageWritten: true`、`looksBlank: false`，已人工查看 PNG；多页截图也直接由正式游戏节点渲染。
- 检查原生 Button 的回归辅助代码已同步兼容 Button.text，继续兼容原有 Label 包装按钮。

测试与截图均使用独立保存目录。运行日志中有当前 Windows 环境已有的证书存储诊断，以及部分旧回归在退出时的资源释放诊断；未出现脚本解析或操作错误。本次验证不包含重新导出 Android 安装包或真机触摸测试。
