# 参考画风修改方案与实施记录

## 目标

2026-10-01 用户要求按参考游戏画风修改。以此前录屏的绿色城镇、蓝色城镇与独立对阵、纸色硬边列表为依据；保留《远征》四职业身份、世界观、地图ID、任务、碰撞、出口与已有存档投入。

参考的是统一的低分辨率像素视觉：地面以安静的大色块组织，角色轮廓清楚、头身较修长，建筑体块简洁、统一光向，UI硬边与少量金色角饰。安卓浮层、聊天遮挡和数字键盘不作为目标。

## 规格与顺序

| 批次 | 实施内容 | 验收 |
|---|---|---|
| V1（当前） | 昭元边城地表重绘并实际接入；地图主角占屏校准；共用按钮、纸页、标题、标签改硬边少投影；主世界战斗建立同地区独立地表构图 | 城镇/战斗/背包480×800与480×1067截图、原存档保护、地图可走/战斗/界面回归 |
| V2 | 主角四方向与NPC/普通怪逐种重绘；保留颜色、武器、职业身份和脚点注册 | 同屏主角/NPC/怪共享像素密度、光向、阴影，侧面脚部语义与走动连续性正确；不以改缩放替代重绘 |
| V3 | 城镇建筑统一透视与材质；港口/第三幕程序道路、轨道、房屋和设施更换像素资产 | 现有碰撞/地图旗保持；边缘、转角和状态变化可见；世界、战斗均无几何占位质感 |
| V4 | 营帐、登录、养成与剩余地区统一；装备/坐骑/宠物动态表现 | 全流程视觉连续、Android实际尺寸与性能验收；S7仍需独立完成 |

人物样板显示高度目标约70–85逻辑像素，普通NPC与主角相近，普通怪按体型而非统一放大；建筑门口与人物共同校准。先从现有角色占屏和地表/UI调整开始，不把临时缩放后的旧精灵称为角色美术重绘完成。逻辑48px格、128px帧容器和脚点协议继续沿用；原生美术像素尺寸要由实际样板确认。

地表：浅草绿/灰绿石路，较大色块与少量点缀；人物/建筑对比高于地面。原主街中心位置及宽度保留，不在可走区烧进建筑、人、标识和文字。原图保留，新图使用版本化路径。

UI：直角或极小角度，深棕外轮廓、纸色内容区、薄金内边；按钮采用清楚的选中/禁用颜色，保留现有触控热区。去除大软投影和胶囊外形，硬边阶梯角饰由现有代码组件实现。正文不故意像素化到不可读。

战斗：沿用既有战斗模拟、操作、进出恢复与剧情结算。独立地表只替换表现背景，不更换地图/模拟状态；使用区域色调的原有地砖构成安静战场，不把探索栈道、轨道和路牌作为对阵背景。明确保留技能预兆与目标信息。
