### 5.1 BGM 候选清单（2026-09-19 夜间核查 · **需人工下载**）

夜间迭代尝试自动替换 6 首占位 BGM，核查结论如下（**没有下载任何文件**，避免引入许可不明的曲目）：

- ❌ **FreePD.com 已永久关闭**（站点公告：2008–2025，原公共领域曲库下线）——项目 README 里推荐过它，已失效。
- ⚠️ **OpenGameArt** 可访问，但**许可证必须逐曲在条目页确认**（搜索筛选 ID 只是查询条件，不能当许可结论），
  自动抓取拿不到可靠的"作者 + 许可 + 直链"三件套，故不在夜间自动下载。
- ⚠️ **Pixabay Music** 对本机返回 403（需登录/风控），不可自动取。
- ⚠️ **Incompetech（Kevin MacLeod）是 CC-BY**：用了必须在游戏内署名，能避则避。

**人工下载时的搜索关键词与筛选条件**（照这个口径挑，替同名文件即可，代码不用动）：

| 需要的槽位 | 搜索关键词 | 情绪/速度 | 时长 |

| `bgm_home.ogg` | `medieval tavern loop` / `peaceful village` | 温暖、木质感 | 60~120s |
| `bgm_city.ogg` | `medieval town day` / `market folk` | 轻快、有市集感 | 60~120s |

| `bgm_battle.ogg` | `epic battle loop` / `orchestral percussion battle` | 紧张、打击感 | 60~90s |
