### 2.1 验证（headless，改完代码必跑）

```powershell
$godot = "D:\godot\Godot_v4.6.1-stable_win64.exe"
$proj  = "d:\godot\new bee\远征"
$scenes = @("VerifyAssets","VerifyBattleScene","VerifyCity","VerifyGameHome",
            "VerifyMapScene","VerifyRouteScene","VerifyGacha","VerifyPanels")
foreach ($s in $scenes) {
  $out = (& $godot --headless --path $proj "res://tools/$s.tscn" 2>&1 | Out-String)
  $ok  = ($out -match "_OK all tests passed") -or ($out -match "ASSETS_OK")
  $bad = ($out -match "FAIL:") -or ($out -match "ASSETS_FAIL")
  "$s : " + $(if ($ok -and -not $bad) { "PASS" } else { "FAIL" })
}
```

判定口径：输出出现 `*_OK all tests passed` / `ASSETS_OK` 即通过；出现 `FAIL:` 则失败。

> `VerifyPanels` 会打印一行 `ERROR: Parse JSON failed`——这是「非法存档码」用例的**预期报错**，不是失败，只要结尾是 `PANELS_OK` 即可。

## 4. 素材取用机制（本轮刚修，务必理解）

```gdscript
G.res_tex("ui_banner_gacha")   # 按名取纹理，缺失返回 null（调用方自备回退画法）
G.res_path("...")              # 同上，返回路径
```

`G._build_res_index()` 的解析顺序：

1. **先扫 `ready/`**（递归各子目录，文件名即 key，如 `ui_banner_gacha.png`）
2. **再扫 `source/` 补位**（剥掉 `NNN_` 编号前缀作为 key）

**为什么必须 ready 优先**：`source/` 是 970~2170px 的原始 AI 母图，`ready/` 才是裁到设计尺寸、已硬化 alpha 的成品。之前只扫 `source/` 导致每个 UI 图标都在加载千像素大图（显存浪费），且会把 TextureRect 撑爆。

## 5. 必须遵守的硬性约束

1. **登录流程不可省**：`Title →「开始游戏」→ Login → 有档进主城 / 无档创角`。登录界面不能被存档跳过。
2. **反 AI 模板审美**：柔和下投影（`G._apply_shadow`）；圆角**刻意微差**（5/7/6/4 这类，别做成规整矩形）；金色按钮要有按压反馈（微暗 + 微缩回弹）。
3. **解锁 与 通关 是两种状态**，UI 上必须能区分。
4. **窗口居中、可关闭**。
5. **UI 一律走 `G.gd` 的主题工厂**（暖棕 + 羊皮纸 + 金；字号阶梯 13/16/18/22/30/56）；**文字严禁烧进图片**。
6. **数值全部表驱动**，不要硬编码进 GDScript。
7. 发现素材本身的问题，记进 [素材问题清单.md](素材问题清单.md)。

## 6. 本轮修掉的坑（**别再踩**）

### 坑 1｜`TextureRect` 的 `expand_mode` 必须在 `size` **之前**赋值

`Control.size` 只会被「顶大到不小于最小尺寸」，**不会自动缩回**。先设 `size` 再设 `expand_mode`，最小尺寸瞬间被钳到贴图原尺寸，`size` 随后被顶成原图大小。

症状：召唤横幅被撑成 **2172×724** 铺满面板，把「保底/出率/炼化规则」全压住不可读。

```gdscript
tr.expand_mode = TextureRect.EXPAND_IGNORE_SIZE   # ← 先这个
tr.custom_minimum_size = Vector2(w, h)
tr.size = Vector2(w, h)                           # ← 再这个
```

已修位置：`GachaPanel._tex_rect`、`TraitPicker` 流派图标、`CodexPanel` 头像与稀有度边框、`BattleScene` 战斗背景。**新写 TextureRect 时同样注意顺序。**

### 坑 2｜`PanelContainer` 会把每个直接子控件都铺满内容区

往 `G.gold_button()` 的返回值上再 `add_child` 一个 Label，两个 Label 会**完全重叠**（曾导致「十 连」盖在「800 魂石 / 1 券」上）。两行按钮必须用 `VBoxContainer` 竖排（见 `GachaPanel._gold_btn2`）。

### 坑 3｜GDScript lambda 捕获局部变量是**值拷贝**

```gdscript
var base_y := 0.0
root.ready.connect(func(): base_y = root.position.y)   # ✗ 外层永远看不到
```
曾导致 `TraitPicker` 悬停时 tween 到 `0-6=-6`，把整张卡推出屏幕。
**正确做法**：用 `set_meta` / 节点属性 / 数组容器传递可变状态。

### 坑 4｜Variant 推断警告被项目当错误

```gdscript
var mon_id := (lead_mon if i == 0 else pick.call())   # ✗ 编译失败（从 Variant 推断）
var mon_id: String = (lead_mon if i == 0 else pick.call())   # ✓ 显式标注
```
三元表达式 / `Dictionary.get()` 混类型时，一律**显式标注类型**。

### 坑 5｜终端是 PowerShell，不是 bash

- `tail` 不存在 → 用 `Select-Object -Last N`
- `Join-String` 在 PS 5.1 不存在 → 用 `-join` 或字符串拼接
- 给 Godot 传用户参数要加 `--` 分隔：`... ShotRunner.tscn -- --scene=gacha`
- 批量跑长时间命令时，`Start-Process -ArgumentList` 拼数组容易踩参数绑定错误，直接用 `& $exe args... | Out-String` 更稳

### 坑 6｜写完后台子代理产出必须主线程验证后再接线

不要直接信子代理的「已完成」，先跑对应 `VerifyX.tscn`。
