## 里程碑 A：P0 热修（8 项）

### A1 撤离重进无限刷 → 节点进度持久化

**改法**（核心原则：地图每次重建，但「打过什么」记在 RunState）：
1. `src/run/RunState.gd` 新增 `var map_state := {}`（键 `"%d_%d" % [layer, index]`；RunState 是会话态、不入存档，已核实无需迁移）。
   每节点存：`{"killed": [], "taken": [], "spots": [], "score": 0, "cleared_bonus": false, "boss_down": false}`。
2. `src/explore/MapScene.gd`：
   - 生成时给怪物/拾取物/兴趣点分配**稳定序号**（按 `_build_world` 的创建顺序 `enumerate`，见 `MapScene.gd:307-331` / `924-936` / `939+`）；
   - `_build_world` 末尾新增 `_restore_node_state()`：按 state 移除已击杀怪（`_monsters` 同步 erase、`_kills = killed.size()`）、已拾取物、已用兴趣点；恢复 `_score/_cleared_bonus`；`boss_down` 时直接解锁传送阵且不生成 BOSS；
   - 三个结算点回写 state：`_on_battle_end` 胜利（`MapScene.gd:1356` 附近，append 怪序号 + 写回）、`on_pickup`（`1067-1081`）、`_altar_pay`（`1038-1053`）；
   - 胜利结算加**防重保险**：`if state.killed.has(idx): 不再 add_reward/grant_drops`（防未来改动再次重复发放）。
3. 有意的行为保留：重进地图**同一布局**（种子不变），只是「打过的不复活」。

**回归**（VerifyMapScene 扩）：进节点 → 杀 1 怪 → 撤离 → 重进：怪少 1、金币不增、清剿赏/评价赏不重复、委托不重复上报；BOSS 已败重进传送阵解锁。

**风险**：序号稳定性依赖生成顺序确定性（现有 `_rng` 同种子同序，无并发）；若未来给装饰类单独开 RNG，需同步校验。

### A2 战斗「撤退」语义修正

**改法**：
- `src/battle/BattleScene.gd:688-694`：确认撤退时 `sim.result = "flee"`（不再写 `"defeat"`）；
- `_show_result` 增加 `flee` 分支：标题「已撤退 · 节点进度保留」、按钮「返 回」；
- `src/explore/MapScene.gd:_on_battle_end`（`1343-1355`）插入 `flee` 分支：`st.hp = hp_left`、`_contact_mon.chasing_contact=false`、toast「已撤退」、**不** `st.finished`、不结算奖励；
- 复用现有「怪复位」段（`1372-1375`）但不发奖励。

**回归**（VerifyMapScene）：flee 后 `st.finished==false`、节点可重进、hp = 战斗剩余值；低血提示文案不改（「补药或撤退」此后名副其实）。

### A3 存档导入生效

**改法**：
1. `src/autoload/G.gd`：把 `_ready` 中状态初始化抽成 `_init_state_defaults()`（覆盖 prog/wallet/items/city/quest/arena/account 等全部字段默认值）；
2. 新增 `func reload_save() -> bool`：`_init_state_defaults(); _load_save(); return true`；
3. `src/ui/SettingsPanel.gd:_on_import`（`483-499`）：写盘成功后改调 `G.reload_save()` → `G.go(TITLE_PATH)`；删除 `reload_current_scene()`。

**回归**（VerifyPanels 扩）：改内存钱包 → 导出 → 改回 → 导入：内存值 == 文件值；导入后立刻 `save_game()` 不覆盖导入内容。

**风险**：`reload_save` 需覆盖所有派生缓存（如 `ensure_starter_pets` 的重装）；实现时对照 `_ready` 逐行清点。

### A4 重置存档

**改法**：`G.gd:2053-2060` 重写 `gm_reset_save()`：
- 抽 `_default_city()/_default_quest()/_default_arena()`（从各初始化点复用）；
- 重置：`prog/wallet/items/city/quest/arena/account/player_name/avatar_id/avatar_use_custom`（保留 `avatar_custom` 磁盘文件）；`ensure_starter_pets()`；`save_game()`。

**回归**（VerifyPanels）：重置后 items 空、`city.built==["hall","gate"]`、quest 重刷、arena 清零、昵称清空。

### A5 宴会冷却

**改法**：`data/city.json:135-137` feast 加 `"cd": 14400`（4h，与征收同档）。
**加固**：新增校验（VerifyCity/VerifyPanels）：非 daily 活动必须 `cd>0` 或显式 `"unlimited": true`——杜绝「cd:0 = 无限次」的歧义再次出现。

### A6 吸血修正

**改法**：`src/combat/Combatant.gd:244` → `var lifesteal := (src.buff_pct_sum("lifesteal") if src != null else 0.0)`。
**回归**（verify_battle 增）：攻击方带 lifesteal 命中 → 攻击方回血；受击方带 lifesteal 被命中 → 攻击方不回血。
**风险**：顺带审计 `monsters.json` 所有 `lifesteal` 效果是否都作用于施法者（`SkillSystem.gd:203` 路径）；有目标型吸血要单独走查。

### A7 双刃词条数值

**改法**（`src/combat/TraitSystem.gd`）：把 4 处硬编码全部改读表：
- `passive_atk_pct`: `_sum_stat("atk")` + `de_ranxue.atk_pct` + `de_baojia.atk_pct`（`traits.json:85-89`）；
- `passive_def_pct` 的 `-0.25`、`passive_spd_pct` 的 `+0.25`、`passive_dmg_taken_pct` 的 `0.15`、`heal_taken_pct` 的 `-0.50` 同样从对应 `double` 条目读。

**回归**（verify_trait 增）：燃血 ATK+35%、薄甲 ATK+30%/DEF-25%、狂潮/死线数值与表一致（表改即测出）。

### A8 BOSS 召唤修复（数据为主）

**改法**：`data/monsters.json:16-17`：
```json
{ "id": "boss_summon", "name": "召唤狼群", "k": 0, "cd": 30, "target": "self",
  "effect": { "type": "summon" },
  "summon": "mon_wolf", "summon_count": 2, "summon_cap": 6 }
```
- `target:"self"` 让 `_pick_targets` 返回施法者（不再触发空目标早退，`SkillSystem.gd:108-110`）；
- `effect.type:"summon"` 命中现有 `SkillSystem.gd:159-162` 分支（代码读顶层 `summon/summon_count/summon_cap`，保持不变）。

**防御**：`VerifyData` 加断言「带 `summon` 字段的技能必须有 `effect.type=="summon"`」。
**回归**（verify_battle 增）：施放后场上 +2 狼（封顶 6）、事件 `"summon"` 出现。

## 里程碑 B：P1 修复（15 项）

### B1 每日免费抽 + 抽奖数据底座（gacha v2 第一步）
**数据**：`data/gacha.json` 升级（读取端一次性切换，不留双源）：
```json
{ "version": 2,
  "pools": [{ "id": "pet", "currency": "soul",
      "cost_single": 80, "cost_ten": 720,
      "rates": {"white":0.60,"blue":0.30,"purple":0.08,"gold":0.02},
      "pity": 60, "daily_free": 1, "ten_guarantee": "purple" }],
  "dup_gold": { "white":200,"blue":600,"purple":1500,"gold":4000 } }
```
（十连改 9 折 720；十连保底由「至少蓝」升为「至少紫」，对齐设计 §4.2/§4.3。）
**存档**：`prog["gacha"] = {"pity":0,"free_day":"","free_streak":0,"free_last":""}`；`_load_save` 迁移：旧 `items["gacha_pity"]` → `prog.gacha.pity` 并 erase；`SAVE_VERSION 2→3`（引入迁移框架，见 C-存档）。
**逻辑**（G 新增）：`gacha_state()/gacha_free_available()/gacha_mark_free()`；七连：`free_last==昨天` → streak+1，满 7 发魂石×50 并重置 streak。
**UI**（`GachaPanel`）：余额条下加「今日免费」按钮（未用高亮/已用灰显「明日再来」）；规则 ⓘ 补免费条款；保底显示兼容新结构。
**回归**（VerifyGacha）：同日二次拒；跨日可领；7 连发奖励；迁移正确；720/保紫断言更新（删掉旧「800/保蓝」锚点）。
**风险**：现有 `VerifyGacha.gd:51-52/107` 锚定旧口径，必须同步改——这是「测试锚定设计」的正面用法。

**决策点**：装备实例化（池 + 背包 + 强化对象改造）列入里程碑 D 单独评估，不随本轮。

### B5 连败保底礼包
`prog["lose_streak"]`：`RouteScene._show_end(false)` 时 +1，满 3 → 发 `soul×30 + pet_food×5`（结算页加一行 + toast）并清零；胜局清零。
**回归**（VerifyRouteScene 扩）：三连败恰好触发一次。

### B6 治疗口径统一（单一公式来源）
抽公共函数 `role_battle_max_hp(role_id, level, traits, growth)`，**严格复刻** `BattleSim.gd:75-83` 的截断顺序（先词条 int、后成长 int）；`BattleSim._build_role` 与 `RunState.max_hp()` 都改调它；`RunState` 加缓存（traits 变化失效）。
**回归**：带 growth 时 `map max_hp == battle max_hp`；篝火后 hp 不下降；血条 ≤100%。

### B7 空目标技能
`SkillSystem.resolve_cast`：**先解析目标再扣费**；目标为空且是伤害类 → 回退 `caster.lowest_hp(敌方)`；仍空（无敌人）→ 退还能量、清 CD、return。
**回归**（verify_battle）：前排全灭时 front_all 改打最低血单体；无敌人时不扣能量。

### B8 演武场平衡 + 超时平局
- `G.make_arena_foe`（`G.gd:2740-2751`）：血量改为按当前角色面板生成（`int(role_hp×2.2)`，下限 180）；`ai` 由 `"boss"` 改 `"basic"`（去掉 <30% 狂暴，`Combatant.gd:67-68`）；攻防按面板 ×1.15/×1.0；
- 超时：`BattleSim.gd:380-383` 的 `result` 改 `"draw"`；`ArenaPanel._on_battle_end` draw → 「未分胜负」不扣分；`MapScene` 显式把 draw 当败处理（注释说明）。
**回归**：verify_battle 的 draw 判定；VerifyArena 傀儡新数值；镜影模式回归不受影响。

### B9 自动前往打断
`MapScene._start_battle` 开头 `_stop_auto_walk()`；战斗结束后**不自动恢复**（罗盘需再点）。
**回归**（VerifyMapScene）：开战后 `_auto_walk==false`。

### B10 浮层冻结
新增 `_modal_open() -> bool`（battle/map_done/picker/big_map/altar/exit_ui/beat/trait_remove 全含），替换 `MapScene.gd:1711`（怪冻结）、`1294-1298`（接触判定）、交互物判定三处。
**回归**（VerifyMapScene）：开大地图时怪不移动、不触发开战。

### B11 cast 去重
技能槽加 `pending: bool`：`enqueue_cast` 置 true；`resolve_cast` 清 false；`can_cast` 开头 `if s.pending: return false`；单位死亡/退场时清所有 pending。
**回归**（verify_battle）：一次施法恰好 1 条 `cast_start`；前摇中 AI 不再重复入队。

### B12 词条三处
- 荆棘·小：数据改 `"hook":"passive", "effect":{"stat":"reflect","pct":0.08}`（仅改表，`reflect_pct()` 即可读到）；
- 弱点洞悉：实现 `crit_vs_full_hp` —— 新增 `traits.crit_bonus_vs(target)`，接入 `SkillSystem.gd:187` 与普攻掷骰两处；

**回归**（verify_trait）：三词条各自生效（含普攻处决）。

### B13 时间防线 + 委托池过滤
- `G.now_ts()`（`G.gd:611-612`）单调化：`t = maxi(系统时间, prog.last_ts)`，并把 `prog.last_ts` 随存取盘（D6）；
- `_refresh_quests`（`G.gd:1634-1656`）：建池时过滤未解锁世界的任务；不足 `daily_slots` 时回退到可完成池。
**回归**（VerifyQuests 扩）：回拨后签到/活动被拒；沙暴世界未解锁时不出沙漠委托。

### B14 自动前往寻路改良
- 卡住处理：记录失败侧 → 优先另侧 → 两侧都失败即停并提示「前路受阻」；
- 超时：26s → 按剩余距离动态（`maxi(20, dist / 100 × 3)`）；
- A*（栅格化 deco）列 D。
**回归**（VerifyMapScene）：模拟被挡住 → 最终停止且提示正确。

### B15 怪物碰撞
`_MapMonster extends Node2D` → `extends CharacterBody2D`（`MapScene.gd:1663`）：加 `CircleShape2D(_radius×0.8)`、`collision_mask=2`、`collision_layer=1`；`position +=` 改 `velocity + move_and_slide()`（游荡/追击/返回巢穴三处）。
**回归**（VerifyMapScene）：怪推向树 → 不穿入。
**风险**：`_draw` 自绘不受影响；接触判定是距离检测，与物理层互不干扰。
