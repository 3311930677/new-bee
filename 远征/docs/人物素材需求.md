# 人物 / NPC 素材需求（生成提示词手册）

> 用途：照着本文档生成主城 NPC 素材。生成后把 png 放进
> `image/generated_201_333/ready/npcs/`（或新建批次目录），文件名对得上即可，
> 游戏按文件名自动索引，不需要改代码也能被 `G.res_tex("文件名")` 找到。
> 开发侧接线（替换色块小人 / 对话立绘上屏）等素材到位后由开发完成。

---

## 1. 现状与目标

- 主城里 7 位 NPC + 每日 2 位来访旅人，目前是**程序画的色块小人**（长袍色块 + 圆头），廉价感来源之一。
- 主角（破军 pojun 等 4 人）是**日式 Q 版像素小人**，NPC 必须与主角同一画风、同一身高比例，否则同框违和。
- 已有 3 张 512×512 像素半身立绘（`npc_merchant` 胖商人 / `npc_blacksmith` 铁匠 / `npc_courier` 年轻信使），风格很好，**可继续沿用做对话立绘**，也可当新图的风格参考。

## 2. 统一规格（每张图都要满足）

| 项目 | 规格 |
|---|---|
| 画风 | 日式 Q 版像素风 RPG 小人，2.5~3 头身（chibi），深棕色像素描边，暖色手绘上色，阴影干净，不要渐变喷枪、不要 3D 渲染感 |
| 视角 | 45° 俯视 RPG 视角（与主角一致：看得到头顶和脸，不是纯正面平面） |
| 站姿 | 自然站立、全身入画、正面朝向（脸朝画面下方/观者） |
| 背景 | 纯透明（alpha）。不要白底、不要投影到地面外的多余元素 |
| 帧内位置 | 角色总高约 110px，**脚底贴 y≈120**，水平居中于 128×128 帧 |
| 描边 | 深棕（近黑）1px 像素描边，不要黑死边 |

### 三类图的画布布局

**A. 待机动画 idle（必需）** —— 替换色块小人靠它
- 画布 **512×128**，**4 帧横排**，每帧 128×128
- 4 帧为轻微呼吸/重心摆动循环（幅度小，不要夸张动作）
- 参考：主角 `image/role/zs/pojun_idle.png`

**B. 四方向行走 walk_4dir（可选，先不做也行）** —— NPC 目前站桩不走路
- 画布 **512×512**，**4 行 × 4 列**，每帧 128×128
- 行顺序固定：**第 1 行朝下走、第 2 行朝左走、第 3 行朝右走、第 4 行朝上走**
- 参考：主角 `image/role/zs/pojun_walk_4dir.png`

**C. 对话立绘 portrait（可选，多多益善）** —— 对话气泡旁的大头像
- 画布 **512×512**，半身像（胸部以上），透明背景
- 参考：`npc_merchant.png` / `npc_blacksmith.png` / `npc_courier.png`

### 文件命名

```
npc_<英文名>_idle.png        # 例：npc_steward_idle.png
npc_<英文名>_walk_4dir.png   # 例：npc_steward_walk_4dir.png
npc_<英文名>_portrait.png    # 例：npc_steward_portrait.png
```

放置目录：`image/generated_201_333/ready/npcs/`

### 通用负面提示词（每次生成都带上）

```
realistic, 3d render, watercolor, blurry, gradient shading, anti-aliased edges,
white background, multiple characters, text, watermark, extra limbs,
full body cut off, side view only, perspective distortion
```

## 3. 逐个 NPC 的设定与提示词

通用提示词骨架（英文，生成时把【外观描述】替换进去）：

```
pixel art RPG character sprite, chibi 2.5-head-tall proportions,
45-degree top-down view, full body, facing viewer, standing pose,
【外观描述】, dark brown pixel outline, warm hand-painted colors,
clean shading, transparent background, single 128x128 frame,
character about 110px tall, feet near bottom edge
```

> 生成 idle 图时：先要单帧站姿满意，再让模型出 4 帧微动条（或复制单帧手工微调）。
> 直接生成 512×128 四帧条常常帧间漂移，**建议按 128×128 单帧出 4 张，再拼成横条**。

### 3.1 闻叔 · 执事（npc_steward）

- 位置：议事厅前。50 岁上下的老城执事，管建设和杂务，温厚可靠。
- 外观：深棕/赭色长袍执事服，腰挂钥匙串，手持账册或木板夹，灰白鬓角，微胖，笑眼。

```
elderly male steward, around 50 years old, dark brown and ochre long robe
with sash, key ring at waist, holding a wooden ledger board, grey sideburns,
slightly plump, kind smiling eyes
```

### 3.2 老赵 · 城门卫（npc_guard）

- 位置：城门内侧。退伍老兵，管城门出入和访客簿。
- 外观：旧皮甲+铁盔（或头巾），手持长枪拄地，络腮胡，风霜脸，站姿笔直。

```
veteran gate guard, weathered face with short beard, worn leather armor
with iron pauldrons, cloth headwrap, holding a long spear planted upright
on the ground, straight military standing posture
```

### 3.3 青姨 · 图志阁掌事（npc_scribe）

- 位置：图志阁门口。中年女学者，管八片大陆的图志。
- 外观：青绿色长袍，发髻插木簪，怀抱一卷地图/书卷，眉眼温和但干练。

```
middle-aged female scholar, teal-green long robe, hair bun with wooden
hairpin, holding rolled map scrolls in arms, gentle but capable expression
```

### 3.4 阿豆 · 兽栏伙计（npc_keeper）

- 位置：兽栏。十五六岁少年，喂宠物刷毛干活，活泼。
- 外观：短打布衣+皮围裙，袖子挽起，手拿草料叉或毛刷，咧嘴笑。
- 对话立绘可用现成的 `npc_courier.png`（年轻信使气质接近）。

```
teenage stable boy, around 15 years old, short cloth tunic with leather
apron, rolled-up sleeves, holding a hay fork, cheerful grin, messy short hair
```

### 3.5 石头 · 铁匠（npc_smith）

- 位置：演武场边。壮汉铁匠，炉子还没点（锻造铺待开放）。
- 外观：赤膊肌肉+皮围裙，肩扛大铁锤，白胡子（与现有立绘一致）。
- 对话立绘直接用现成的 `npc_blacksmith.png`。

```
burly blacksmith, muscular bare arms, leather smithing apron,
carrying a large hammer over shoulder, white beard, fierce but friendly face
```

### 3.6 云游 · 行脚商人（npc_warden）

- 位置：城中走动。远方据点来的行脚商，见多识广。
- 外观：胖身材，宽檐帽插羽毛，披风挂满行囊小包，手持金币（与现有立绘一致）。
- 对话立绘直接用现成的 `npc_merchant.png`。

```
plump traveling merchant, wide-brimmed hat with a feather, cloak covered
with small bags and pouches, backpack with lantern, jolly bearded face,
holding up a gold coin
```

### 3.7 小满 · 城中孩童（npc_child）

- 位置：城中心空地。8~10 岁小孩，盼着祭坛修好。
- 外观：粗布短褂，冲天小辫，光脚或布鞋，仰头看的姿势，个高明显比成人矮一头（帧内高约 70~80px 即可）。

```
small kid around 8 years old, simple cloth jacket, little topknot pigtail,
looking up curiously, noticeably shorter than adult characters
```

### 3.8 来访旅人 ×2（npc_guest）

- 位置：每日从城门进来 2 位，来自不同据点（青石堡/落雁渡……）。
- 外观：**一张通用图即可**——靛青连帽斗篷，背大行囊，斗篷半遮脸（省去画脸也省事，还能营造「每天来的人不一样」的想象）。

```
hooded traveler, indigo-blue hooded cloak half-covering the face,
large backpack with bedroll, walking staff, mysterious wanderer look
```

## 4. 交付检查清单（图给我之前自查）

- [ ] 尺寸对：idle 512×128 / walk 512×512 / portrait 512×512
- [ ] 透明背景，无白边、无杂色描边光晕
- [ ] 帧内角色脚底贴底（y≈120），水平居中
- [ ] 身高与主角一致：成人约 110px；小满约 70~80px
- [ ] 同一角色的 idle / walk / portrait 长得是同一个人（发色、服装、配饰一致）
- [ ] walk_4dir 行序 = 下/左/右/上，每行 4 帧
- [ ] 文件名符合 `npc_<id>_<kind>.png`

## 5. 素材到位后的接线（开发侧备忘）

1. png 放入 `image/generated_201_333/ready/npcs/`，无需登记（res_tex 按文件名索引）。
2. `CityScene._CityNPC` 由「程序绘制」改为「贴图优先、色块回退」：
   - `G.res_tex("npc_<id>_idle")` 命中则用 AnimatedSprite2D 播 4 帧呼吸；否则沿用现有色块画法。
   - id 映射：city.json 的 npc id（npc_steward 等）直接作文件名前缀；旅人统一 `npc_guest_idle`。
3. 对话框旁加立绘位：`G.res_tex("npc_<id>_portrait")` 命中则在对话浮层左侧显示半身像。
4. 跑 `VerifyCity` + `ShotRunner --scene=city` 截图复查。
