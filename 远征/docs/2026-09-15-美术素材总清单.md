## 0. 全局规范

**风格锚点（所有生成图统一）**：3/4 俯视角 2D 像素、2.5 头身、深棕硬边轮廓、24~32 色固定色板、暖金底 + 暗红/青蓝高亮、透明背景（背景图除外）、**无任何文字**（中文一律 Godot NotoSansSC 实时渲染）。

**锚点先行顺序**：3 张批准锚点（破军设定母图 / bg_forest 森林背景 / UI 面板皮肤）人工批准后锁定，其余全部带锚点参考图生成。

**目录约定**（沿用现有 `image/` 主目录；`assets/` 仅放字体；`assets/role/` 旧目录待合并清理）：

```
image/
  background/   战斗背景 8 主题 + 主界面/路线图底板
  role/         4 人物（现有 zs/ck/fs/fz 子目录）
  pet/          宠物（id 子目录）
  monster/      怪物（id 子目录）
  mount/        坐骑
  fx/           技能/状态/通用特效（帧序列）
  ui/           面板纹样/稀有度框/底板
  icon/         buff/技能/物品/货币/节点/流派 小图标
  npc/          NPC 立绘
```

**命名规范（与 data 表 id 严格对齐，snake_case）**：

| 类型 | 模板 | 示例 |
|---|---|---|
| 战斗背景 | `bg_{theme}` | bg_forest / bg_snowfield |
| 技能特效 | `fx_{技能id}` | fx_zs_lieshan |
| 技能图标 | `sk_{技能id}` | sk_fs_shuangren |
| buff 图标 | `buff_{id}` | buff_bleed |
| 怪物 | `mon_{id}` | mon_wolf |
| 宠物 | `pet_{id}` | pet_frostwolf |
| 路线节点 | `node_{type}` | node_elite |
| 稀有度框 | `frame_{稀有度}` | frame_gold |
| 货币 | `cur_{货币}` | cur_soul |
| 物品 | `itm_{id}` | itm_pet_food |
| 段位徽章 | `rank_{段位}` | rank_diamond |

帧序列命名：`{名}_0001.png` 起连续编号。

**尺寸速查**：背景 480×800（PNG 不透明）｜头像 128×128｜技能 icon 64×64｜物品/节点 icon 48×48｜buff/货币 icon 32×32｜单位单帧 ≤96×96｜NPC 立绘 512×512+｜应用 icon 512×512。

**通用规则**：母图批准后派生（裁切/缩放/切帧）全部走确定性工具（pillow 脚本 + `tools/normalize_sprite_sheet.py`），逐帧动画绝不由 AI 独立生成；版权红线——旧素材仅参考抽象特征，不进发行包。

## 6. 程序生成项（🔧 永不进 AI，全部引擎/脚本完成）

- HP/能量条、CD 遮罩、站位格、路线连接线、红点——Godot Control/StyleBox 绘制
- 精英怪变色变体——hue-shift 脚本
- 稀有度框着色变体、头像/图鉴裁切、帧切分与对齐——pillow + `tools/normalize_sprite_sheet.py`
- 全部中文文字——NotoSansSC 实时渲染
- 抽取动效占位（翻转卡+纯色粒子）——Tween 先行，母稿到位后替换
