## 二、世界观与主线剧情 ✅

readme.txt 原文整理（创世—政变—寻友三幕结构）：

1. **创世**：洪荒时期，造物神「帕拉多」受命创造天狼星系。他将橙色气体行星「欢愉」实体化，注入岩石、气流、烈火与海洋，更名为「帕拉多诺」后离去。
2. **乱世**：帕拉多诺大陆百年演化，各国为领土/资源/意识形态混战。人类王国「洛林国」正值内忧外患。
3. **主角**：因父亲战功，主角被送入皇宫当骑士侍童，与「钢剑王子」在花园偶遇结为挚友。
4. **政变**：骑士团长「毒矛」借演习之名发动政变，御林军一日之内被解除武装。宫廷侍卫长「月影」携主角与王子连夜出逃，隐居偏僻的「枫林村」，月影兼任二人的武学与法术导师。
5. **启程**：数年后，神秘陌生人单独会见钢剑王子后，王子不辞而别。主角辞别月影，踏上寻找钢剑的冒险之旅。

**关键设定**：主角（骑士侍童出身）、钢剑王子（挚友/寻访目标）、月影（导师）、毒矛（政变反派）、枫林村（新手村原型）、洛林国/希望之都（主城原型）。

截图：`ref_video/05_map_grass.png`｜`06_map_grass2.png`｜`09_map_desert.png`｜`10_map_desert_tree.png`｜`13_map_forest.png`｜`15_map_pine.png`

**关键画风参数（实测）**
- **草地**：亮黄绿主色 + **深绿斑块**做自然浓淡 + 近白色细碎噪点，覆盖密度高（非纯色平铺）。
- **土路**：**米白/浅卡其**色，边缘**犬牙交错**、非常规曲线，路面散布细碎石点。
- **沙土地**：橙黄沙底 + **米白浅色斑块**，两者之间为**锯齿/毛边硬过渡**（非渐变），边缘带深橙描点。
- **树**：两类 —— ① 金绿/黄绿圆冠大树（草原/森林）② **紫红粉白圆冠树**（沙漠秋色）；树干棕褐，带**椭圆投影**。
- **装饰**：深褐苔石堆、细草丛、白色小碎花、木桩。
- **遭遇战横幅**：进入战斗时顶部中央出现橙红描边「**遭遇战**」字样。

### 11.3 实时战斗 ✅实录（⚠️ 推翻 §5.1 回合制推断）

- **怪物为地图明雷**：僵尸(Lv12)、落叶蛙(Lv8) 等**直接在地图上行走**，玩家靠近/接触即触发战斗。
- **实时动作制**（非回合指令），表现层包含：
  - 玩家与怪物**同屏对峙**；角色持**双弯刀**，攻击时出现**青蓝色弧光**刀迹。
  - **伤害飘字**：`-42` **黄橙渐变大字** + **技能名**（如「重击」）叠于下方，带深色描边。
  - **命中特效**：**白黄五角星爆 + 橙色放射光线**（像素星芒）。
  - **血蓝条在角色脚下**：**红条 = HP / 蓝条 = MP**；怪物用红条。
  - 右下角红色「**自动**」按钮 = **自动战斗**开关。
  - 存在「**失败**」横幅 → 有败北结算（见 `ref_video/22_zoom_sand_terrain.png`）。
- **名称标签配色**（复刻需对齐）：NPC 名 = **绿色**（如「熟采薇10」）｜怪物 = **紫色「Lv{n}名」**（Lv12僵尸 / Lv8落叶蛙）｜选中目标 → 顶部弹出**目标名条**（如「升降梯守卫」，`ref_video/12_ui_targetbar.png`）。
- 场景交互标记：NPC 头顶**红色菱形**（任务/采集点）+ 指引箭头（对应 §4.3 的 `infoarrow`）。

截图：`ref_video/07_combat_hit.png`（`-42 重击` + 星爆）｜`21_zoom_actor.png`｜`23_zoom_purple_tree.png`

> **对复刻的意义（重大利好）**：远征现有战斗已是**实时 sim + 飘字 + 命中特效 + 自动战斗**，与原版实时制**天然同构**。因此 refit 方案中「远征实时 sim 改回合制」的决策**已改为保留实时制**（✅ 2026-09-21 落地：refit Task 2.1 重写为「战斗表现对齐」）—— 不仅更还原，改造量也大幅下降（仅需补：遭遇战横幅、目标名条、红蓝条脚下化、标签配色）。
