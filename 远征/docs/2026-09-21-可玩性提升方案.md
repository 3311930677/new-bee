# 《远征》可玩性提升方案（2026-09-21）

> 定位：本文是**审查结论 + 实施计划**二合一。审查部分只收「已逐行复核」的条目（子代理报告里未能自己确认的放附录 §8 待复核），实施部分按 A→B→C→D 四批推进。
> 依据：`src/combat/*`（7 个 .gd）、`src/battle/BattleScene.gd`、`src/explore/MapScene.gd`、`src/run/RunState.gd`、`src/autoload/G.gd`、`src/save/SaveData.gd`、`src/ui/{EquipPanel,DeployPanel,GameHome}.gd`，以及 `data/` 全 23 张表。
> 复核方式：逐行读源码 + `data` 表交叉核对 + 实跑 `tools/run_regression.ps1 -Only VerifyArena`（PASS，据此剔除了「竞技场连胜不落档」这条误报）。
> 素材：**本方案零新增素材**（全部程序绘制 / 表驱动），符合「无素材也能跑」口径。

---

## 0. 一句话诊断

1. **已经写好的构筑系统玩家摸不到**：一局是 3 层 + BOSS（每层 3 选 1），战斗节点通常 3~4 个 → 词条三选一也就 3~4 次（`nodes.json:4-6`）；六流派却要**同系 3 件**才激活（`TraitSystem.gd:51-52`），且三个槽位有限制（`RunState.gd:118-131`）→ 数学上几乎凑不出三件套；更糟的是**流派核心词条本身不生效**（见 A 批）。
2. **3 选 1 有类型信息、没有代价信息**：路线图节点已带类型徽章与名字（`RouteScene.gd:14-22` `NODE_META`、`_RouteNode._draw`），「精英 / 宝箱 / 商店」是有信息的选择；但精英强多少（1.8× 属性、挂什么词缀）玩家一概不知，战斗里也看不出档位（B4）——类型可见、代价不可见。再叠加 HP 漏洞（A6 送死换满血），「打精英要掉血」的风险感也不成立。
3. **战斗里只有一个决策，且能被托管无损替代**：托管与手动共用同一套出手条件（`MonsterAI.gd:70-75`：大招满能量即放、中费留 20 缓冲、小技能够就放），没有任何手动专属收益。
4. **八个世界只差数值**：`×(1+0.12N)`（`nodes.json:8`），玩法元素从第 1 个世界起就全部见过了。

## 1. A 批：把「写了却没生效」的战斗效果修好（P1）

> 这批纯修行为，**不改设计口径、不动数值**，是性价比最高的一步。全部集中在 `Combatant / TraitSystem / SkillSystem / BattleSim` 四处。

## 3. C 批：八世界主题规则（先做 3 条，其余按模板）

玩法元素从第 1 个世界起就全见过，是当前最大的「新鲜感缺口」。给每个世界一条**纯表驱动**的规则，成本最低、感知最强。

**表结构**（`maps.json` 每个主题加一段）：

```json
"rule": { "id": "volcano_burn", "name": "灼热之地",
          "params": { "interval": 6.0, "hp_pct": 0.02 } }
```

**先做 3 条（覆盖 3 种实现路径，后续照抄）**

| 世界 | 规则 | 实现路径 | 参数 |
|---|---|---|---|
| 火山 | 每 6s 最大生命者受 2% MaxHP 灼烧（双向） | `BattleSim.step` 里 tick 计时 + `_direct_damage(dmg, null, sim)`——src 传 null：环境伤害**不占击杀归属**（A2 的 on_kill 不会因灼烧收尾误记），也不触发受击钩子（与 A1 解耦） | `interval/hp_pct` |
| 雪原 | 每 8s 全场减速 15%×2s（冰面打滑） | 复用 `add_buff("slow")` | `interval/dur/pct` |
| 深渊 | 小地图敌影揭示半径减半（520 → 260） | **不是零代码**：`map_reveal_radius` 读的是 maps.json **顶层**（`MapScene.gd:2145`；`_map_cfg` 来自 `TableCache.maps_config()`，`:104`），主题条目里改不动它 → 在 MapScene 按主题 rule 覆盖，且必须 `duplicate()` 后再写（原地改 `_map_cfg` 同样会污染缓存） | `reveal_mult` |

剩 5 条（森林：拾取 ×2；墓穴：击杀 30% 复起半血；荒漠：能量回复减半；冰川：控制时长 +50%；王城：精英全带词缀但掉落翻倍）按上面同一个模板往里加，**每条只动数据 + 一处 if**。

**验收**：`VerifyMapScene.gd` 断言「规则生效（灼烧掉血 / 减速 buff 存在 / 揭示半径按规则变化）」与「无 rule 的主题行为不变」；`VerifyBattleScene.gd` 断言灼烧不触发受击钩子（防与 A1 打架）。

## 5. 需要产品拍板（我不替你决定）

1. **人物 0 血（宠物收尾获胜）怎么算**：① 本局直接失败（最严肃，但玩家会觉得「宠物赢了却输了」）；② 按 1 血续战（保留宠物价值，但 0 血设计失去意义）；③ 0 血续战但**不能吃药/不能出战**（折中）。**A6 必须先定口径再改**。
2. **流派激活阈值 2 还是 3**：2 = 每局都能成流派；3 = 稀有高光。建议 2，并在 B3（精英额外选择）后观察一版。
3. **精英的回报权重**：额外一次词条选择（构筑向）vs 掉落翻倍（经济向），还是两者都给一点。
4. **世界主题规则是否双向生效**：火山灼烧/雪原减速如果只打敌人会变成纯福利；双向更硬核，但雪原会同时惩罚玩家走位。

## 6. 实施顺序与风险

| 批次 | 内容 | 预估 | 风险 |
