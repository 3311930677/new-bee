# 野外 HUD 视觉重构 · 2026-10-15

已生成成熟像素手游参考图，并将重点设计接入 `远征` 的实时野外界面。

## 设计方向

深色木漆面、旧铜双层包边、像素角码和铆钉，配合暖白文字、玉绿生命条与蓝色历练条。装饰集中在界面边缘，保留中央探索视野。

- 角色状态：独立等级徽章、内凹状态条、细像素高光，低血量显示红色。
- 任务栏：主线小印与标题层级，长任务支持两行，保留完整提示与原有任务入口。
- 小地图：阶梯像素铜环与四向刻度，使用当前实际地表缩略，图外标记收在圆内。
- 操作盘：伙伴、疾行、药剂和情境交互使用统一金属边缘；疾行增加玉绿选中标记，药剂耗尽变灰并显示数量。
- 摇杆与名字牌：统一材质，保持摇杆底座透视地面。
