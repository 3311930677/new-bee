## 工程判断与差异

- 原 `node_campfire` 实际为篝火，而非验收描述的帐篷，因此补一枚 72px 源、24px 显示的原生 SVG 帐篷。没有用细线房屋符号替代。
- 生成模型输出的源画布比指定尺寸大：字标源为 1983×793，Godot 导入限制为 900 并生成 mipmaps；显示仍为 300×120，阴影独立绘制。源文件和完整提示词保存在素材目录的 generation_manifest.json。
- 天空输出包含完整延展场景，但工程只取上部天空。下部原街道继续使用原文件，融合由原生 shader 实现，不采纳模型重画后的建筑或街道。
- 地形缩略图是工程数据：真实底图的道路分叉保留，颜色归纳为草地/沙路/建筑；非整图地面使用实际道路中心线及宽度。它是导航示意，不作为碰撞判定。建筑标记只有已落成状态，NPC 来自实际实体。
- 任务目标优先指向当前地图的主线 NPC/实体，否则沿用既有导航目标。该选择只用于显示，没有改变自动行走目的地、镜头、碰撞和任务结算。
- 灰度图使用 Godot 原生屏幕 shader 当场渲染，未对截图做后期调整。暗铜环与指定沙路色的计算对比为 3.59:1；复杂地面上是否始终好读还需设备验收。

## 验证

截图与专项检查通过 **567 项，0 失败**；包含 37 张原生截图、真实鼠标/键盘操作、触控摇杆、地图与小地图共享数据、安全区、药剂数量/治疗、疾行两态、任务收合及交互入口。文字审计未发现错误采样、小字号艺术字或不足字框。

交互圆盘两张诊断图在相同真实距离下暂停自动接触那一步，以拍到自动对话触发前的可用状态；有效距离内的真实点击确认打开原 NPC 对话。平时的靠近自动互动没有改为必须点圆盘。

相关 VerifyMainWorld、VerifySafeArea、VerifyPerf、VerifyNav、VerifySave 回归通过。存档与截图均隔离。首次图形采样遇到原设置页的系统剪贴板读取错误，截图模式现已明确跳过剪贴板；正常设置功能保持原行为。最终图形采样没有脚本错误或剪贴板错误，既有引擎退出时的资源清理诊断继续保留。

城镇左右半透明木板为本轮验收排除的既有地图问题，本轮未修改。截图不等于实体手机触控、性能与所有地图状态的验收。
