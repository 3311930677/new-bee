# 《远征》第一轮 V1 视觉验收修复单（启动菜单 + 城镇 HUD）

> 依据：`README.md`、`UI_MASTER_SPEC.md`、`MAIN_SCENES_UI_PLAN.md`，以及 `title_before/after.png`、`world_before/after.png`、`title_after_long.png`、`world_after_long.png`（2026-10-09 Godot 原生渲染）。
> 坐标为 480 宽逻辑像素，由截图目测，误差约 ±4px。
> 总体判断：两页相对 before 都**明显改善**。Title 去掉中央对话框后形成“街道 → 开始游戏”的单一主动作；HUD 顶部统一为一种漆墨容器，任务收窄到左侧 x12–228，最低到 y≈168，y190 以后的游玩视野已净空；右下由四个等重方块改为圆盘，营帐也移出了拇指区。以下只列剩余最影响质感的 5 项。
> 范围说明：城镇画面左右边缘的半透明木板/墙块（after 中 x0–60、y195–345 与 y545–665，以及右侧 x435–480），在 before 右侧 x435–480、y205–330 已经存在，因此归为**既有场景问题，待实机核实**，不计入本单，也不要求改地图。

## 1. Title：品牌区仍是旧模板 Logo，长屏顶部是空白色带并露出接缝（素材阻塞，单一资产需求）

1. **位置**：Title 480×800，Logo 位于 x82–398、y68–228。Title 480×1067 中，天空延展在 y0–≈265，Logo 在 y≈175–335，正压在延展层与原背景天空的交界（y≈265–300）上。
2. **证据与改善**：Logo 已从约 360 宽缩到约 316 宽，城门（y≈190–270）重新露出，这是有效改善。但对话框移除后，翅膀、青宝石、绿缎带成了画面里唯一的高饱和冷色块，也是最大的装饰物，第一眼仍落在它上面。长屏顶部约 170px 是一块无内容的平涂渐变，Logo 两翼横跨交界，接缝可见。
3. **影响**：这是首屏的第一印象，模板化的 Logo 会直接抵消下半屏的改善。长屏上的空色带和接缝会被看成“没铺满”的半成品。
4. **目标与要求**：
   - 按规范 §4.1 交付 T-LOGO-WORD：“远征”书法字标，铜漆质感，无翅膀、无宝石。显示 300×120，放在 (90,72)。
   - 副标题改为实时文字，按 PLAN §1.2 T5 排版（x110、y200、w260、h28），字体 NotoSerif SemiBold 18，字距 +6，颜色 `#D9BE8A`。两侧各一条 48 宽的 U-RULE-BRONZE。
   - 按 §4.1 交付 T-BG-SKY-EXT，与原背景无缝衔接。
   - **补充要求**：长屏下的品牌区不能横跨未融合的接缝。天空延展的透明融合带不少于 33px（§4.1 的值）。若最终 Logo 仍落在融合带内，需在 100% 原尺寸截图中看不出水平分界。
   - 素材到位前不改动现有坐标，工程端无需返工。
5. **新素材**：需要。
   - **T-LOGO-WORD**：显示 300×120，源图 900×360，透明。拆两层：字形本体、2px 暗影。线性过滤 + mipmap。不含副标题文字。
   - **T-SEAL**（增强）：显示 20×20，源图 60×60，透明，压在字标右下角。
   - **T-BG-SKY-EXT**：显示 480×300，像素密度与 T-BG-STREET 相同，最近邻过滤。底部 33px 渐隐为透明。内容是黄昏渐变延续加 2–3 条云带，不加月亮或星点这类会抢焦点的元素。
   - **U-RULE-BRONZE**：显示 48×6，源图 96×12，左右各 12px 源像素不可拉伸。
6. **优先级与完成标准**：P1（素材阻塞，最高画面影响）。
   - 480×800 与 480×1067 两张截图中，品牌区不再出现青色或绿色。
   - 副标题能被选中、可以改字，即为实时文字。
   - 长屏在 100% 缩放下看不到天空接缝。
   - 字标底边到“开始游戏”顶边至少 160。

## 2. HUD：小地图内容仍不可辨（框体已改，内容没改）

1. **位置**：城镇 HUD 小地图 x364–468、y12–116，地图井 x368–464、y16–112。
2. **证据与改善**：框体已达标：去掉了“地图/展开地图”两行字，“北”放在右上，展开角标在右下。但地图井里仍是深青色底，只有一条竖向虚线、3–4 个点和一个白色箭头（约在 414,88）。实际画面中清楚的沙路分叉、右侧塔楼和草地，在小地图上都认不出来。这一项与 before 基本相同，规范列的第 7 个问题未解决。
3. **影响**：小地图是 HUD 里唯一的导航与目标提示。内容抽象成几个点，读起来像占位控件，“位置/目标提示”这项功能合同也没有真正兑现。
4. **目标与要求**（PLAN §2.2 H4、§2.4，SPEC §4.3 M-*）：
   - 地图井 96×96 显示地形简化图，用最近邻过滤：
     - 可行走路面 `#C9B88A`
     - 草地 `#5E7A45`，整体压暗 25%
     - 建筑/阻挡 `#3A3238`
   - 标记：
     - M-PLAYER：9×9 朝向箭头，纸白 `#F3E8D0` 加 1px 影，固定在井中心。
     - M-TARGET：9×9 灯金 `#F0B95A`，可加两帧闪烁。
     - M-NPC：5×5 旧纸色 `#BFB096`。
     - 目标在井外时，贴井边显示并带方向缺口。
   - **补充要求**：地形图来源由工程决定，可以运行时从现有图块或碰撞数据生成，也可以每张地图预生成一张缩略图。比例固定，具体比例待实机核实。不在图中烘焙任何文字。展开地图使用同一份数据。
5. **新素材**：
   - M-PLAYER、M-TARGET、M-NPC：像素小图，1× 源图，透明，规格按 §4.3。
   - 地形缩略图：属于工程产物，不是美术素材。
6. **优先级与完成标准**：P1（工程可立即做）。
   - 在 world_after 同一站位截图中，小地图里能认出沙路分叉和右侧塔楼的位置。
   - 灰度截图中玩家、目标、NPC 三种标记可以区分。
   - 展开地图与小地图的地形一致。

## 3. HUD：营帐与任务收合使用网页线框图标，语义也不对

1. **位置**：
   - 营帐按钮的图标在 x320–348、y20–42。
   - 任务收合按钮 x230–270、y76–118，图标为“≡”。
   - 疾行图标“»”在 x342–370、y738–756。
2. **证据与改善**：营帐从 before 的像素帐篷火光图标换成了细线“房屋”图标，属于**退步**。任务收合用的是汉堡菜单“≡”。药剂瓶、伙伴爪印是像素填色图标，与这几个线框图标并排，粗细和填充方式明显是两套。
3. **影响**：细线库图标是网页/后台的典型符号，放在像素世界里最显廉价。“≡”通常表示全局菜单，会让玩家误以为这里是主菜单，而不是收合任务；房屋图标也表达不出“回营帐”。
4. **目标与要求**（SPEC §2.4、§4.3）：
   - HUD 图标统一用硬剪影填色，显示尺度 1px 暗轮廓，不超过 5 级色阶，线性过滤 + mipmap，禁止只有描边的图标。
   - **V1 立即替换**（复用现有素材，零新增）：
     - 营帐改回 before 中的像素帐篷图标，显示 24。
     - 任务收合改用 before 主线行里的卷轴/纸签图标，显示 24。收起状态按 PLAN §2.5 显示主线签头色和“+N”角标。
   - **V2**：按 §4.3 交付 I-CAMP、I-QUEST、I-SPRINT-OFF/ON、I-EXIT。
   - 疾行开关仍需按 C-TOGGLE 做到图标与“疾行中”文字双重区分。after 截图只有关闭态，开启态**待实机核实**。
5. **新素材**：V1 不需要。V2 需要以下素材，均透明、单层、线性 + mipmap：

   | 素材 | 显示尺寸 | 源图尺寸 | 状态 |
   |---|---|---|---|
   | I-CAMP | 24 | 72 | — |
   | I-QUEST | 24 | 72 | — |
   | I-EXIT | 24 | 72 | — |
   | I-SPRINT-OFF / ON | 28 | 84 | 关、开两张 |

6. **优先级与完成标准**：P1（V1 只需替换资源）。
   - HUD 内不再出现只有描边的图标。
   - 营帐图标灰度下可辨认为帐篷。
   - 任务收合图标不是“≡”。
   - 灰度截图中所有 HUD 图标的轮廓粗细一致。

## 4. HUD：摇杆与右下圆盘在亮场偏弱，材质与数量角标不统一

1. **位置**：
   - 摇杆 x38–130、y652–746。
   - 伙伴 x412–466、y644–698；药剂 x404–468、y716–780；疾行 x328–384、y724–780。
   - 药剂数量“2”约在 (446,722)。
2. **证据与改善**：圆盘的层级、位置和热区间距符合 PLAN §2.2，营帐离开拇指区，相对 before 是结构性改善。剩余问题有三处：
   - 摇杆是白色半透明玻璃质感，是 HUD 里唯一的白玻璃材质，在黄绿草地上几乎褪色。
   - 圆盘边缘是很细的浅色线，底色透明度偏高，压在 NPC 精灵上时（例如疾行圆盘下的斗篷人）图标被干扰。
   - 圆盘内图标只有约 20px，四周空。药剂数量是裸露数字，没有角标底，看起来像漂浮的杂字。
3. **影响**：拇指操作区是触控游戏最常看的位置。材质不统一、亮场看不清，会让 HUD 显得像临时叠加层，而不是一套器物。
4. **目标与要求**（SPEC §2.5、§3 C-ACTION-DISC / C-DOT，§4.2 U-DISC / U-JOY / U-BADGE）：
   - **圆盘**：底色漆墨 `#17151A`，不透明度 78%，需实测当前值。外 1px 暗铜 `#6E5434`，再加 1px 影 `#0A090B` 40% 外描，用于亮场。图标显示从约 20 提到 28；名称保持 12px Bold。
   - **药剂角标**：U-BADGE，18 高，放在 (448,712)。漆墨底、1px 暗铜边、纸白 12px Bold。数量为 0 时角标改灰烬色，图标去饱和。
   - **摇杆**：取消白玻璃。底盘 104 直径，漆墨，闲置 35% / 触摸 70%，加 1px 暗铜环。摇杆钮 44 直径，漆墨 85%，顶部 1px 亮铜高光。
   - **补充要求**：闲置时摇杆环在最亮的沙路（`#C9B88A` 附近）上仍要清晰可见。目标是环与沙路的亮度对比不低于 3:1，以灰度截图目测为准。
   - 骑乘入口与靠近自动交互保持工程现状。交互圆盘出现时与其他圆盘的间距按 PLAN §2.2，**待实机核实**，因为本组截图里没有出现交互态。
5. **新素材**：V1 可以用 StyleBoxFlat 和纯色圆实现，不阻塞。V2 需要：

   | 素材 | 显示尺寸 | 源图尺寸 | 状态 / 规格 |
   |---|---|---|---|
   | U-DISC | 56 / 64 / 76 | 228×228 | default、pressed、disabled、toggle-on 四张 |
   | U-JOY-BASE | 104 | 312 | 透明 |
   | U-JOY-KNOB | 44 | 132 | 透明 |
   | U-BADGE | 18 高 | 36×36 | 横向 12/12 九宫格 |

6. **优先级与完成标准**：P2。
   - 在 world_after 同站位的灰度截图中，摇杆环和三个圆盘的边缘都清晰。
   - 药剂数量放在角标底上。
   - 补拍药剂为 0 的截图，确认角标与图标的灰化状态。
   - 圆盘图标量得 28px。

## 5. Title：开始按钮用浅色圆角描边，次级入口缺分隔与“退出”降级

1. **位置**：
   - 开始游戏 x96–384、y544–614，约 288×70。
   - 次级行文字基线约 y659：介绍 x102–170，设置 x206–274，退出 x310–378。
2. **证据与改善**：“唯一主动作 + 一行轻量入口”已经成立，相对 before 的四个等重按钮加面板是本轮最大改善。剩余问题：
   - 按钮外框是浅米色约 2px 的圆角描边，是下半屏最亮的线条，读起来像网页上带描边的主按钮。
   - 尺寸比规范大约 8×6。
   - 次级行没有分隔铜点，“退出游戏”与另外两项同色同重。
3. **影响**：主按钮是首屏唯一的行动点，它的边框决定整页材质是“器物”还是“网页”。退出入口与其他入口同重，也不符合“低频”的要求。
4. **目标与要求**（SPEC §2.5、§3 C-BTN-PRIMARY / C-ENTRY-TEXT，PLAN §1.2 T6–T11）：
   - **主按钮**：尺寸 280×64，位置 (100,548)。面色朱漆 `#6A2B1F`。双色边：外 1px 暗铜 `#6E5434`，内 1px 亮铜 `#C29A5B`，顶边内侧 1px 亮铜 30% 高光。V1 先用直角或圆角 ≤1px，替代当前的大圆角浅边。
   - **分隔点**：补 T8、T10 两个 4×4 亮铜点，位于 (186,656) 和 (290,656)。
   - **退出游戏**：文字色改为 `#9E9381`。
   - **次级行文字**：保持 NotoSerif SemiBold 17，颜色 `#BFB096`，加 1px 影。
   - 热区仍为 88×44，不变。
5. **新素材**：V1 不需要。V2 用 U-BTN-PRIMARY-9：源图 560×128，九宫格左右 40、上下 24，两端铜钉放在不可拉伸区。共 default、pressed、disabled 三张，透明，线性过滤。
6. **优先级与完成标准**：P2。
   - 480×800 截图中主按钮量得 280×64。
   - 按钮边框不再是浅米色，也不是 y500 以下最亮的线条。
   - 两个分隔点存在。
   - “退出游戏”可见地比另外两项暗一级。
   - 补拍键盘焦点截图，焦点环与按下态外观不同。
