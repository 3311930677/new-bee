**选B。** 单靠美术解决不了问题2、3：建筑中心离街太远，竖屏下必被裁切；城门与出口方向矛盾属于布局问题。野外路网线形保留，问题出在“同宽同材质”且缺少让环路成立的地形，所以靠地形和材质分级就能解决。

- **保留**：城镇南北主街中轴与北出口；野外全部6条路线中心线、3个出口、3个到达点；两图尺寸960×1248；相机1.15。
- **重做**：城镇建筑与NPC布局、城墙边界、广场、后巷；野外新增溪、潭、石桥、浅滩，改变各级道路的视觉宽度，重排部分交互点与敌人；全部地表、景观和待建表现。画风改为参考图1的明亮16-bit像素；构图采用参考图2的框景：每个视口左右边缘由密集树冠或屋檐围住，中间留出浅色活动空地。
- **统一**：两图主角缩放统一为同一值【建议0.60，样板验证】。

## 3. 昭元边城空间规划

**结构：一条中轴、三坊、一座广场。** 从北门进城，经门内军务街到中央市井广场，尽头是议事厅。这条轴线既是走访顺序，也引导视线。

- **入口与地标**：城门改为中式门楼(gate)，横跨北端主街，出口触发器留在门洞内(480,96)。门洞阴影和城墙压住画面顶边，从古道进城第一眼就是门洞框住的长街。议事厅放在轴线南端，作尽端焦点：重檐、旗、台阶朝北，从广场南望全程可见。
- **北·门楼军务坊**（y 130–420）：马厩带西侧围栏马场，巡界厅带东侧校场。这里尘土多、有拴马桩、兵器架，路面以夯土为主。
- **中·市井广场**（x 330–630, y 560–780）：仓廪、锻造铺占广场北侧两角，门朝南开向广场；西南是社树（老枫）、长桌和灯，承载“三城小聚”任务；东南是兽栏开放围院，围门朝广场；东侧是云游商摊和货车。广场按参考图2处理：一大片奶油色压实地面，带淡淡的鳞纹铺砖，向外过渡为一圈金黄草穗，再进入亮绿草地；四角各放一棵大枫树，把广场框成舞台。这里是全城最热闹的停留点。
- **南·官署坊**（y 840–1200）：议事厅居中，图志阁在西，祭坛在东，铺青石，环境安静，有树荫。
- **道路层级**：主街碰撞/可走宽度沿用144，视觉上是奶油色到浅沙色的压实土路，宽度在96–150之间呈波浪变化，边缘有金黄草穗和小石过渡，不画直边；坊巷宽48–64，从主街通到各门前；两侧后巷宽56，可走，形成南北回环，是可选的探索路线。
- **建筑群**：功能建筑中心x≈300/660，门和招牌落在主街视口内（每栋可见约2/3）。屋顶用暖橙瓦和灰瓦两族，配浅灰石墙。x<190、x>770为后院，参考图2用密集枫树、圆冠树和少量屋顶混合填满，形成画框；这里不可交互。
- **NPC**：每人站在本建筑门前或工作点上，不站在路中，也不站在空草地上。执事闻叔在议事厅台阶西侧，新档出生即可看见。参考图2中NPC头顶的“!接任务”标识，对应本作现有的任务可接/可交付状态。可以在地图上加同类头顶标记，只读现有任务状态，不新增机制。
- **待建表现**：基线只落成议事厅和城门，所以开局边城的主体就是“正在重建”。三档视觉为：①未开工：旧屋残基+围栏+苫布料堆+木牌写建筑名；②施工中：脚手架+半成木构；③落成。只换视觉，档位映射现有建造状态，不改变开放条件。对应NPC留在门前临时工位（如石头守露天铁砧），只在入口确实开放时可交互。
- **走访顺序**：新档出生在广场南(480,860)→闻叔(议事厅)→广场各坊→北门出城。从古道回城出生在门内(480,200)，沿主街南下。
- **留白与遮挡**：广场中心不放碰撞物；树冠和屋檐只盖住后院；功能门前留出至少96×96空地。

## 4. 枫林古道空间规划

**主题：一条车道穿过枫溪谷。** 新增枫溪从西边进入，在石桥下穿过主路，汇入东侧小潭，再经石涵流出。两条环路因此有了存在理由：西环是溪滩踏石小径，东环是绕潭小路。“8”字变成“溪谷里分出的两条小路”。

**道路分级**（中心线全部沿用，画法见参考图1）
- 主路(宽88)：暖沙色土路，视觉宽80–110并呈波浪变化，边缘是锯齿状草缘和零星草丛，路面有浅色斑点和少量脚印、车辙纹。
- 盐道支路(76)：同一沙土材质，视觉宽56–70，掺入残石板和白色盐渍。
- 环路与驿亭支路(60/62)：同一沙土材质，视觉宽36–48，中间常被草丛、踏石或落叶打断，层级上明显比主路窄、比主路断续。

**节奏分区（南→北）**
1. **Z1 城外缓坡**(y 1000–1248)：开阔低草、木栅、“昭元边城”路牌与界碑，是安全起步区，西南林缘有1狼。
2. **Z2 枫溪潭桥**(y 620–1000)：全图核心景点。修桥任务4点都在石桥上；西浅滩旁枯枫挂着旧风铃；东环绕潭，芦苇间放草根b所在的东南草坡。狼只在两侧林缘活动。
3. **Z3 盐道岔口**((515,640)一带)：路石匣立在岔口里程石旁；东向旧盐道s12前有木栅封路，挂盐车轮和告示，解锁后栅门敞开。
4. **Z4 灯道林荫**(y 400–560)：枫林收窄成廊，古道路灯立在路边；西林中有草根a。这里是全图最暗、最密的一段，与Z2的开阔形成对比。
5. **Z5 驿亭**(NE端)：瓦顶驿亭，配拴马桩、货箱；驿亭交易和交付盐袋并排。
6. **Z6 古祠回环与北坡**(y 96–400)：西北环内有红叶残祠（纯景观停留点）；北出口为上行石阶和断碑剪影，预告“断碑坡”。

**框景**：参考图1、图2的共同点是画面四周被大树压住、中心留出走动空间。野外沿路两侧x<220、x>740种满圆冠绿树、枫树和针叶树，形成连续林墙，树下点缀灌木、花丛、石块、倒木。任意竖屏视口里，左右边缘至少约20%被树冠占据；路面和交互物周围保持干净。

**找路与发现**
- 主路靠明亮的沙土色、波浪草缘和两侧林墙辨认，一眼可见。
- 每个岔口放一个地标：界碑、石桥、里程石、路灯、驿亭、断碑。
- 可交互物统一使用暖铜与麻绳点缀，底部有柔光圆盘，保留现有◆标记，不放在树冠阴影里。
- 远景提示出口：北面石阶上行，东面木栅，南面路牌。
