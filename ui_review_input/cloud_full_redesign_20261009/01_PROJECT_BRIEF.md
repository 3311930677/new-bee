# 项目与本轮目标

游戏为《远征》，副标题“昭元行旅录”。它是一款 Godot 4.x 的竖屏像素幻想 RPG，已有古城、营帐、野外行旅、主线/支线/委托、伙伴和装备养成、地区探索与战斗流程。

本轮目标：将主要页面从“功能已能用、局部反复修整”推进到一套成熟游戏的整体视觉与交互质量。允许重新构图、调整模块比重、改变信息组织、组件形制与资产体系。现有界面完成度不作为必须保留的理由。

## 已完成但可再评估的试作

启动页取消中央菜单板，使用独立铜漆字标、实时副标题、古城街道与朱漆开始按钮。长屏顶部已经接入绘制天空，保留原街道。

城镇/野外 HUD 将常驻信息放到角落，移动营帐/撤离入口，采用任务收合、玩家居中的地形小地图、填色帐篷/卷轴/疾行符号、深漆摇杆及药剂数量角标。其余页面还使用之前不同阶段的纸页、徽章、栏位和按钮，整体统一性需要重新评价。

新字标与天空是实际已接入的资产，不能再把当前截图误认成旧翅膀 Logo 的过渡版。登记或其他配套页面若仍出现旧品牌形制，应按具体页面指出一致性缺口。

本包不是最终美术方案。你可以认定已有内容不适合成熟游戏，并给出替代设计；请解释新设计如何改善玩家第一眼、使用路径与主题表达。

## 成功的定义

- 玩家第一眼认出这是什么世界、自己在哪、最该做什么。
- 每页有清楚的视觉锚点与行动层级，角色、地图和 UI 不互相争夺面积。
- 字体、图标、材质、选中态和反馈能跨页形成一套语言，同时保留页面职责差异。
- 养成、装备和背包能清楚表达比较、操作成本、结果与反馈；战斗信息能及时读懂。
- 原尺寸截图可读，短屏与长屏构图成立，触控热区和安全区可实现。
- 提交的规范足够让另一名 Godot 工程师独立落实，不依赖临场猜设计。

## 当前证据边界

此前截图专项和相关玩法回归已经执行，但这不构成审美批准，也不能证明实体手机体验。模型本轮只根据提供的图和功能合同设计，未提供的状态写成需要验证的假设。

本轮不要求新增玩法、经济系统、账号/联网架构或付费运营功能。内部子页面没有提供的，不要臆造为已经存在；用共享组件与扩展规则覆盖其未来接入。
