# 《远征》主要界面：完整视觉重构评审包

日期：2026-10-09。目的：让 Cloud / Claude 重新评价目前游戏的主要界面，并在保留像素行旅幻想风格与现有玩法的前提下，提出大胆、完整、可实施的重构方案。

## 使用方式

1. 解压本包。用 Claude Code 时，只把本目录作为工作目录；用网页对话时，上传说明文件与截图，并把 `PROMPT_FULL_REDESIGN.md` 全文粘贴到消息中。平台若不能直接读 ZIP，请解压后提交文件。
2. 第一批读 `01_PROJECT_BRIEF.md`、`02_FUNCTION_CONTRACT.md`、`03_STYLE_AND_CONSTRAINTS.md`、`SCREENSHOT_INDEX.md` 与 `screenshots/core/` 的 10 张图。
3. 再读 `screenshots/support/` 的 7 张配套页面，完成全流程的设计。状态图片放在 `screenshots/states/`，只在判断对应问题时读取。
4. 当前方向不是已批准的最终答案。旧试作中的尺寸、3px 切角、单铜边与圆盘排列都允许重新评估；新方案需要定义统一规则并保留功能。
5. 本轮让模型交付 3 份设计文件，不让它做工程探索、编程、运行或素材生成。之后由 Codex 按方案实现，再用真实截图验收。

## 内容与真实性

- core：启动、营帐、城镇、野外、养成、装备、背包、战斗、地区图、出征准备。
- support：登记、创建角色、加载、图鉴、设置、介绍、战斗技能页。
- states：长屏、灰度、安全区、疾行、药剂零数量、任务收合、地图展开、交互提示。
- 所有页面图来自 Godot 原生渲染。基础页面于本次整理重新拍摄；已经刚完成验证的启动/HUD/状态图直接采用同日最新图，不重复生成。
- 保留原生尺寸与文字，没有滤镜、锐化、裁剪、后期绘制或概念图替代。角色与数值使用演示数据，截图不能证明所有真实玩家状态。
- 交互就绪诊断图暂停自动接触步骤，以展示原有效距离内的按钮；真实点击原 NPC 对话已通过检查。平时的自动靠近互动保持原行为。
- 城镇左右半透明木板是已知既有场景问题；允许提出与 UI 构图相关的背景整理需求，单独记作场景依赖，不能声称它由最新 HUD 改动引起。

不提交源码、存档、完整素材库、日志、API 账单或旧长对话。截图出处和尺寸见 `SCREENSHOT_INDEX.md` 与 `capture_manifest.json`。
