## 结论：有条件通过

本轮把上一轮 8 项问题都落到了真实画面上，下列部分已达到可上线的骨架水准，本单不再重复：
- 战斗敌方条、能量刻度与技能三态。
- 装备与背包的单层格和逐模板图标。
- 养成属性栏。
- 图鉴陈列壁龛与胸箧背景。
- 出征的暗场标题。
- HUD 伙伴入口恢复。

但距离成熟商业竖屏 RPG 的完整画面，还有三个核心差距：

1. **空间对应仍然断裂。** 战斗里底托芯片和场上的敌人之间没有视觉连接。地区图的节点与绘制地图上的空地、道路错位，默认视口只能看到 18 个地点中的 2 个。
2. **新素材的绘制语言和像素世界不统一。** 物品、技能图标与地区图是柔和渐变的生成式绘画，没有像素轮廓。五个技能图标在 40px 下几乎是同一个铜色漩涡。
3. **对象的“落地”和页面收尾不完整。** 宠物悬在展台上方，手记的托盘悬在半屏，出征配置仍是一串居中的文字框，图鉴未知页底部有 160px 空白。

以下共 8 项，按对成熟观感的影响排序。

## 1. P0 · 战斗主视图：敌方条与场上敌人没有一一对应，集火与“下个目标”的语义仍然混淆

**截图与位置：**
- `current/08_battle.png`、`states/battle_focus_1067.png`
- 敌群 x285–445、y170–360
- 敌方条 y592–636
- 场上文字“集火目标 · 哥布林掠盗”在 y563
- 次键“集火 · 树妖”在 12,734,146,50
- 攻击键在 316,680,152,104

**可见事实**：

信息表达：
- 4 个敌人重叠成一团，场上只剩 2 条 40×4 血条（y355 处 x315–355 与 x375–415），无法判断它们分别属于谁。
- 敌方条里有两张一样的“树妖 91/91”芯片（第 1、第 4 格）。玩家无法知道哪张芯片是左上那棵树，哪张是左下那棵。
- 集火只有一个灯金 ▼（333,130），悬在敌群上方，没有落到某个敌人的脚下。
- 场上浮着一行“集火目标 · 哥布林掠盗”，与攻击键副行和芯片上的“集火”标签说的是同一件事，同一信息出现了三次。
- 次键写的是“集火 · 树妖”，实际含义是“下个目标”。它和攻击键的“集火 · 哥布林掠盗”格式完全相同，玩家会以为有两个集火对象。

素材质量：
- 攻击键图标像一把镐或斧，不像剑击。
- 次键图标约 20px，比其他次键的图标轻。

**影响**：连续战斗中最常用的判断是“我在打哪一个、下一个是谁”。现在只能读芯片文字，无法和画面对应。这是动作 RPG 的核心可读性缺陷。

**目标效果**：
- 每个敌人在场上和芯片上用同一个**编号徽记**对应。
- 集火目标在场上有脚下环和头顶标记两重表达。
- 场上不再浮文字。
- “集火”只出现在攻击键上；次键明确是“换目标 / 下一个”。

只改芯片样式不够，必须在场上与芯片之间建立编号映射。

**可执行要求**（不改目标逻辑，不新增点击选敌）：

1. **编号徽记**：
   - 每个敌人按敌方条顺序编号 1–4。
   - 场上在敌人精灵脚底中心下方 4px 画 16×16 漆底铜边圆徽，内写 12 Bold 数字。
   - 芯片头像左上角画同一个徽记（14×14）。
   - 两个徽记重叠时，后者向外侧（远离敌群中心）偏移 12px，最多偏移 2 次。
   - 同名敌人在芯片上加后缀，如“树妖·1”“树妖·4”。
2. **集火目标**：
   - 脚下画灯金椭圆环 56×14（2px，`#F0B95A`），在徽记之下。
   - 头顶 12×8 ▼ 移到该敌人的精灵顶上方 4px。
   - 该敌人的徽记改为灯金底、黑字。
   - 敌群重叠时只保留集火目标的 40×4 血条，其他敌人的血条隐藏，由芯片承担。
3. **删除场上那行“集火目标 · …”**（y563）。800 高时战场下沿因此多出 28px。
4. **次键改为“换目标”**：
   - 图标为循环箭头 ICN-CMD-CYCLE 28。
   - 主文字“换目标”15。
   - 副行 12 旧纸写“下个 · 树妖·4”。
   - 若该键与攻击键的循环是同一逻辑，则保持现有回调，只改文案和图标（待实机核实）。
5. **攻击键**：
   - 图标替换为 ICN-CMD-ATTACK v2（斜劈大剑带弧光），显示 40。
   - 主字 22。
   - 副行“集火 · 哥布林掠盗”12 金纸色，保留。
6. 次键图标统一为 28px，文字 15，同一套光源。

**新素材：**
- **ICN-CMD-ATTACK v2**：显示 40，源 120×120，透明。斜劈大剑加一道弧光，硬剪影，1px 暗轮廓，左上光，≤6 色阶加灯金强调。
- **ICN-CMD-CYCLE**：显示 28，源 84×84，透明。两枚首尾相接的弧形箭头，旧铜色。
- 编号徽记用代码绘制。

**完成判据与补拍：**

## 2. P0 · 地区行路图：节点与绘制空地、道路错位；默认视口只见 2 个地点；“锁定”与“条件受限”共用锁形

- 生成地图（1189×1323 原图放大到 1440×1600）上的 18 块沙色空地与导出坐标不完全重合。北部一带系统性偏差约 50–70px（例如 lorin_wilds 导出 (200,270)，空地约 (218,200)）。

- 画布西半部与西南约 40% 的面积没有任何地点（见 `map_guide.png`），是纯装饰地形。

状态：
- 截图中“锁定”和“条件受限”都用锁形图标。两者只能靠详情托盘里的文字区分，名牌本身区分不了。

- 默认一屏能看到当前地点周边 6–9 个地点。

## 3. P1 · 新增物品图标、技能图标的绘制语言与像素世界不统一；技能图标彼此不可区分；“传世”稀有度色与灯金色冲突

**截图与位置：**
- `current/07_inventory.png`：网格 y152–420 共 14 件；详情 (28,490) 图标 80。
- `current/06_equipment.png`：槽位条 y64–134；焦点 (20,160,96,96)。
- `current/17_battle_skills.png` 与 `states/battle_cooldown_800.png`：技能图标 x25–65、y525–765。

**可见事实：**

素材质量：
- 物品图标是柔和渐变的高细节绘画（锤头金属反光、羽饰发丝、毛皮笔触），没有 1px 暗轮廓。在 60px 下细节糊成一团（如第 2 行第 4 格的弯刀和第 1 行第 3 格的长刀，轮廓接近）。
- 物品图标与像素角色、像素 HUD 图标放在一起，是两种绘制语言。这就是“把泛用符号换成另一套生成式画片”的情况，规范 B.6 的硬剪影、≤5 色阶、1px 暗轮廓没有落实。
- 五个技能图标都是“深色圆盘 + 铜金漩涡”，40px 下裂山、破阵、战吼几乎无法区分。灰化后的回风斩也只是同一个圆盘变暗。

信息表达：
- 详情中“碑鸣圣锤”名字用的是“传世”稀有度色。这个色接近灯金 `#F0B95A`，在背包页与右上的“金币 12,800”、灯金选中框同色，抢走了行动强调。

**影响**：图标是玩家每天看得最多的素材。它的绘制语言决定游戏是“一套作品”还是“素材拼盘”。技能不可区分时，冷却与能量状态的阅读也会失败。

**目标效果**：
- 物品与技能图标统一为“像素邻近”画法：硬剪影、1px 暗轮廓、有限色阶、左上光，与角色像素密度协调。
- 技能图标在 40px 下靠剪影与强调色就能区分。
- 传世色与灯金色拉开。

**可执行要求：**

1. **工程侧立即可做**：
   - 稀有度色表中“传世”改为 `#E07038`（偏朱橙），并在格子角标上叠加一个 2px 亮点作为形状区分（传世专属）。
   - 灯金只用于选中框和行动强调。
   - 详情名字的稀有度色降为 85% 亮度。
2. **物品图标重做**（44 个模板，可分批，先做背包演示中出现的 14 个）：
   - 显示 60（格子）/ 80（焦点、详情）。
   - 源图为 60×60 像素网格，每个像素导出为 2×2，即 120×120，最近邻缩放。
   - 每个模板保持现有设定（名称、材质、颜色）不变，只换画法。
3. **技能图标重做 20 枚**（现有 20 枚图集）：
   - 取消统一的圆盘底，改为“无底主体 + 单一强调色”。
   - 每枚的主剪影不同（劈、刺、旋、吼、锁链等），强调色从霜蓝、朱砂、灯金、玉青、赭石中按技能属性分配。
   - 不可用态由代码去饱和，不另画。
4. 保留：格子框、角标、强化数、锁定、穿戴、新物标记的布局（已经合格）。

**新素材**（提示词见附录 A.2、A.3）：
- **ITEM-ICON-PX-{模板}**：44 枚，源 120×120（60 网格 ×2），透明，最近邻，1px 暗轮廓 `#1A1410`，≤16 色，左上光，不带底色、不带稀有度色。
- **ICN-SKILL-PX-{技能}**：20 枚，源 120×120，透明，硬剪影，1px 暗轮廓，≤6 色阶加 1 个强调色，无圆盘底。

**完成判据与补拍：**

| 补拍状态 | 完成判据 |
|---|---|
| 背包装备页签（与本次同一演示库存） | 灰度截图中 14 个物品剪影两两可辨；图标边缘无半透明柔边 |
| 装备页 | 与角色并排时像素颗粒接近 |
| 技能列表就绪、冷却、能量不足三态同屏 | 5 个技能图标在 40px 灰度下可辨 |
| 传世物品详情 | 详情中传世色与灯金不再相近 |

## 4. P1 · 图鉴展示：宠物悬空不落台，未知页底部大块空白，进化收益无标签

**截图与位置：**
- `current/14_codex.png`：岩龟脚底约 y265，展台顶面约 y305，悬空约 40px；“全属性 +25%”在 16,622。
- `states/codex_unknown_800.png`：剪影脚底 y330，展台顶 y355；托盘 y640–800 空白；“通关「凛风雪原」首领”在 y470 和 y623 重复出现两次。

**可见事实：**

布局：
- 宠物展示图（64px 原生，3× 显示）与展台之间有一段空隙，没有接触阴影，读起来像“贴在空中的贴纸”。
- 展台是一个通用的深色扁圆盘，宽度与宠物体型无关。
- 未知页把途径重复写了两次，底部 160px 什么都没有。

信息表达：
- “全属性 +25%”用 20 Bold 大字单独成行，但没有说明这是“进化后”的收益，与上方的当前属性行混在一起。

素材质量：
- 64px 宠物展示图 3× 显示时清晰度可以接受，与壁龛背景的写实暖光也协调，保留。

**影响**：收藏页的价值在于“端详对象”。悬空让好素材显得廉价；空白底部和重复文字让页面像没做完。

**目标效果**：
- 宠物稳稳站在展台上，带接触阴影。
- 展台随宠物宽度变化。
- 已拥有页的收益有明确标签；未知页的底部承担“结缘途径”展示。

**可执行要求：**

1. **落台**：

   - 接触阴影：椭圆，宽 = 宠物不透明宽度 × 0.8，高 10，`#0A090B` 50%，放在展台顶面上、宠物之下。
   - 展台宽 = max(160, 宠物宽 + 48)，等比缩放。
2. **已拥有页的进化收益**：
   - 改为“进化后”标签 13 旧纸 + “全属性 +25%”20 Bold，放在一行，行前加 4px 玉青签头，区块位于消耗芯片上方。
