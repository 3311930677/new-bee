## 功能边界

连续战斗、普通攻击和集火循环沿用现有 BattleSim；目标展示不调用随机选敌，不额外改变随机数。没有默认加入点击头像直接指定目标。技能耗能和冷却仍来自现有数据。

地图变化只涉及视觉坐标、道路与显示组件，未修改 `data/main_world_maps.json` 的出口、门槛或连接；地点选择仍查看详情，不传送。

背包的售出确认、锁定、穿戴、卸下、宝石加工、待领取与存档流程沿用原接口。相同装备模板的多个实例使用相同图标，不用实例编号制造假品种。新版演示背包刻意包含多种现有模板供美术核对，不能据前后截图数量差异推断玩家库存被修改。

出征补给仍为预选，确认出征才结算。登录仍是本地旅人登记；存档危险操作继续需要确认。本轮所有检查与截图都使用隔离演示档。

## 素材及复现

素材在 `assets/ui/full_review_fixes_20261009/`：四组装备图集、20枚技能图标图集、10只宠物展示图、胸箧内壁、图鉴壁龛、展示框/台与地区底图。

`generation_manifest.json` 保留各次实际生成提示词、透明要求、原始文件和工程副本。地区图提示词及引导图单独保存；生成原件仍保留在原目录。生成工具是内置 ImageGen，共10份源输出。图集的透明范围只用于读取裁切元数据；64px展示图由Godot原生渲染导入。

`tools/BuildReviewAssetIndex.py` 从实际数据模板顺序重建区域索引，保留原生64px宠物副本；`source_regions.json` 保存原图区域，`tools/PrepareReviewSprites.tscn` 可据此重新导入，避免重复缩小副本。`tools/ExportReviewMapLayout.py` 导出地图布局与引导图，`tools/CaptureMapGuide.tscn` 原生渲染引导图。

新素材已进入现有加载页预热队列，进度来自真实剩余任务。一次性能检查发现地区图首开101ms，接入预热后单独复测为73ms，低于原100ms预算；复开27ms。图鉴首开22ms。该轮加载页预热约4.4秒，是本机观测值，不作为手机性能承诺。
