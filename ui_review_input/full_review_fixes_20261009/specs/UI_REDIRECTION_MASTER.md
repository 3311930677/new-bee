## A. 真实画面诊断

### A.1 整体判断

**最拖累整体质量的不是某个边框或颜色，而是三个结构性问题：**

1. **页面骨架是“黑底中央一块板”。** 装备、背包、地区图、出征、图鉴、设置、介绍这 7 页都是同一种做法：近黑底上居中放一块 420–456 宽的面板，面板内再排表单。屏幕 60–85% 的面积被容器边框和空白占掉，世界、角色、物品都不在场。这是“网页后台/系统对话框”观感的根源。
2. **材质族群割裂。** 17 个视图里至少能数出 5 套互不相干的材质语言：
   - 深漆 HUD（03/04）
   - 青蓝夜色加金色重饰（02 营帐、05 养成徽章）
   - 灰白方格纸板（06/09/10/14/15，边缘带刻度尺）
   - 深蓝板加米色详情（07 背包）
   - 深青框加米纸加金铆钉（16 介绍）

   另外登记页和加载页（11/13）仍是旧的翅膀 Logo。玩家每进一页，就像换了一个游戏。
3. **行动层级倒置。** 多数页面最大、最居中的按钮是“返回”：05 底部是 432×48 的返回条，06/09/10/14/15/16 都把返回放在底部居中。主要行动（确认强化、出征、领取）反而与次级按钮等宽。开关被画成按钮（15“静音：关”、10“苦行：关”）；关闭入口重复（07 同时有 × 和返回，15 同时有 × 和返回）。

**已有成果中有效、应保留的部分：**

### A.3 为什么小修不能解决

上一轮验收已经证明：换一套边框、改几个颜色、替换几个图标，可以把单页从“粗糙”拉到“干净”。但只要“中央一块板 + 等宽按钮 + 底部返回”这三件事不变，每页仍然是表单。

完整重构要改变的关键关系有四条：

1. **背景与内容**：从“容器遮住世界”改为“世界在场、匣盘托住操作”。
2. **对象与操作**：每页先展示被操作的对象（角色、物品、地点、秘境、灵宠），再给操作；对象是视觉锚点。
3. **主行动与导航**：主行动固定在右下拇指位，导航固定在左上；两者不再争夺底部中央。
4. **信息与说明**：图例、规则、提示由组件状态表达（角签、语义色、状态芯片），不靠段落解释。

## B. 唯一主美术方向

### B.1 候选与选择

| 候选 | 定义 | 结论 |
|---|---|---|
| ① **灯下行箧** | 所有界面都是旅人在营灯下打开的行箧：深漆木承载，旧铜只做结构件，纸只做记事内衬，灯火只照亮当下该做的那一件事 | **选定** |
| ② 行旅手账 | 全部页面做成纸页手账，HUD 用深色 | 放弃：现有灰白纸板正是网页感的来源，大面积纸页在暗色营帐和亮场 HUD 之间会持续割裂 |

**选择理由：**
- “行箧”能自然覆盖深色 HUD（随身漆牌）、页面匣盘（打开的箱格）、纸页内衬（文牒、手记）和朱漆主行动（箱上的封漆）这四种职责。
- 营帐夜景、灯笼、黄昏街道本来就以暖灯为光源，“灯火”作为唯一强调色有世界观依据，可以替代到处加金边的做法。

### B.2 方向定义

- **一句话定义**：深漆承载，旧铜立骨，纸签记事，灯火指路。
- **气质**：沉稳、温暖、克制，像旅途中用旧了的好器物，不像宫廷宝匣。
- **世界观联系**：营帐（夜、灯、布、木）与古城（漆木、铜件、文牒），行旅（箱、签、路牌、印）。
- **视觉母题**（只有三个）：
  1. **箱沿**：匣盘顶部 2px 铜沿，两角各一个 12×12 铜包角。
  2. **纸签**：记事内衬，单侧燕尾或平切。
  3. **灯池**：对象脚下或焦点后方的柔和暖光椭圆，每屏最多 1 个。
- **适用边界**：
  - 品牌字标与场景插画不受“克制”约束，可以浓烈。
  - 世界内像素美术保持原样。
  - 弹窗、表单、设置以清晰为先，不加母题装饰（只保留箱沿）。

**强调预算（每屏）：**
- 朱漆主行动 ≤1。
- 灯金元素 ≤3（主行动文字、1 个可行动提示、焦点）。
- 朱砂只在真实状态下出现。
- 灯池 ≤1。
- 稀有度色只出现在物品格内。
- 禁止整块渐变、外发光、循环扫光。

### B.6 图标标准（ICN 系列）

- **造型**：硬剪影，单一主体，45° 左上光。主体占画布 80%，四边留白 10%。
- **轮廓**：显示尺度 1px 暗轮廓 `#1A1410`。
- **色阶**：每个图标 ≤5 级色阶，加 1 个固有色（药红、帐褐、灯金等）。不画高光星点，不画背景圆盘。
- **尺寸**：

  | 场景 | 显示尺寸 |
  |---|---|
  | HUD | 24 / 28 |
  | 导航、指令 | 32 |
  | 成长线、页面入口 | 40 |
  | 物品格 | 48 |
  | 物品大图 | 96 |

  源图一律 3×，线性过滤 + mipmap（与已有高清器物缩小方案一致）。像素世界标记（小地图、地图节点地标）用 1× 像素最近邻。
- **状态**：
  - 默认：原色。
  - 禁用：着色器去饱和 + 50% 亮度。
  - 选中：图标不变，由容器表达。
  - 提醒：由 DOT 组件叠加，不另画图标变体。
  - 仅开关类（疾行、自动、静音）需要两张图：关为线性轮廓填暗，开为填色加动势线。

### B.7 装饰标准

- **可以承担标志装饰的区域**（全游戏共 6 处）：
  1. 标题字标
  2. 营帐继续旅程主键
  3. 匣盘箱沿与包角
  4. 地区地图卷边
  5. 秘境/世界插画画框
  6. 图鉴展示台
- **必须安静的区域**：列表行、表单、设置、背包网格、战斗血条与指令盘内部、HUD 文字区。
- **禁止**：翅膀、宝石、罗盘玫瑰作为通用装饰；每个角都加铆钉；常驻发光或扫光；刻度尺边（06/09/10/14/15 的纸板刻度一律去掉）。

### B.8 像素世界与精细 UI 的连接

1. **分辨率分层有依据**：属于世界的内容（角色、地图、小地图标记、地图地标、战斗单位）保持像素、最近邻、整数倍；属于器物的内容（匣盘、按钮、图标、字标）用 3× 源图平滑缩小；文字独立线性。
2. **桥接手段**：
   - 器物轮廓统一 1px 暗线，接近像素描边的视觉重量。
   - 切角只用 2px 和 4px 两档，呼应像素阶梯，不用大圆角。
   - 灯池、影子用低频软光，衔接像素地面与平滑 UI。
3. **角色展示**：营帐、养成、建角三处的角色台需要高于地图尺度的展示精灵。现有精灵约 200px 高，若源图是 2× 整数缩放可直接使用（待核实）。若要做到“更有存在感”，需新增 **CH-SHOW** 展示精灵：同一像素风，整数 3× 显示，带 idle 6 帧。不允许把小图非整数放大。

## C. 组件与行为体系

### C.1 基础规则

| 规则 | 值 |
|---|---|
| 网格 | 4px 基础单位；常用间距 4 / 8 / 12 / 16 / 24 / 32 |
| 页边距 | 左右 12（匣盘外），匣盘内 16 |
| 最小热区 | 44×44；相邻热区间距 ≥4，不重叠 |
| 切角 | 高度 ≤44 用 2px，高度 ≥52 用 4px；HUD 漆牌由现 3px 统一改为 2px |
| 轮廓重量 | 结构线 1px；选中和焦点 2px；没有 3px 以上的边 |
| 分隔 | 行间用 1px 铜影线；分组之间用 16px 间距 + 区块标题；不用盒中套盒 |
| 阴影 | 只用于浮层：Y 偏移 4、模糊 8、`#000` 40%；匣盘只有箱沿下方 1px 影 |
| 层级 z | 0 世界/背景 → 10 世界名牌 → 20 VEIL/遮罩 → 30 页面内容/HUD → 40 匣盘 → 50 反馈浮层（Toast、伤害数字） → 60 弹窗遮罩 + 弹窗 → 70 系统（加载、异常） |
| 转场 | 进页：背景淡入 240ms；匣盘上滑 24px 并淡入 180ms（ease-out）。退页：反向 140ms。页签切换内容交叉淡化 120ms。按下 80ms |
| 反馈节奏 | 即时（80ms，按下）→ 确认（160–240ms，状态变）→ 结果（600ms，一次性）→ 常驻（只限低血量与可交互提示） |
| 输入 | 手机不依赖悬停。桌面悬停只允许亮一级。键盘焦点统一用 FOCUS 环；系统返回键等同 A-BACK |

**通用状态外观**（各组件只写差异）：
- 按下：面色变为漆面 L2，内容下移 1px，缩放 0.97。
- 禁用：内容改灰烬，边改暗铜 50%，无按下反馈，并在旁边或 Toast 中给出原因。
- 键盘焦点：外扩 3px 的 2px 灯金环，再外加 1px 影。焦点和选中可以叠加。

| **SK-STAGE（台与匣）** | 养成、装备、背包、图鉴、出征、建角、介绍、设置（设置的台退化为页头） | PAGE-HEAD（y0–56）→ STAGE（对象）→ TRAY（操作与信息）→ 行动栏（y732–788，右侧或通栏 A-PRIMARY） |
| **SK-HUB（营帐）** | 营帐主页 | 身份与资源（顶）→ 角色台（中）→ 主行动 HERO → N-TABBAR（底）；右侧旅签架 |
| **SK-HUD** | 城镇/野外 HUD | 四角漆牌，中央净空 |
| **SK-BATTLE** | 战斗、技能页 | 顶栏（撤退/标题/速度/自动）→ 战场 → 指令匣盘（技能页为展开态） |
| **SK-FRONT** | 标题、登记、加载 | 全幅场景，品牌在上，行动在下 |
| **SK-MAP** | 地区行路图 | 全幅地图卷可拖动，加底部详情匣盘 |

**通用安全区规则**（模拟顶部 44、底部 34、左右 8）：
- 背景、VEIL、TRAY 底色越过安全区，铺到物理边缘。
- PAGE-HEAD 和顶部控件下移 44。
- 行动栏与 N-TABBAR 上移 34。
- 左右控件内收 8，组内间距不变。
- 可用高度不足时按以下顺序压缩：先压缩 STAGE（每页给出最小高度）→ 再让匣盘内容可滚动 → 不缩小主行动与热区。
