# 《远征》“灯下行箧”三批实现 · 完整视觉验收修复单

> 依据：`00_README.md`、`REVIEW_RULES.md`、`IMPLEMENTATION_B3.md`。

## 总体判断

**已经合格的部分**（下文不再重复）：
- 色彩与材质统一；朱漆主行动只有一个，位置在右下或底部通栏。
- 左上返回已统一，不再有底部返回或重复关闭。
- 标题页、营帐主页、建角页的构图成立；设置页的开关、滑杆、步进器职责清楚。

**仍未达到成熟商业 RPG 水准的部分**，原因不在配色，而在三件事：
1. **对象展示弱**：物品、技能、宠物、地标多数是通用符号或低清素材，被框中框包住。
2. **骨架被机械套用**：同一张营帐夜景出现在 7 个页面后面，列表和网格直接压在场景上。
3. **动态信息不够图形化**：战斗与地图里关键关系（集火目标、拓扑、可用性）仍主要靠文字说明，而不是靠位置、形状和图形。

下文共列 8 项，按影响排序。

## 1. P0 · 战斗主视图与技能页：集火目标、敌我血量、能量与技能可用性读不出来

## 2. P0 · 地区行路图：节点按网格排布、直角连线，与地图画面无关，仍是“流程图贴在插画上”

**截图与位置**：

- `states/b3/regions_dragged_800.png`：节点列 x≈340，行 y≈130/300/450。

**可见事实：**
- 18 个地点按等距网格排布（列距约 180，行距约 160）。连线全部是水平和垂直的 2px 直线，直接穿过山体与河流，与画面里的道路没有对应关系。
- 名牌 96×34 的深框是画面里最重的元素，地标图标只有约 36px，被名牌压过。
- 锁定与可达的区别只有后缀文字“· 锁”，名牌外观一样。“条件受限”只写在下方详情里。
- 视口边缘的节点被裁切成“道 / 8”“波 / 12”，没有任何拖动或方向暗示。
- 底部“回到当前位置”是 456×56 的通栏按钮，一个辅助功能占了主行动的位置与重量。

**为什么削弱质感**：地区图是“行旅”主题最该出彩的页面。网格加直角线读起来像技能树或网页流程图，绘制地图沦为背景纹理，探索感和地理感都没有建立。

**目标效果**：
- 地点放在地图的地理位置上，连线沿画面里的道路弯曲。
- 地标是主体，名牌是附属。
- 当前、可达、锁定、条件受限四种状态靠形状加图标加文字区分。
- 视口边缘给出可拖动的方向暗示。
- 拓扑与门槛仍来自现有的 exits、requires_*，不新增传送。

**执行要求：**

   - 在现有地图上沿可见道路手工摆点。

   连线改为沿道路的折线或贝塞尔曲线（每段 2–5 个控制点）：
   - 已通路：2px 亮铜 `#C29A5B` 实线 + 1px 影。
   - 未解锁：2px 灰烬虚线（6 实 4 空）。
   - 禁止水平/垂直直角硬连。
2. **节点**：
   - 地标 48×48 显示（源 24×24 像素，整数 2×），作为主体。
   - 名牌缩为 84×30：名 13 Serif + 第二行 Lv 12。名牌底为漆面 85%，1px 暗铜边，放在地标下方 2px。
   - 热区 96×80（地标加名牌），节点中心最小间距 104。
3. **四种状态**：

   | 状态 | 地标 | 名牌 | 其他 |

   | 当前 | 全彩 | 名牌亮铜边 | 灯池 FX-STAGE-POOL 96×24 + 旅人旗图标 16 插在地标右上 |

4. **拖动暗示**：

   - 当前地点的相邻地点若在视口外，在视口边缘贴一个方向签：漆面 96×32，箭头 + 地名 12，可点；点击后平移 240ms 到该地点。这是界面导航，不是传送。

   - 地图视口因此增加 48。

## 3. P0 · 装备与背包：物品是通用符号加框中框，稀有度与差异不可辨

**截图与位置**：
- `current/07_inventory.png`：网格 x12–468、y152–445；详情 y462–660。
- `current/06_equipment.png`：槽位条 y64–144；物品焦点 x28–110、y168–250。

**可见事实：**
- 背包 15 格里，14 格是同一个“狼牙大剑”图标：一个铜框方块里画一把剑的线形符号。装备页的“生铁大剑”也是同一个符号。物品本体没有材质、颜色或造型差异。
- 每格是三层框：外层卡片框、内层图标框、底部名牌，再加 +0 角标。15 格并排时，框线密度远高于内容密度。
- 稀有度只靠格子底部一条 2px 色线（绿、蓝）。“稀有”的月纹坠饰和“精良”的大剑放在一起几乎看不出差别。
- 网格直接压在营帐夜景上，城楼与灯火从格缝中透出来，干扰辨认。
- 详情：
  - 第二行绿色“生命 +30 暴击 +1%”没有标签，看不出是对比、强化后还是套装加成。
  - “需求 Lv.1 ·”末尾多一个分隔点。
  - 宝石孔是三个写着“空”字的方框。

**为什么削弱质感**：装备驱动 RPG 的核心乐趣是“看到好东西”。物品没有面孔、稀有度没有存在感时，背包像文件列表，强化投入也缺少情感回报。

**目标效果**：
- 每件物品有自己的像素器物图标。
- 格子只有一层框，稀有度通过三种渠道同时表达：底色、角标、名字颜色。
- 网格背景是安静的箱内材质，不是城景。
- 对比结果有明确标签。

**执行要求：**

1. **物品格**（背包）：

   | 项 | 规格 |
   |---|---|
   | 尺寸 | 84×84，步距 92，5 列（x=12/104/196/288/380） |
   | 可见行数 | 3.5 行（y152/244/336，加 428 起的半行）。露出半行就是滚动暗示 |
   | 层级 | 单层框（UI-CELL-9 v2，见下）+ 物品图标 60×60 居中 |
   | 名字 | 格内不再写名字，只在详情显示。名字在格内重复 15 次是机械感来源 |
   | 稀有度 | 格底径向色晕（稀有度色 14%）+ 左上 10×10 三角角标（稀有度色）+ 详情名字着色。普通品无晕、无角标 |

   | 选中 | 2px 灯金框 + 漆亮底 |

2. **背包背景**：网格区（y148–452）背后使用 BG-CHEST-INTERIOR（箱内漆木格，见第 5 项），或纯夜漆 92%。城景只保留在页头一带（y0–148），并加 VEIL。
3. **装备页**：
   - 槽位格 70×70（步距 74），槽名 12 放在格下方外侧（y138）。
   - 物品焦点框改为 UI-CELL-L 96×96，放在 (20,156)，图标 80。

4. **详情对比与镶孔**：
   - 对比行写成“对比已装备：生命 +30 ▲ 暴击 +1% ▲”：标签 12 旧纸；数值 14 Bold，玉青为提升、朱砂为下降。
   - 修正“需求 Lv.1 ·”尾点。
   - 宝石孔改为 28×28 空孔图标（铜环，内暗），删除“空”字；行尾写“可镶嵌 3”12 号。

  - 第一批覆盖所有现存装备基型 × 材质档（剑、枪、杖、锤、甲、坠饰）。
  - 稀有度不烘焙进图标。
