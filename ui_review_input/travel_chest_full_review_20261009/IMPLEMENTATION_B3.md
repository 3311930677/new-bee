# 灯下行箧 · 第 3 批交付

2026-10-09。按 Cloud 已确定的三份设计文档推进流程统一。前三批的 17 个主要界面现已接入新的视觉语言；视觉是否达到商业游戏水准，仍由完整真实截图审查判断。

## 完成内容

- 战斗：右下攻击主键、技能／道具／伙伴／目标的分层指令、左上撤退确认、自动与倍速状态、队伍血量与能量读数、实时行动信息。技能列表保留实际技能定义、等级、能量、冷却与范围，并显示就绪／能量不足／冷却中；不可施放时禁用。单位血量增加数值，重叠名字避让，集火有目标环。
- 地区图：绘制地图背景与 12 类地标，覆盖工程现有全部 18 个地区；保留实际道路连线。空白处可拖动，地点可选，条件与路径写在详情匣盘，无桌面滚动条。地图不会新增直接传送。
- 出征：三个步骤、秘境插画与题记、人物与主力／替补摘要、累计补给、苦行开关、扫荡与出征。补给仍在最终出征时结算；返回不扣钱。
- 登记：新字标、纸签表单、输入焦点、密码显示切换、上传头像、字段错误、主提交与游客入口。表单可滚动，模拟软键盘时提交按钮保持可见。
- 建角：角色整数倍展示、灯池、职业箭头与滑动、性别分段、昵称与随机名、唯一主确认和顶部返回。
- 加载：保留插画、预热任务和真实进度，替换为铜槽与灯金填充。
- 图鉴：展示舞台、已知／未知状态、缩略条、收集里程领取和进化，继续调用原有奖励与进化接口。优先使用已有大图，低分辨率图采用整数倍率。
- 设置：三类页签、音量滑杆、静音／震屏／剧情开关、两端倍速步进、头像与昵称、导出／导入／重置等原有功能。导入和重置有独立确认；默认焦点在取消。
- 介绍：保留世界／旅人／启程三章与全部原有文字、角色和路线插画；统一标题、正文、章节导航。
- 技能研习：展示招式演示、描述、冷却、耗能、等级、实际升级收益与费用，保留无需研习与满级状态；升级后不跳到其他招式。

## 根据工程事实处理的设计差异

1. 战斗是连续推进，没有玩家／敌人回合闸门。本批没有新增回合规则或阻断既有手动施放；“攻击”继续承担原有的循环选择集火目标功能。
2. 地区图有 18 个地区，而非设计稿早期示例中的四个。连线与门槛来自现有 exits、requires_story、requires_flags；等级区间只作建议，未变成新门槛。界碑历练保留其现有入口说明，不凭空画出不存在的路线。
3. 补给是累计购买多瓶的预选机制，保留购买行，不改成只有开／关的单瓶开关。
4. 建角仅沿用现有昵称非空与最长 12 字符规则，没有新增重名、最少字符或汉字数量限制。登录也没有新增远程认证。
5. 没有改动 BattleSim、Combatant、数据表、奖励、存档格式、迁移或经济结算。

## 素材与实现

新增 `assets/ui/travel_chest_b3/`：地图背景、12 地标图集、8 指令图标、攻击主键材质。采用 4 次内置 ImageGen 调用，原图保留；透明区域通过 AtlasTexture 使用，按钮边缘通过九宫格使用。完整提示词在该目录的 `generation_manifest.json`，坐标在 `regions.json`。生成图片没有烘焙动态文字、地点或道路连线。

页面共享 `FlowChestUI.gd`；各系统面板继续拥有导航及操作回调。独立视图只管理组件、布局与状态显示。新增视图已经与加载预热链路一起编译。

## 剩余视觉审查与素材问题

- 新布局与素材已实现，尚未取得 Cloud 的本轮视觉验收意见。
- 部分旧灵宠原图本身清晰度有限，即使整数倍率显示也无法增加原图细节；建议视觉审查单列素材升级需求。
- 城镇边缘半透明建筑、部分世界／敌人占位美术属于既有场景素材，本批没有改动它们。
- 引擎退出时仍有已登记的资源／RID 诊断（问题 #43）；交付检查区分退出诊断与运行脚本错误。
