## 对参考图的正确理解

请将以下视觉特征转化为可执行方案：
- 清楚、细腻、成簇的像素/手绘细节，树冠有受光面、暗面、叶团和深度，树干、草丛、石头都贴地。
- 草地是自然层次与材质，路面较安静；路缘有侵入、磨损与不规则过渡，不是硬切的两种填充色。
- 大树、灌木、草簇、花、倒木和岩石有尺度梯度、分组与留白，围出可信的空间；避免均匀撒点和机械阵列。
- 统一的光源、接触影、遮挡和体积，使人物真的站在环境里；避免贴纸感。
- 图面明亮、有生气，但不是荧光色或不断叠加随机噪声。允许自然色层、过渡、细节和更丰富调色，不以颜色数量少判定质量。
