## 2. 制作方向

### 2.1 两个可行方向对比

| 维度 | A：高品质像素瓦片 + 散件 | B：手绘地表底图分块 + 分层散件（采用） |
|---|---|---|
| 参考质感达成 | 路缘需要 47 种以上 blob 过渡和大量变体，否则会重复、发硬 | 路缘、草舌、磨损带可整图手绘，最接近参考 |
| 改路成本 | 低，重铺瓦片即可 | 中，只重绘受影响的分块 |
| 制作量 | 前期套件量大，每张图拼装快 | 套件较小，每张图需整图绘制 |
| 接缝风险 | 瓦片边重复可见 | 整图绘制后切块，没有接缝 |
| 内存 | 小 | 中：960×2112 约 8 块 480×528 不透明图，移动端可接受 |
| AI 辅助适配 | 生成的图很难严格对齐瓦片边 | 生成的样板图可以直接作为整图描改的底稿 |

### 2.2 结论：选 B，并配“材质笔刷套件”

地表按整张地图绘制，再切成不透明分块。绘制时使用统一的材质套件：草地 3 个色层的填充纹理、土路填充、路缘笔刷、草舌印章、落叶/碎石贴花。这样以后做断碑坡、旧盐道时，套件可以复用，不必每张图从零画。所有树、灌木、石头、建筑、交互物都做成独立透明散件，放进 Y 排序层。逻辑层仍可沿用 48px 格来存数据和寻路，美术不再受格子约束。

### 2.3 参考匹配验收标准（每屏实机截图逐项打勾）

1. **地表分层**：草地至少有亮、中、暗三层；暗层主要出现在树冠下和林缘。480 宽视口里不能看到同一斑块重复出现。
2. **路面安静**：路面内部明暗对比不超过草地的一半；路缘有 8–24px 的磨损过渡带，夹着草舌和草簇侵入；整段路缘里任何一段都不能连续 48px 以上是直线硬边。
3. **体积**：每棵树、每丛灌木、每块石头都要有左上受光面、右下暗面和接触影；树干根部用草簇或根须压住地面。
4. **尺度梯度与留白**：每屏有 2–4 棵大树（允许被画框裁切）、4–8 丛灌木、3–5 组草花，以及 1–2 组岩石或倒木；视觉安静区不少于 35%；同类物件不能 3 个以上等距排成一列。
5. **人物入境**：主角影子的方向、软硬程度与散件一致；主角能被树干遮住，在树冠下时树冠半透明；主角与路面的明度差足以让人第一眼找到他。
6. **色彩**：明亮、自然、偏暖绿，不出现荧光色。不限制色数，但每个资产族使用同一套色阶。
7. **灰度测试**：截图转成灰度后，路、主角、交互物仍然清楚，植被能读出三个明度团块。
8. **缩略图测试**：缩到 25% 后仍能一眼看出“一条路穿过林子，前方有目标”。

### 3.3 相机

- 缩放：取消固定 1.0 的建议；按接入修订先以 1.15 校准，并比较 1.0/1.25。480 宽逻辑视口在 1.15 时显示约 417.4 世界单位；主角约 72 世界单位对应约 82.8 屏幕单位，不能把世界高度与屏幕高度混用。候选图须按局部视口而非整图比例检查。
- 主角屏幕锚点：纵向约 50%，落在上下 HUD 中间的可玩带。
- 死区 24×40；移动方向前瞻 48px；跟随做平滑处理；贴世界边界时停止移动。
- 480×1067 长屏：沿用同一锚点规则，多出的高度向上下展开；不放大，也不改变比例。
- 显示：纹理用最近邻采样，资产在离线阶段就定好尺寸。设备上的非整数缩放不强求消除，但运行时不得叠加第二次分数缩放。

| 层（从下到上） | 内容 |

碰撞规则：

- 树：只在树干根部做椭圆碰撞，约 0.35 倍树冠宽。树冠不做碰撞。

- 水面：整段不可走，桥面始终可走。
- 灌木：小碰撞，可选；草花没有碰撞。

**探索节奏与视线引导**

- **北门（收）**：门洞是逆光的亮口，一进城就看见老赵和石凳。

- **荒院（险）**：从两处断墙缺口进入。地面换成荒草和碎瓦，与生活区明确分开。

**未落成表现**（保留真实状态，不直接解锁）

- 待建：同一占地上放地基石框、竹脚手架、苫布盖住的木料和瓦堆，再加一块写着设施名的告示木牌。门位的交互点保持不变，行为照旧。

- 落成：换成完整建筑。占地和门位不变，所以碰撞和交互点不必迁移。

**城内敌人**：现配置有 4 个刷新点。全部迁到南城根荒院，远离 NPC 交谈半径（≥160）。敌人种类、奖励与刷新语义不变；巡游半径建议 ≤96。Codex 需核对这些敌人的类型，确认放在荒院里语义合理。
