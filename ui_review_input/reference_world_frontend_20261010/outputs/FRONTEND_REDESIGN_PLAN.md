## 1. 统一原则

**品牌“灯下行箧”**

- 母题是一盏提灯加一只漆木行箧（旅人随身的箱子）。三页各用一次，不铺满。
  - 加载：提灯标记进度。
  - 标题：门楼下挂着的灯和行箧。
  - 登记：打开的行箧和文牒。
- 深漆、黄铜和纸张材质只用在 UI 物件上，背景里的自然环境保持地图的森林画法。

**与地图同一个游戏**

- 背景插画沿用地图的光源（左上暖光）、树冠画法、土路路缘和像素密度。
- 背景插画最小像素单位为 1 逻辑像素；按 2 倍尺寸最近邻交付，避免缩放发糊。

**主角**：加载页和标题页出现的人物必须是现有主角（红发、红披风、暗甲），以背影或小比例出现。当前加载页的白发冰系法师和北境古堡与主角、昭元边城的世界观都不符，予以替换。如果她是已规划的角色，留给后续内容使用。

**尺寸基准**（逻辑分辨率 480 宽）

| 元素 | 尺寸 |
|---|---|
| 安全区 | 顶部 44、底部 34（刘海屏和手势条） |
| 文字层级 | 主行动 24；表单输入 18；标签/次级按钮 16–18；提示 15；最小注释 13 |
| 触控热区 | 最小 44×44 |
| 主按钮 | 300×60–64 |
| 次按钮 | 240×48，或 120×44 的文字按钮 |

**长屏规则（480×1067）**

- 背景源图做成 480×1067，并保证中间 480×800 的视觉焦点完整。
- Logo 锚定在顶部安全区，行动区锚定在底部安全区，多出的高度留给中景呼吸。
- 不放大 UI，也不拉伸面板。

## 2. 加载页（Loading）

**构图：林口晨光**

- 背景是枫林古道南端：土路从画面底部中央以 S 形伸向右上的林缘，远处露出几株红枫。
- 主角背影约 90px 高，背着行箧，提一盏灯，站在下三分之一处的路上。
- 上方约 1/3 是树冠间透下的亮色天光，Logo 放在这里。

**布局**（480×800；长屏括号内为 1067 屏的位置）

| 区域 | 位置 / 尺寸 | 内容 |
|---|---|---|
| Logo | 中心 y=150（安全区 +106），宽 260 | 沿用现有“远征”字标，比标题页小一号，下方 16px 小字“昭元行旅录” |
| 场景 | y 230–620 | 纯画面，不放任何 UI |
| 行程条 | y 664（底部安全区上方 102），宽 400×20 | 9 宫格土路条；已完成段为暖色压实土，未完成段为浅草色；一枚 24×32 的提灯标记随**真实进度**移动 |
| 阶段文字 / 百分比 | 行程条上方 22px，16px | 左侧为真实预热阶段名（“整理行箧…”“点亮提灯…”，映射到实际资源/脚本加载阶段），右侧为百分比 |
| 提示语 | y 714，15px，最多 2 行 | 世界观短句轮换 |

**状态**

- 0–100% 必须反映真实预热，不允许装饰性假进度。
- 到 100% 时，提灯亮度提升，约 0.3 秒后按原流程自动进入下一页。
- 如果现有工程有失败/重试状态，保留原行为，文字放在提示语位置。

- 视角在昭元边城内，看向北门楼。门洞外是阳光下的绿林古道，是全画面最亮的焦点。

- 右前景是一根灯柱，挂着提灯和行箧，形成品牌角。
- 去掉当前截图里占画面约 40% 的空石板地；石板改为透视收束的街道，把视线引向门洞。

**布局（480×800）**

| 焦点 | 门洞约在 y 300–420 | 不放 UI |

## 4. 旅人登记 / 登录页（Login）

**构图：行箧文牒（俯视静物）**

- 木桌上摊开一只深漆行箧，左上角有提灯暖光；箱盖内侧贴着一角旧地图，旁边有一片枫叶。
- 一张米色通关文牒压在行箧上，表单就“写”在文牒上，从而摆脱网页表单的感觉。
- 文牒上不预印任何文字，所有文字都由 UI 渲染。

**布局（480×800）**

| 区域 | 位置 / 尺寸 | 内容 |
|---|---|---|
| 返回 | 左上安全区内 44×44 | 保留现有返回 |
| Logo | 中心 y=96，宽 200 | 字标加“昭元行旅录”（15px） |
| 文牒 | x 28–452，y 160–590 | 纸面 9 宫格，边缘有轻微卷翘和阴影 |
| 标题 | 文牒内 y 192 | “旅人登记”22px，左对齐，左侧加一枚小朱印 |
| 画像 | 文牒右上，88×88 | 照片框加小铜钉；点击 = 自选旅人画像；下方“导入图片”文字按钮（14px，热区 88×44） |
| 账号 | y 268，左侧宽 300 | 标签“通关文牒”15px，墨线输入行高 52，输入字 18 |
| 密码 | y 352，全宽 396 | 标签“通关秘钥”；右端 44×44 眼睛图标切换明文 |
| 错误反馈 | y 430，固定预留 40 高 | 朱褐色 15px 加警示小图标；不出错时也保留空间，避免布局跳动 |
| 文牒落款 | 文牒右下 | “昭元行牒”印章装饰，不可点击 |
| 主行动 | y 624，300×60 | “登录入城”，朱印形按钮 |
| 游客 | y 700，240×48 | “游客入城”，做成系在行箧上的布签 |
| 注释 | y 756，13px | “旅途进度自动保存在本机” |

**长屏**：文牒和两个按钮整体锚定在可视区垂直中心偏下（中心约 y=560），桌面和行箧向上下延展。

**状态与交互**

- 输入框有常态、聚焦（墨线加粗，标签变朱色）、错误（墨线变朱色）三种状态。
- 软键盘弹出时，整体上推，保证当前输入框和“登录入城”都可见，沿用现有键盘处理方式。
- 头像未选时显示默认剪影；导入后显示裁成方形的图片。
- 提交中按钮置灰，防止重复提交。
