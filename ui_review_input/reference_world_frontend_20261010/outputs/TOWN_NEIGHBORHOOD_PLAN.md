南侧收尾修订：路不是必须接到画面底部；约1740以下逐渐变窄、变浅并略向右弯，约2000前后融入草地，留下少量不连续土痕。新草坪与路缘已接入独立样板，前后截图在../playable_prototype/screenshots/town_south_comparison.png。此处改变地面外观，不新增出口或移动交互点。

最新版按用户要求：出口只用一个路边牌子，不建设门楼；左右布置不同设施；中间一条适度宽的自然土路；树木在空地和外缘独立点缀。地图范围随建筑体量、站位和边缘留白调整，当前尺寸只用于工作与测试。

## 现在的样板

实际房屋8座。原gate设施的访客簿功能保留为议事厅旁的独立小点位，不再需要门楼素材；出城路牌只有一个。north_gate仍通向maple_road/from_city，野外south_gate仍返回lorin_wilds/from_maple_road。

路牌在主路侧边，不挡路；走到附近按E或底部交互即可出城。返回点和出口分开，不会立即跳回。复用了已有像素路牌，技术整理为61×64，未新增AI生图。

## 地图大小与路宽

FitTownExtent.py根据当前房屋、树和交互点的外接范围加留白计算工作地图；当前约1200×2112。数据标记extent_policy=fit_content，后续调整屋形或位置时重新计算，地图不锁死在这组数字。最终生成前，具体裁切区仍必须登记，以便拼接与坐标对齐。

主路暂为136世界单位，允许按实机观感在约120–144范围内校准；支路通常72，议事厅门前80，访客簿短路64。世界变大时路宽保持独立控制，不按画幅比例一起膨胀。草坪是主背景，路缘有轻微弯曲、磨损和草舌，短草花丛分组点缀。

## 房屋与交互

左侧从北向南为马厩、仓廪、议事厅、图志阁；右侧为巡界厅、锻造铺、兽栏、祭坛。上下轻微错位，各自有门前小空地和短路。大型议事厅保留约88高门洞，其余设施单独绘制不同体量，不缩小复制。

NPC站在门前侧边，避开主路与进入点。9名NPC、6个任务物件和访客簿均保留原ID。每日访客预留位置。近处只显示当前交互目标名字，避免堆叠姓名。

当前最近屋檐间距61，所有门前、NPC交谈站位、任务点和出城区域可达。这些是工作轮廓检查，实际素材超出轮廓时会调整位置或扩展地图并重验，而非把图片挤进原框。

## 生图分层

1. 地表只画草坪、土路、自然路缘和少量短草；不烘焙房屋、门、树、NPC、牌子或物件阴影。
2. 8座建筑独立素材，包含完整屋檐和台阶；围栏及附件只占本设施地块。
3. 树木独立素材、独立位置，树冠与树干分层；当前5棵只是稀疏布点，数量随同屏效果调整。
4. NPC、任务物件和路牌独立摆放，实际文字与交互状态由工程显示。
5. 先验证位置、出入和交互，再生成具体裁切区；布局草图只提供几何，不当作美术风格参考。

最新提示词已删除出城门楼要求。D1改为路牌，A8改为路口，标题G2改为沿路启程。原风格参考仍为用户森林图；当前平涂草图、普通房屋简形和NPC简形不是最终美术。
