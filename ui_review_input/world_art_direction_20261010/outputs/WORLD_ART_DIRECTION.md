## 二、选定方向：「晴野行旅 · 3/4 俯视手绘像素」

以主角当前的像素密度为锚点：人物的最小细节约等于 1 显示像素，并且有彩色深描边。**地图向人物靠拢，而不是让人物迁就地图。**

- **保留世界观**：古城行旅奇幻 = 夯土与青灰瓦的边城、木栅、旗幡、驿路和路牌；野外是有真实地域色彩的枫林、岩坡和古道。和 UI「灯下行箧」只共享**点缀语义**：朱漆只出现在旗幡、门框、灯笼这类地标处；灯金只出现在可交互光源和发亮物上；旧铜只用在五金件上。地表、植被、人物衣料都保持自然色，不刷成深漆木纹，也不加金边。
- **保留主角**：主角不重做；所有资产的尺寸、描边、光向都按主角校准。
- **解决不统一**：① 地表改为低对比、2–3px 块面的受控调色手绘瓦片，不描边；② 建筑和道具改为 1–2px 细节、只在外轮廓描边、使用实心 alpha；③ NPC 用受控调色重绘，脚底锁定，做局部呼吸；④ 统一左上主光、暖色接触影；⑤ 用疏密分区代替均匀铺满。
- **层级口诀**：地表负责空间（对比最低）→ 建筑负责地点（中等对比，靠轮廓和屋顶识别）→ 人物和交互物负责操作（对比最高、饱和度最高、描边最清楚）。

## 三、同屏规范表

| 项目 | 规范（显示像素均按 480 宽视口计；源图规格见 BRIEF） |
|---|---|
| 视角/透视 | 统一 3/4 俯视：人物正面略俯，可见头顶；建筑可见正立面加屋顶，屋顶约占建筑可见高度的 40–55%；不用透视灭点，不用等距 2:1；所有立面正对镜头或只做轻微侧面 |
| 尺寸 | 主角显示高约 80px（目测估值，**待 Codex 实测**）。成人 NPC 可见高度是主角的 0.85–0.95 倍（约 68–76px），壮汉可宽不可高；孩童是主角的 0.60–0.68 倍（约 48–54px）；长兵器可超出头顶 ≤12px；门高约为成人的 1.3 倍 |
| 像素密度 | 人物：最小细节 1px，五官和手 ≥2px 块；道具：1–2px；建筑：砖瓦木纹以 2px 簇为主；地表：2–3px 簇，单块瓦片内最多 2 级明度跳变。禁止亚像素渐变、柔焦和噪点颗粒 |
| 色彩层级 | 地表明度 35–70%、饱和度中低；建筑明度 20–80%；人物和交互物明度 10–95%，饱和度最高。单个 NPC ≤48 色，单块地表色带 4–5 阶、整套地表 ≤20 色/地域，单栋建筑 ≤40 色。每屏高饱和亮点（花、灯、旗）≤3 组 |
| 轮廓/描边 | 人物：1px 外描边，用暗于邻色的同色相（selout），不用纯黑；道具：外轮廓 1px，局部断开；建筑：只描与地面相接的外轮廓，内部结构靠明度区分；地表：不描边 |
| 光照/接触影 | 统一左上主光，阴影朝右下。人物和道具：脚下扁椭圆（宽约 0.5–0.6 倍身宽，高约为宽的 1/3），暖深棕，不透明度 35–45%，硬边或两阶；不做长投影。建筑/树：向右下 4–8px 的短落影，边缘与墙基或树根贴合，不能悬空 |
| 地面与道路 | 路 = 压实土或石板，比草亮 1–2 阶但饱和度更低；路缘要有草叶压边加 1px 暗缝。城镇主路的视觉宽度跟现有碰撞走，野外小径同样以现有碰撞为准（不改）；路面中心安静，纹理集中在路缘 |
| 植被/岩石 | 草地 = 底色 + 稀疏草簇 + 少量花丛，草簇成团不撒点；枫树 = 树干底座（Y 排序）+ 树冠（独立层），冠色朱橙、赭黄、暗绿三档；岩石 3–5 块成组，压在弯道和路缘 |
| 建筑 | 青灰瓦或茅草屋顶，夯土或木板墙，石基；屋顶外轮廓决定识别，立面只放门、窗、招牌框（不写字）；每栋建筑带完整墙基与地面接缝，不允许半透明主体 |
| NPC 服装/身份 | 靠「轮廓 + 主色 + 道具」识别：执事＝宽袖长袍 + 冠 + 簿册；巡界人＝短甲 + 红头巾 + 长矛；工匠＝围裙 + 锤；孩童＝短褂 + 小包。主色彼此错开，避免与地表同色；配色统一服从左上光 |
| 动效幅度 | 待机 4 帧：脚底和下半身锁定，只动胸、肩、头 1px，或衣摆、头巾 1–2px；不整体平移，不换脸，不变装，手和武器只允许 ≤1px 随动。环境动效（旗、叶）≤2px，每屏 ≤2 处 |

## 四、目标构图

**城镇画面（昭元边城，480×800 视口）**
中轴是现有的南北主路，保持当前走向、出口和碰撞。左右两侧各有 1–2 栋完整建筑「夹道」：完整屋顶加门朝路，墙基压在草地边缘，取代现在的半透明木框。塔楼保留在右侧，作为边城地标。疏密三层：安静地面约 60%（大片草和路心）、中密建筑与道具约 30%（货箱、木栅、灯柱以 2–4 件成组，贴着墙基和路口）、焦点约 10%（人物、交互物）。NPC 站在路面或较亮的空地上，周围留出 1 格（约 48px）干净地面，名牌和交互标记不压建筑细节。黄花只放在墙角和栅脚，最多 2 簇。必须保留：主路通畅可读、各 NPC 头顶标记可见、HUD 遮挡区（底部按钮和摇杆）下不放关键交互物（**仅为建议，摆位改动属于工程确认项**）。

**野外画面（枫林古道）**
一条清楚的土路从南向北，弯道与小地图一致（走向不改）。左右两侧是枫树林缘：树冠从屏幕边缘探入，形成框景，树干落在碰撞外。落叶集中在路缘和树冠下方，路心保持干净。弯道外侧用一组岩石标出方向。敌人活动的空地用略深的草色，让野狼的轮廓清楚。路牌在岔口，两侧留空，保证可点。避免：整屏同频草叶、随机撒落的石子、棋盘式重复的地块、过多高亮落叶。必须保留：路牌与出口文字可读、宝箱和敌人不被树冠完全遮住（树冠遮挡角色时是否半透明淡出，属于工程确认项）。

## 五、处置分类

**必须重绘**
- 城镇地表/道路瓦片族、野外地表/土路瓦片族：只改色达不到密度和降噪要求。
- 枫林地域标识件：枫树（干、冠分层）、落叶地被、岩石组。现在没有，必须新做。
- 执事、巡界人待机帧条：首轮样板。按受控调色重绘，锁定脚底，做局部呼吸。
- 城镇代表建筑一栋（边城木构屋或执事署）：用来建立屋顶与立面的规则。

**可修整复用**
- 塔楼：降饱和约 10–15%，统一光向，补墙基接触影，用调色量化对齐；结构保留。
- 路牌：几乎达标，只统一描边色和接触影。
- 孩童、铁匠帧条：先只做「脚底锁定 + 调色量化 + 局部呼吸」的修整测试，样板验收后再决定是否重绘。
- 主角、岩鳞龟：不动。若样板验收时主角描边或光向与新资产冲突，列为可选依赖，单独评估。

**先核实显示问题（核实前不重绘）**
- 城四处半透明木构：核查 alpha、调制色（modulate）、遮挡淡出逻辑、裁切和层级。若原图本来就是完整建筑，只需修显示。
- 地表发软和超高色数：核查纹理过滤（应为 Nearest）、mipmap、非整数缩放、导入压缩。
- 人物 0.64 显示倍率：确认采样方式；测试 0.625 等其他倍率是否更利于像素对齐（**工程确认项**）。

**工程确认项（不进入默认执行清单）**：建筑与树冠的遮挡淡出、HUD 下的交互物挪位、NPC 显示倍率调整、树冠作为可遮挡层接入。
