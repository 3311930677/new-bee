# 世界美术指导边界

《远征》是Godot竖屏像素RPG，当前UI方向为“灯下行箧”：夜墨深漆、旧铜结构、纸签笔记、灯金重点、朱漆主行动。这里提供的是跨系统的色彩与世界观背景，不要求场景复制UI材质。

本轮对象是玩家能够走动的游戏地图及其NPC、地表、道路、植被、岩石、建筑、道具与接触影。地区选择界面的绘制地图，以及标题、背包等UI不在本次重设计范围。

保留现有主角辨识度，以运行截图中的主角为同屏尺度参考。必须区分NPC、敌人、宠物与主角，不把地图里的所有小人都作为NPC重新设计。

首轮只定昭元边城、枫林古道样板，给其他地域复用规则。优先解决资产来源感不一致、视觉密度失衡、人物落地和通路可读性。允许大胆重绘必要资产，不默认全项目换图。

现有NPC身份包括执事、巡界人、图志记录员、兽栏照料、铁匠、导师、马厩管理、行脚旅人和孩童；表现这些身份，不增加新NPC功能。

保留地图出口、碰撞、通行门槛、交互点、任务、人物身份及功能。艺术建议需要改变这些内容时必须单列，不作为默认实施任务。建筑透明/裁切等原因不能靠截图确证，先标待技术核实。
