## 决策原则

1. 地图、NPC、主角必须像来自同一套资产库。比较视角、人物比例、可见像素块、轮廓、细节频率、饱和度、对比度、光源、材质与脚底落点。不要只建议“提高分辨率”或“统一颜色”。
2. 地表负责空间与通路，建筑负责地点身份，人物与交互物负责操作重点。地表细节和对比度应低于人物、可交互对象；道路、边缘与遮挡关系必须清楚。
3. “灯下行箧”是已确定的UI语言：深漆、旧铜、纸签、灯金、朱漆。地图保持自然地域色彩，不能把森林、道路和人物全部做成深漆木板，也不能为了呼应UI给所有物体加金边和红色。
4. 同屏先统一，再追求单个资产精致。避免NPC像写实立绘缩小，建筑像另一款游戏的3D模型，地表像低清照片或噪声贴图。不得用光晕、粒子或锐化掩盖比例与像素密度不一致。
5. 区分资产问题与显示问题。半透明建筑、空壳、裁边、悬浮、过大投影，可能涉及透明通道、遮罩、缩放、导入采样或层级。截图不能证明原因时写“待技术核实”，不要一律判定必须重绘。
6. 默认保持现有道路、出口、碰撞、交互点、任务关系与NPC身份。美术可以重做地表、植被、岩石、立面、道具、人物及摆放的视觉表达；涉及实际空间或玩法的变化单列为工程确认项，不进入默认执行清单。不要增添新玩法、NPC功能或随意改职业。

## 首轮样板与范围

首轮只建立“昭元边城 + 枫林古道”的统一样板，以及能验证方向的少量NPC与物件。其他地域只给复用规则，暂不逐张设计18张地图、逐个输出全部NPC的长提示词。

请明确选出最值得先做的样板组合，数量以能证明统一方向为限：例如一种身份偏文职NPC、一种守卫NPC、一段城镇地表/道路、一段野外地表/道路、一座代表建筑或一组交互道具。每个必须说明为何能代表后续资产。不要默认把主角也重做；若主角本身是统一风格的障碍，单列理由和可选依赖。

## 只输出两个文件

### outputs/WORLD_ART_DIRECTION.md

- 当前最影响整体观感的5个问题，按影响排序。每项注明图片与位置、可见事实、影响、判断把握；不得把敌人误当NPC，不推断未提供的画面。
- 选定一个美术方向，写清它怎样保留世界观与主角，又解决不统一；不要罗列三套方向让用户再选。
- 可执行的同屏规范表：视角/透视、成人与孩童相对主角的尺寸、像素密度/细节尺度、色彩层级、轮廓与描边、光照/接触影、地面与道路、植被岩石、建筑屋顶/墙面、NPC服装与身份辨识、动效幅度。
- 用“一个城镇画面”和“一个野外画面”描述目标构图与疏密关系。避免全图均匀铺草、全屏亮点、随机散件和棋盘式重复。明确必须保留的通路、人物识别和交互可见性。
- 分出：必须重绘、现有资产可修整复用、先核实显示问题。不能仅换配色就算完成。

### outputs/WORLD_ASSET_REBUILD_BRIEF.md

- 按P0/P1/P2列资产或资产族清单：用途、当前问题、保留/修整/重绘、源规格、最终显示尺度、透明/不透明、平铺/分层、脚底锚点或遮挡锚点、制作依赖与验收方式。无法确认的数值写推荐值或待验证，不能冒充已测量。
- NPC：以现有身份为基础，文职、守卫、工匠、孩童靠轮廓/服装/道具辨识；保留人物差异。规范同一帧条内身高、脚底、朝向和光源，待机不漂移、不换脸、不变服装、不扭曲手与武器。
- 场景：把可平铺地表、道路过渡、地被、建筑/遮挡物、交互物、光影区分为可复用资产族；不把NPC、UI文字、任务箭头烧入底图。若推荐大底图与散件混合方案，说明边缘接缝、通路对应和遮挡边界。
- 提示词采用“场景母提示词 + NPC母提示词 + 差异表”，不要给几十个资产重复同一段长前缀。母提示词明确用途、投影视角、风格、像素细节尺度、光源、色彩预算、交付形式，以及禁止文字/UI/水印/背景污染等要求。
- 只为首轮样板写最多4条可直接用于生图的完整提示词：至少包含一位NPC与一个场景资产；其余资产用差异表描述。动画帧条提示词明确帧数、排列、同角色一致性和固定脚底。不能承诺生成工具一次就产出严格像素规格，需列出导入前可检查的条件。
- 给Codex的执行顺序：先排除显示问题 → 接入样板 → 用同一运行视角比较 → 修正 → 推广资产族。每步写具体完成判据，首轮没通过前不批量重绘全部地图与NPC。
