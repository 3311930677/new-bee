# 已确认的技术事实

以下来自少量相关文件核对，不要求Cloud读取工程。

- 截图为480×800竖屏的实际引擎渲染；并非完整世界尺寸。首轮先检查这个视口，后续用480×1067长屏核对。
- 部分地面走48×48逻辑格的TileMap路径；部分主世界采用完整底图或其他地表绘制。48不是整图尺寸，也不意味着所有新资产必须是48px。分层/平铺方案可提出，但接入方式需工程确认。
- 昭元边城NPC通用待机接口读取横向4帧，每帧128×128，即512×128 RGBA条图，默认约5帧/秒。各帧的脚底、角色外形与服装应一致，只做微幅待机。
- 嵌入游戏地图的普通NPC帧画布常用0.64倍率，即128px画布约82px显示；可见人物高度受透明留白影响，不能把画布高度当作实际人物身高。普通城务视图还存在0.72倍率。新美术尺寸须明确源画布、人物可见区域与最终显示尺度。
- 部分霜关NPC使用独立帧区域和脚底注册规则；本轮不用上述接口强行套改全部NPC。只为昭元样板明确交付规格。
- 通用NPC现有约定是帧中心x≈64、脚底y≈123；新方案可以建议调整，但默认保留落脚注册，具体可见边界由Codex导入后核对。
- 文字、名牌、交互/任务标记与HUD由引擎绘制，不烧入人物或场景贴图。建筑、人物、交互道具尽量保持可分层；碰撞与出口不随生图随意变化。
- 当前截图中的半透明建筑、裁切或不自然投影，仅能证明可见问题，无法确认是原图还是显示处理造成。重绘前应核查alpha、缩放、裁切/遮罩、层级与脚底/遮挡注册。

推荐的新像素网格、材质色数、地面过渡、建筑分层与显示尺寸由美术方案给出，不在这里预先伪装成既定事实。
