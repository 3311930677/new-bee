## 2. 统一美术语言

### 2.1 主题：「漆墨铜签」——旅人随身器物

UI 不是悬浮在世界上的“界面板”，而是旅人随身带的器物：**黑漆木牌、旧铜包边、纸签、朱砂印**。

理由：
- 背景是黄昏古城、灯笼和旧木建筑（Title），城镇是明亮的木石建筑（HUD）；漆木与旧铜在暗场能与灯火呼应，在亮场以小面积深色出现时像挂在画面上的木牌，而不是整块深色仪表盘。
- 现有 Logo 的青宝石、绿缎带与世界色系无关，删去；旧金被降级为“暗铜细边”，不再作为大面积装饰。
- “签”的形态（窄条、切角、左侧类型签头）天然适合任务、名牌和标签，解决“圆角卡片/胶囊”网页感。

形态母题（唯一）：**3px 切角**（45° 截角），代替圆角。所有容器、按钮、标签共用；圆形只用于 HUD 拇指操作圆盘与摇杆（触控习惯所需）。

- 禁止：渐变大按钮、外发光、彩虹稀有度色、通屏压暗。

### 2.4 像素与精细 UI 的融合

三层采样规则，按“它属于世界还是属于器物”划分：
1. **属于世界**（地图、角色、NPC、小地图内标记、世界内交互提示箭头）：像素风，最近邻，整数逻辑倍率。
2. **属于器物**（容器、按钮、进度条框、九宫格、铜线、Logo 字标、HUD 操作图标）：2× 或 3× 源图，线性过滤、关 mipmap（Logo 可开），所有边缘对齐整数逻辑像素。
3. **文字**：线性，独立于两者。

连接两者的手段不是“把 UI 也像素化”，而是：HUD 图标采用硬剪影 + 1px（显示尺度）暗轮廓 + ≤5 级色阶的“像素邻近”画法，与现有高清器物图标缩小方案一致；容器使用切角而非圆角，轮廓 1px，避免平滑大圆角与像素世界冲突。

### 2.5 材质、轮廓、边框、装饰

- 材质：漆墨平面，顶部 1px 亮铜 30% 高光线 + 底部 1px 影；面内亮度变化 ≤6%，不画木纹噪点、不用随机纹理。
- 轮廓：所有容器 1px 暗铜外框；亮场额外 1px 影 40% 外描（只在 HUD）。
- 边框层级：普通容器 1px；主按钮 2px（外暗铜 + 内亮铜）；地图框 2px + 四角铜包角。没有第三种。
- 装饰：只允许三处——Title 主按钮两端小铜钉、副标题两侧铜线+朱印、小地图四角包角。其余组件零装饰。
- 图标：统一 24 或 28 显示尺寸，单色剪影为主 + 一处固有色（药剂红、营帐暖褐、疾行灯金）；不加底光。
- 信息密度：HUD 常态同屏文字块 ≤6 个（Lv、HP、金币、地名、主线、委托），其余用图形表达。
- 动效：按下 80ms 缩放 0.96 + 面色变漆面；状态变化 160ms 滑入/淡入；常驻循环动画只允许 Title 灯笼光层（2–3s 呼吸，亮度 ±8%）与 HUD 低血量（1.2s）。无旋转光、无扫光循环、无粒子堆叠。

## 5. 视觉验收标准

截图必须为 Godot 实机原生截图（480×800 与 480×1067 各一套，另加带安全区模拟的一套），不接受概念图替代。

1. **原尺寸文字**：100% 缩放下，12px 文字在亮场（城镇草地/沙路）与暗场（Title 黄昏、夜间/洞穴类野外，若存在）均可辨认；不出现字形发糊、描边糊字。
2. **视觉焦点**：Title 遮住 Logo 后第一眼落点为“开始游戏”；HUD 遮住顶/底 HUD 后玩家角色位于未遮挡区域中心附近；常态同屏强调色元素数量符合 2.2 预算。
3. **热区**：所有可点击元素热区 ≥44×44，热区之间无重叠（以 MAIN_SCENES_UI_PLAN 表格为准，工程可开调试框截图核对）。
4. **长文本**：昵称 12 字、地名 12 字、任务两行 + 超长、金币 999999999、经验 0% 与 100%、HP 1/690 均不溢出、不压住邻近组件。
5. **安全区**：顶部/底部插入 44/34 逻辑像素模拟占用时，固定控件随可用矩形移动，背景/遮罩延伸至物理边缘，无控件被切。
6. **一致性**：所有容器仅一种切角、一种边框规则；图标轮廓粗细与色阶统一；未出现圆角卡片、渐变大按钮、外发光。
7. **状态可辨**：疾行开/关、药剂 0、禁用、焦点，在灰度截图中仍可区分（证明不只靠颜色）。
8. **静态局限**：截图只能证明布局与可读性；按下/焦点动画、摇杆与按钮手势冲突、帧率与绘制开销必须另行在设备/编辑器中交互测试，不能以截图签收。
