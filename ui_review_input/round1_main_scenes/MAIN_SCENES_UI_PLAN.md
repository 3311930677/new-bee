# 一、启动主菜单 Title

## 1.1 最终构图与视线顺序

主方向：**“街道即菜单”**。去掉中部承载面板，让黄昏街道的透视自上而下引导：

1. 字标“远征”（上部，城门上方的天空）→
2. 远处城门（背景自带纵深，不加任何 UI）→
3. 沿街道落到下三分之一的“开始游戏”朱漆签牌 →
4. 其下一行轻量文字入口：介绍 · 设置 · 退出。

Logo 不再压在城门上，城门成为“启程目的地”；主按钮位于拇指舒适区；次级入口不与主按钮争重量。

## 1.3 480×1067 与安全区适配

| 元素 | 规则 |
|---|---|
| 背景 | 宽度固定 480，底部锚定（石板、灯笼位置相对底部不变）；多出的 267 由 T-BG-SKY-EXT 覆盖顶部 0–300（与原背景顶部 33px 融合）。不纵向拉伸、不放大背景（放大会造成非整数像素）。 |
| 字标组（T3–T5） | 顶部锚定；顶偏移 = 72 + 0.4 ×（可用高 − 800）。在 1067 时字标 y=179，副标题 y=307。字标不缩放。 |
