# 四方向第三轮

判定：可接入游戏作效果试用。

- 四向各八帧，单帧 128×128，行顺序符合游戏现有下、左、右、上的约定。
- 头顶在 y≈19–23，所有方向的脚底统一到 y=120。
- 近远腿 / 左右腿有意分开，分别存在落地、抬脚和摆动姿态。
- 左向不是镜像右向，使用原版左向躯干和剑；前后向使用各自原图。
- 后向原图钢刃断裂已补接，握剑手和金色剑柄保留。
- 身体上下幅度 2px，披风滞后一个阶段；每帧 110ms，边缘留有透明余量。
- 原版多色和边缘透明度保留，没有强制变成工具默认的少色画风。
- 目前侧向动作比前后向更充分，前后抬脚仍偏简略。这是可交互评估的版本，不能据此宣称角色动画已达到最终美术品质。

游戏接线和运动检查在 role_pixel_studio/zs/review/verify.log 中记录。
