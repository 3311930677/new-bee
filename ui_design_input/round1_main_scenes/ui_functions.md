# 必须保留的功能

这是功能合同，不是必须照搬的布局。允许移动、合并视觉分区或将低频入口收纳；不得删除功能、虚构可点击入口或更改玩法。

## 本轮范围：启动主菜单 + 游戏内主场景

### 启动主菜单 Title

| 功能 | 必须保留的行为 | 设计要求 |
|---|---|---|
| 游戏品牌 | 显示《远征》及现有副标题“昭元行旅录” | 第一视觉识别；允许拆分标志、文字与装饰，不擅自改名 |
| 开始游戏 | 保留现有开始/后续流程 | 唯一主要行动，不擅自增加账号或服务器选择 |
| 游戏介绍 | 进入已有介绍内容 | 保留入口，本轮不设计内部页面 |
| 游戏设置 | 打开现有设置 | 次级但可发现，本轮不更改设置内容 |
| 退出游戏 | 保留现有桌面退出行为 | 低频处理；手机差异交由工程师核实，不凭截图删除功能 |

背景为黄昏古城街道，现有 Logo 带旧金边、翅膀与青色宝石。以上是可重做的现状，不是强制保留的装饰。新的 Logo 方案必须标注素材代价与无新资产时的替代方案。开始/介绍/设置/退出目前是四个按钮，不要求继续做四个同等重量的框。

本轮包含下文 B（城镇/野外 HUD），不包含下文 A（营帐）；A 仅给备用任务提供功能依据。

## A. 营帐主页（本轮不设计）

| 功能 | 现状与必须保留的行为 | 设计优先级 |
|---|---|---|
| 玩家身份 | 头像可更换；显示昵称、等级与经验进度 | 持续可识别，长昵称有处理方案 |
| 四类货币 | gold、expedition、soul、honor；现有金币、行旅令牌、魂晶、荣誉图标 | 数字易读，四币可区分 |
| 角色展示 | 当前选中职业的像素动画、职业名与等级；截图为破军战士 | 页面视觉锚点；保留脚底与场景关系 |
| 继续旅程 | 返回当前主世界地图；当前地点取自存档 | 唯一最高优先级操作 |
| 任务 | 打开主线及今日委托，摘要随进度变化 | 重要但不与主操作争抢 |
| 活动 | 打开活动面板 | 次级入口 |
| 竞技、召唤、兑换 | 现有三个独立入口；召唤/兑换存在有条件的提醒 | 可收纳，须给出明确访问路径 |
| 世界、背包、养成、图鉴 | 当前底部四入口，打开相应窗口 | 稳定导航；可调整样式及位置 |
| 设置 | 头像旁设置入口，含存档和键位等功能 | 必须可达 |
| 归路小聚 | 完成对应支线后才出现 | 必须设计出现后的布局，不能挤掉角色或主入口 |

营帐不是底部四栏中的某一个选中页，不要伪造“当前背包/世界已选中”的状态。当前地点、姓名、经验、任务、货币都必须是可更新文本或控件。

提醒只在真实条件满足时出现：任务可交付、召唤券可用、荣誉达到兑换门槛等；不得让全部入口常亮红点。现有设置与异常存档提示继续可达，设计不处理存档逻辑。

## B. 游戏内城镇/野外 HUD

| 功能 | 必须保留的行为 | 设计要求 |
|---|---|---|
| 地点 | 当前地图名；城镇与野外使用相同语言 | 长地名可读，不压住地图 |
| 玩家状态 | 等级、生命当前值/上限、历练/经验进度 | 战斗外也要易辨，低血量有可见反馈 |
| 金币 | 数字与现有点击行为 | 大数字不溢出 |
| 主线、委托及支线 | 摘要、进度、详情入口；按场景和任务状态显示 | 能收起或分层，但重要目标不能丢失 |
| 小地图 | 位置与目标提示、方向、点击展开地图 | 地图内容可辨、扩大入口可触达 |
| 移动 | 左下触控摇杆与现有键盘移动 | 与任务/弹窗/右下按钮热区不冲突 |
| 药剂 | 数量与使用入口 | 0 数量及不可用状态明确 |
| 伙伴 | 伙伴相关入口，保留跟随实体 | 与 NPC/玩家信息层级分开 |
| 疾行 | 可切换状态，缩短跑图时间 | 开/关可辨，不能只靠颜色 |
| 营帐/撤离 | 主世界回营帐，其他模式按现有行为退出 | 区分行为，不能统一成含义错误的按钮 |
| NPC、伙伴和玩家标签 | 名字、玩家标记、场景交互信息 | 标签避免互相重叠或盖住角色 |
| 情境交互 | 临近 NPC、可交互物或目标时按原逻辑出现 | 留出出现区域与层级规则 |

地图本身是玩法空间，不是静态背景。方案需要说明 HUD 对中央视野、摇杆、移动路径与右下操作的遮挡范围。现有截图为城镇，不能据此断言野外没有支线、目标指引或退出状态。

## 需要在设计中覆盖的状态

- 默认、按下、选中/开关、禁用、键盘焦点；桌面悬停可以补充，手机操作不能依赖悬停。
- 新玩家与已解锁玩家；长昵称、长地名、两行任务、货币 999999999、经验满格与零值。
- 低血量、药剂为 0、任务可交付、多个提醒同时出现、条件入口解锁。
- 短屏 480×800、长屏 480×1067，以及顶部/底部安全区有占用时。
