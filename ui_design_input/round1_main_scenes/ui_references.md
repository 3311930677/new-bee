# 风格输入：先看本项目，不照搬其他游戏

用户明确目标：成熟商业手游质感，消除廉价感、AI 模板感和网页化设计，允许重做布局。用户尚未指定某款游戏为已确认的视觉参考。

以下是从现有截图提取的项目方向，不是强制最终答案：古城行旅、像素幻想、青蓝夜景与暖灯火、旧金属、漆木、纸签。允许精简或重新解释，需说明为何与角色和场景更一致。

## 三类本地参考

1. `screenshots/home_current.png`：观察夜色、帐篷、人物与入口的关系。背景世界观可作为继承依据；当前大金边按钮、图标重量与排列只是待审查对象，不代表批准沿用。
2. `screenshots/world_current.png`：观察明亮地图、角色/NPC 与 HUD 的关系。不能将营帐暗底不加调整地盖到野外，也不能以高密度窗口遮住游玩空间。
3. `screenshots/title_context.png`：本轮启动菜单设计基线。它提供古城、灯笼、品牌装饰的语境；布局可重做，不要求继承翅膀、宝石与多层金边。

`home_tall_baseline.png` 是较早的长屏证据，不是审美参考，不据此锁死布局。

## 需要 Opus 解决的审美选择

- 像素场景、角色、精细图标与清晰中文应如何统一轮廓、材质和信息层级？不能只因分辨率不同就判定不合格。
- 什么是页面的第一视觉焦点和第一行动？让角色、任务和导航各有职责。
- 怎样用克制的材质、留白、非机械排列形成游戏感，而非靠装饰堆砌？
- 主世界 HUD 在暗场与亮场如何保持阅读，又不变成满屏深色卡片？

## 不接受的方向

- 多层圆角卡片、满屏标签胶囊、网页式统计面板、统一渐变大按钮。
- 所有模块同等大小、同样金边、同样高亮；为了“精致”给每个角都加宝石和翅膀。
- 随机纹理、过厚文字描边、廉价光晕、强行套用未验证的中文像素字库。
- 用模糊背景或重度全屏压暗掩盖构图问题。
- 用静态概念图伪装成已经运行的游戏成果。

本包不需要联网找参考。若方向存在不确定性，请提出一个有明确理由的主方案，最多一个简短替代方向，不进行大规模风格探索。
