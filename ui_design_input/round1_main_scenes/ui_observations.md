# Codex 预审备注（默认不提交 Opus）

以下仅为对包内截图的观察，不是最终问题排序或定稿方案。保留它便于设计回来后对照，避免提前限制 Opus 判断。

营帐：上方身份/四币/标题/任务信息纵向占用较大；左右入口的图标尺寸、材质与边框重量不统一；大号主按钮的金属边饰与中部像素角色竞争；角色名牌面积较大；底部图标相较侧栏显得轻；背景细节丰富，文字区需要有选择地提高可读性，而不是全屏再压暗。

城镇：左上状态、中央地点与金币、右上地图缺少一致的节奏；两条浅色任务签占用上部视野；玩家/伙伴/NPC 标签的底色和文字风格不同；右下四按钮的图案、文字和计数挤在较小空间；任务与操作区域应先给出总遮挡预算，再细化材质。

这些观察基于历史截图。长屏、低血量、条件入口、点击反馈等没有在本包中完整提供，不把它们写成已目击的缺陷。
