## 资源与接入

- 成品：`远征/assets/completion_20261024/ready/`，装备和任务图 64 像素画布，首页 32 像素，地图图案最长边 124 或 252 像素；按用途保持透明边距或自然宽高比。
- 母稿：同目录 `source/`。`source/.gdignore` 使 Godot 不导入母稿；运行使用 ready 成品。
- 生成方式：**内置 imagegen**，每个独立素材分别生成，使用已查看的项目图作风格参考。完整提示词、母稿来源、裁边范围及成品路径在 generation_manifest.json。
- 地图索引：`远征/data/asset_completion_20261024.json`。放在 data 中以沿用 Windows 与 Android 导出配置的 `data/*.json` 包含规则。
- 道具及装备索引：`远征/data/resource_manifest.json`。移除了 G 中优先覆盖新索引的旧任务 SVG 指向。
- 公共绘制：`远征/src/world/AssetCompletion.gd`。纹理缓存、图集裁区、近邻显示及任务物件语义映射集中维护。
- 准备脚本：`远征/tools/prepare_completion_assets.py`；验收：`远征/tools/VerifyAssetCompletion.tscn`。

装备数据与 HEAD 对比，仅六个模板的 icon 字段改变，属性、价格、掉落和需求字段一致。地图改动位于绘制层，测试同时核对绘制前后的进度旗标与钱包。
