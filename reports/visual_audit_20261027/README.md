| 320 宽主城顶栏、底部入口与建筑入口被裁切 | 按可用宽度缩放主城构图，短屏抬高角色，保留所有入口 |

| 养成页角色、属性和费用文字拥挤 | 重排属性与角色区域，费用卡采用紧凑排列，保留完整数值提示 |

| 伙伴、头像、图志、驿信、押镖和驿路纸页偏移或越界 | 使用设计尺寸和实际安全区居中适配；重复排版不会累积缩小 |

| 信息弹窗固定 400 宽，窄屏左右裁切 | 按安全区重排纸页、分页导航和选项，系统边距变化时重新适配 |
| 原生滚动区难以从按钮上开始拖动 | 统一触摸滚动；拖动取消点击，正常轻触仍只触发一次 |
| 按钮原生文字最小宽度把布局撑开 | 隐藏绘制文字不再决定按钮宽度；标题缩字、截断，并缓存测量结果 |
| 射箭靶心按至少 360 宽运动，320 宽时越出靶场 | 按实际靶场宽度限制准星和移动靶位置 |
| 地理地图和荣誉商城首次打开时上下边缘出界 | 内容最小尺寸变化后重新布局，返回按钮留在屏幕内 |
| 首次进城、打开世界和图鉴时重新生成或读取视觉资源 | 加载页预热实际建筑阴影尺寸、共用背景、按钮图集和宠物轮廓；世界页复用只读地图资料与任务标记 |
