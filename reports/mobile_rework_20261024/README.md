## 本轮实际返工

- 背包在手机逻辑宽度下改为四列，更大的物品格；页签高60、返回热区56、装备操作高64逻辑像素。空容量格与缺图的已持有物品采用不同表现；详情区保持滚动，操作区独立布局。
- 货币详情使用可用安全区高度，去掉720高度上限，完整余额、四币切换和返回独立于滚动正文。正文22、余额24、标题28逻辑字号。
- 战报移除440×664整块画布及整体缩放，使用容器布局；标题与64高确认按钮固定，生命、战功及战利品正文滚动。四个战利品改为两列可阅读卡片。战斗结算、奖励数据来源与确认信号保持原流程。
- 小聚保留正文滚动，字号22、选项60高。短屏收紧插画区，避免把文字和按钮一起缩小。
- 共用文字弹窗正文22、按钮60高，长文按内容滚动。
- 加载插画等比覆盖整个视口，进度和提示独立锚定安全区，取消固定海报下方的纯色补条。
- 主城背包和小聚入口移除“按下”与“点击”重复绑定；一次按下、释放只打开一次。
- 安全区将系统安全区域及显示缺口统一从屏幕物理像素转换到逻辑坐标；Android显式启用edge-to-edge，背景与交互区域分别布局。此设置需要同时正确处理安全区，参见[Godot官方Android导出说明](https://docs.godotengine.org/en/stable/classes/class_editorexportplatformandroid.html#class-editorexportplatformandroid-property-screen-edge-to-edge)。这不构成Android系统栏真机通过的证据。
- 设置常规页增加版本号与“复制设备与显示信息”，由玩家主动复制机型、系统版本、窗口尺寸、逻辑视口和安全区，不包含账号、密码和存档。

运行导出资源的方法不是Android设备或模拟器，不能把这些结果写成手机验收通过。
