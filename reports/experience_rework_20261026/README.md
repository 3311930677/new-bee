# 远征游戏体验改版与验证记录

2026 年 10 月 26 日　候选版本 0.2.2-experience

已按问题方案实施 9 组改动，并导出 Android ARM64 候选包。页面截图来自 Godot 4.7.2 桌面实际渲染；安装包另经资源比对、签名检查和包内编译代码运行核验。当前未连接 Android 设备，手机实际观感、系统栏和触摸体验保留为复验项目。

## 安装包

- [Android ARM64 候选包](./Yuanzheng-0.2.2-experience-arm64.apk)
- 包名 `org.yuanzheng.singleplayer`，versionCode `4`，versionName `0.2.2-experience`。
- 最低 SDK 24，目标 SDK 36，调试签名，APK v2 与 v3 签名通过。
- 大小及 SHA-256 见 [包核验记录](./package_verification.json)。

候选包基于当前工作区构建，保留此前未提交内容和另一轮代码审查已有的玩法改动。共享文件的全部差异不能都归于本轮界面改版。

| 编号 | 已实施内容 | 验证结果与边界 |
| --- | --- | --- |
| Q01 荣誉商城 | 新增主题展示画、分类浏览、紧凑商品卡和统一主次层级；分类名称可配置，较多分类可横向浏览；保留详情确认、余额校验、防重复兑换和保存失败回滚 | 现有五件商品及材料与宝石分类通过；额外二十件长名称商品可滚动；未来奖励类型未接入时禁止确认，避免只有展示没有发放 |
| Q02 活动中心 | 重建主题卡片、分类、真实状态、玩法收获和详情入口；时间状态变化会刷新；常驻玩法与限时活动分开表达；卡片在释放点按后打开，拖动可继续浏览 | 两项现有活动保留，列表与详情不改变进度或余额；开放与结束状态检查通过 |
| Q03 背景采样 | 将普通背景、参考底图、环境景物、建筑与地形材质的显示采样改为平滑；角色图集、UI 和地形分类掩码单独处理；保留同机位采样对照入口 | 城市、港口、雪地和栈道留有原采样与新采样截图；素材本身已烘焙的像素与笔触不会因采样切换自动重建 |
| Q04 比例与景物 | 十八张主世界地图统一步行角色缩放为 0.70，骑乘组合为 0.86；坐骑脚点按实际缩放重新注册，名牌同步调整；普通怪、精英和首领的默认地图高度分别为 64、80、108；地图怪物宽度上限同步校准；部分外围景物小幅放大 | 地图镜头范围保持；十八图角色与地点检查通过；四职业和马熊两类坐骑共八组动画检查通过；最终体感仍需手机观看 |
| Q05 背包滑动 | 新增触摸拖动判定、子按钮滚动取消通知与惯性；拖动不触发物品选择，焦点进入不再抢回触摸位置；上下焦点按真实列数计算 | 从真实物品格发起触摸拖动能滚动且不误选；已有 450 项背包交互检查通过 |
| Q06 字体与按钮 | 建立展示页面共用字号与按钮组件；任务详情改为纵向内容布局，标题、状态、目标与奖励分层；奖励区固定在底部操作上方；完成态缩短纸页；导航按钮统一高度与间距 | 商城、活动、背包、垂钓和地图覆盖宽屏、长屏与窄屏；任务四种状态均有实际截图；本轮覆盖反馈涉及页面及相关共用组件 |
| Q07 骑马节奏 | 待机、步行、奔跑基准播放速度由 5、9、15 调整为 4、7、11.5，并限制运行时过高倍率；保留完整动作帧和接触帧音效机制 | 八组职业与坐骑组合的 1264 项检查通过，包含四方向、动作切换、连续帧及缩放后的脚点；未通过降低游戏整体帧率处理 |
| Q08 垂钓 | 改为独立全屏场景，新增水岸插画、动态浮漂与波纹、抛竿和候鱼阶段提示、收竿时机、收获图标和结果反馈；霜关水域增加冷色与雪花；短屏和窄屏自适应；退出结算失败时保留当前操作 | 使用既有抛竿、收竿、图鉴、次数和制粮接口；垂钓回归通过；不同水域共享一套交互框架和场景主画，鱼种与次数分别取真实钓点数据 |
| Q09 功能大地图 | 新增按真实坐标绘制的地理详图，接入钓鱼、商店、驿站、设施和 NPC；支持筛选、缩放、拖动、密集地点聚合选择、目的地持久化、路径、HUD 与小地图追踪；地图和导航共用主线与旗标开放判定 | 实际骑乘寻路抵达钓点后，确认现场交互才进入对应垂钓；跨图下一跳覆盖十七个出发地区；取消追踪与读档恢复通过；看地图时冻结世界移动与遇敌 |

测试使用独立验收存档。引擎启动日志中有系统证书存储读取错误；保存失败用例会产生预期的锁定警告。既有垂钓独立回归仍在退出时报告对象和资源未释放，功能断言通过不消除这项技术债。其余具体日志位于本目录。

包内编译代码在桌面引擎中运行，不等于 Android 系统运行。手机复验应重点检查从物品格起手滑动、连续点按与滑动的区别、系统安全区、地图聚合选择，以及骑乘与画面比例。
